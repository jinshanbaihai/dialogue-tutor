# 简易对话 · dialogue-tutor

一个对话式学习教练技能（Claude Agent Skill）。发来一道题、一个概念、
或者一段看不懂的内容，它做两件事：

1. **HTML 讲解**：把这道题会用到的公式从本质讲透，一份可以在浏览器里读的产物。
2. **深入追问**：读完之后接着问，一来一回把剩下的聊通，答案由学习者自己说出。

讲懂了就不需要追问，所以第一件是主件。

科目落在 TMUA 数学、Edexcel IAL 统计 S2、CIE 9708 经济，
随口问的数学问题也算。

---

## 它和一般的解题助手差在哪

**初衷是完全理解数学**，所以最要紧的那件工作是从彻底的本质讲解一条公式，
而不是把答案算对。产物分成两半，哪一半都不压：

**上半 · 讲解篇**按对象分章，每章七幕：

1. 造出旧办法断掉的缺口
2. 当年那个人卡在哪
3. 把公式一步步造出来，并且到这一刻才给它命名
4. 一个跟本题无关的经典例子
5. 另一种互相冲突的看法
6. 它自己承认的边界，以及有名有姓的批评
7. 指出对应下半哪几个小问

**下半 · 做题篇**按题目自己的顺序，一题一节、一个小问一段，一个也不漏。
每个小问六样齐全：

1. 题干拆解
2. 题干昭示了哪个方法，别的方法为何不合适
3. 回接上半哪一章第几幕
4. 公式为什么用这条而不是别的
5. 每个等号单独一行并写出依据
6. 最后才是得分位置

第 5 样是这个技能最较真的地方：纵向查上一行推不推得出下一行，
横向查这一行自己立不立得住。读者逐行审的时候，
任何一行问出「凭什么」就算没写够。

对话那一侧的规矩相反，求快：回复分回顾、讲、问三段，
提问只站在已经讲清楚的前提上，追问回合零工具调用。

## 装法

```
/plugin marketplace add jinshanbaihai/dialogue-tutor
/plugin install dialogue-tutor@dialogue-tutor
```

装完如果提示 `Run /reload-plugins to activate.`，跑一下 `/reload-plugins`。
技能带命名空间，形如 `dialogue-tutor:dialogue-tutor`，
不过它是**模型自动触发**的（靠 frontmatter 里的 `description`），
命名空间只影响手动 `/` 调用时的写法。

触发词：「这道题怎么做」「讲一下这个」「带我过一遍」「考我」
「我们对话学」「简易对话」「讲清楚原理」「为什么会这样」。

本地试的时候不必先安装：

```bash
claude --plugin-dir ./plugins/dialogue-tutor
claude plugin validate ./plugins/dialogue-tutor --strict
```

### claude.ai 网页版

网页版的技能是账号级的，插件那条路走不通。
把 `plugins/dialogue-tutor/skills/dialogue-tutor/` 整个目录打成 zip
（顶层目录名必须等于 `SKILL.md` 里的 `name`），去
claude.ai/customize/skills →「+」→ Create skill → Upload a skill。
`references/` 里那三份要一起打进去，缺了会影响讲解质量。

## 目录结构

```
.claude-plugin/marketplace.json           ← 市场清单
plugins/dialogue-tutor/
├── .claude-plugin/plugin.json            ← 插件清单
└── skills/dialogue-tutor/
    ├── SKILL.md                          ← 技能正文
    └── references/
        ├── 考纲与考试局.md               ← 会话开头读一次：记号、公式册、计算器规则
        ├── 数学的冲突读法.md             ← 七幕里第⑤⑥幕的弹药
        └── 统计术语中英对照.md           ← S2 常用术语
```

`skills/<name>/` 这层结构是硬要求：目录名必须等于 `SKILL.md` 里的 `name`，
对不上 Claude Code 会加载不了。

## 渲染上的三个坑

数学产物在浏览器里翻过车，写在 SKILL.md §1.10，这里提一句最要紧的：

- **公式里的 `<` 与 `>` 要转义。** 裸的小于号会被浏览器当成标签开头，
  吞掉整段正文，被吞的那段带着配对的 `\)`，MathJax 于是不渲染，
  裸 LaTeX 源码留在页面上。
- **交付前在浏览器里真的打开一次**，搜页面上有没有裸露的 LaTeX 源码。
- **图里的标注同样走数学排版**，别在 SVG 里写纯文本公式。

## 来历

这个技能原本是一个多技能私有仓库里的一个，2026-08-14 拆出来单独公开。
公开这一份做过轻度脱敏：去掉了作者的称呼、本机云盘路径、Notion 页名与应考日期，
教学法、七幕结构、六样齐全、渲染自检那些一字未动。
`references/` 里几处指向作者私有技能的说明，改写成了不带路径的提示。

它的前身是一个按阅读流设计的数学导师技能（可视化主载体、单向讲透、零回复压力），
2026-08-12 被这一版取代。取代的理由写在 SKILL.md §9：
旧技能每条回复背着可视化、Notion 查询、出题规范一整套流程，
于是思考过久，长回复又在讲解上跳步。
