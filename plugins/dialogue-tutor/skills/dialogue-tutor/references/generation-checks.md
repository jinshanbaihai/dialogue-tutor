# 把生成要求变成当前课件的实际检查

适用于生成含免打字活动的 HTML。完整课件曾在技能文本已经写明要求的情况下，仍出现空操作推导、后组泄露前组答案、接触竞态、角色颜色丢失和回忆入口直接给卡背。以下对应表在写课件之前完成，检查在作者正式交审之前运行；它不替代专家独立审查，也不是新的学习效果研究。

## 编写前的对应表

作者保存一份 `generation-contract.json` 或等价可读文件；字段名可适配学科，但每项必须落到本课具体对象。文件是作者验收材料，不添加到学习者页面中。

|合同项|必须给出的本课内容|
|---|---|
|教学职责|模式；每个对象的七幕职责和首次建立位置；每小问六项入口；实际前提与完整例题。长的条件变化构造归③/④，⑤回看已建关系|
|逐行依据|lineId、对象、条件、before、实际operation、after、reason；相邻同式的必要核查说明；没有实际运算的行不套操作名|
|数学角色|conditionKey/pathId/lineId/occurrenceId、表达位置、objectId/role、精确值、token；变量、代入值、统计量结果与普通常量分开|
|答题组依赖|groupId、判断目标、候选来源、每字段未答标记/合法候选/必填条件；ready输入完整度与judge数学对错分开；显式空集与未回答分开；提交前后边界|
|具体反馈|missing/extra与实际值/权重/原行；correctness和提交时assistance独立；每个repair的完整必要小步、重查对象、返回当前草稿/再试；结果已见的错误优先修复，尚未呈现的预测保持待核对|
|参考覆盖|sourceId→componentId/conditionKey/kind/lineIds；入口实际可见判据；提交和状态转移前同步采集；首次时点及幂等并集|
|恢复验证|组件版本/数据hash/身份、合法条件/路径/阶段/帧组合、合法半草稿、提交冲突处理、已揭示范围；未知记录拒绝或显式迁移|
|媒体状态|合法requested与displayed组合；每个阶段当前事实、尚待问题、下一动作；当前请求的回退推导行；迟到回调隔离|
|开场与收束|openingQuestionId、所问目标、当前条件、精确结果源、已显示判据、真实作答与辅助字段、下一行动；计数不是开场答案|
|回访|每个按钮的动作种类、活动/卡片身份、实际review item来源；普通浏览、继续草稿、提前练习与到期分别处理|

题目类型也写入蓝图：与哪道参照题相比，新增了什么判断。只换数值的同构练习如实命名；改变统计量、机制或版式也要说明实际新增判断。不要把一次选对写成已经证明迁移能力。

## 作者必须执行的风险检查

使用最终组装 HTML 的真实脚本和原生控件，不只测源数据或自己写的计算函数。每项保存输入、实际DOM/导出片段、目标ID和结果。不存在的活动类型可注明不适用及理由；下列风险对应的功能一旦采用就要测。

1. **推导与语义：**独立从题面核全部不同条件的数学答案，检查每个数学变换的理由。列所有相邻同式，逐条裁定必要检查或无操作模板；不能把它们一律删除，也不能只检数值等价。核统计量名称和定义条件。
2. **组间泄露：**零草稿、漏选、误选、同时漏多时，读取整份构造的所有可见组，后组不自动补出前组的正确集合/条数。ready只检本人回答的完整/合法，judge才检数学正确。分别实际提交仅选路径、漏一个已选路径映射、权重空、分布缺一格：不得冻结、计错、揭示或消耗首答；只定位待填字段。默认零勾选与明确空集分别测，后者完成其余必填组后允许作为错误答卷；完整错选/概率和不为1不能当“不完整”拦截。完整提交后才给missing/extra，遗漏的正确路径不被评分器忽略。入站半草稿允许不完整，入站冻结答卷须同一ready。
3. **无打字与自由阅读：**正确、错误、提示、跳过、参考、重试、恢复后均无主流程键入答案；直接全解仍开放，已揭示正文可查。笔记单独标为可选。
4. **即时参考：**每个自定义作答组件分别执行原生summary→同队列submit；summary→立即旧记录导入→立即导出→用实际存储/导出在新窗口恢复→submit；summary→立即公开及原生导出。不能只测带同步采集的“全部展开”按钮。
5. **真实状态入口：**公开API与原生文件上传/下载都测；文件异步读取完成、即将应用时才做共同检查。坏版本/身份记录拒绝时保留当前可信草稿、提交和刚发生的接触；合法半草稿、错选和加载中状态能恢复。新窗口已揭示范围与具体DOM对应，恢复不增加学习动作或改旧提交。
6. **角色节点：**静态与每个合法动态帧逐位置核观察变量、代入数值、结果的值和token；正反路径、同值不同角色、变条件、正误状态都覆盖。不能仅数三种颜色，不能按字面数字全局染色。
7. **媒体异步：**成功A→请求B→失败仍指B的推导；跨条件失败；B请求→C成功→旧B成功/失败均不覆盖C；失败后重试；未完成请求期间恢复。核图、式、目标、href语义、caption、status与显隐，不只核锚点存在。
8. **有后果的反馈：**集合一漏、一多、同时漏多、正确分别核具体差异和对应原行；分别实走每个可达repair：直接读取本处完整小步，或点击真实原行读取当前差异所需的完整小步；再通过补讲自身的具名控件回当前条件草稿/判断重新核对；不以评委手工navigate替代页面入口。主预测和构造分别覆盖，所有动态href检查实际目标/祖先打开与语义；仅名称存在或正文别处有答案不算。重试的新草稿与上次冻结反馈标签分开，旧答案接触不能洗掉。
9. **数学收束：**未作答未揭示、只观察、跳过分别进入结尾；对有本条件答卷者交叉实测“无辅助正确、无辅助错误、辅助正确、辅助错误”，同时检查具体文句、冻结辅助与下一点击目的地。主预测及构造、所支持条件均覆盖，不能用辅助正确替代全部辅助场景；同代码路径合并记录时注明条件与独立异值结果。结果未呈现的预测保持待核对，不提前用repair泄露对错；已呈现的错误不被辅助覆盖，优先推荐对应修复且仍能跳过。结果已见就由当前精确模型回答开场，未见就给实际检查入口；改条件再测，不套默认结论。
10. **真实回忆：**第一卡已完成、当前第二卡背面打开时，分别走浏览、提前练习、到期复习；后两者定位真实卡片并先给正面，保留历史，提前不推进间隔。复习传完整真实item，不能只navigate到同一ID。

同源数据减少不一致，但不能作为独立数学期望值的唯一来源。测试预期从固定题干和合同推导，作者计算函数不能同时充当实现与裁判。

## 图像与证据的边界

实际 Manim 渲染、Scene/数据/帧hash及行映射照 interactive-html；实际PNG按最终图像内容宽度查看，宽度须扣除真实祖先的padding和边框。HTML有效样式核层叠优先级，不把被覆盖的字号声明写成实测值。新增控件复用已批准token/样式；按实际匹配CSS与祖先背景列“控件样式×背景”验收族，含边界、填充、外侧底色及状态覆盖后的有效值，透明色先合成。必要识别边界按既有≥3:1精算；正文与白底activity分族，同样式同背景可合并。变量存在不代替最终对比核验。完成目标后有/无scroll返回均查所有接续入口的当前文句与实际目的地。

分别记录静态源码、真实DOM事件、人工load/error回调fixture、实际PNG目视/像素、真实浏览器。人工事件fixture能检分支，不能证明图片解码或浏览器排版；jsdom也不能认证原生MathML、触控、Tab或200%缩放。条件不可用时明确未测，按当前任务约定报告，不伪造通过。

## 冻结与退回

正式交审时保存实际skill全体输入hash、可知模型/参数、生成指令、最终HTML/JSON/Scene/媒体manifest及实际测试记录；不可见配置标未暴露。专家检查失败项和其余必要路径。技能通过只是允许生成，作者测试不是专家终审。

用户要求“修skill→重新生成→直到专家通过”时，完整课件退回先修生成规则或公共组件，并复审受影响条款；下一位独立作者从空目录生成，不复制失败整课正文/题库/组件。可以使用批准的通用runtime、原始资料和已验证渲染环境。最终新课重新测试；旧版通过项只对其原hash有效。不得通过改名、只改HTML或删除失败断言来绕开循环。
