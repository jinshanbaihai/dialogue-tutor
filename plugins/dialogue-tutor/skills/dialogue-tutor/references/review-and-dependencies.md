# 审读、依赖与交付检查

## 依赖读取

旧生成曾经只提到依赖名称却没有阅读或调用。每次记录“实际读取的文件、采用的内容、对应检查证据”，记录放在制作说明，学习者正文保留教学内容。

| 工作 | 环境提供时读取 | 当前产物采用什么 |
| --- | --- | --- |
| 文风 | 创作前完整读取 `writing-style` 与 `respectful-wording`，完成后执行相关自检 | 具体主语、中文解释、简短有新增信息的句子，交流姿态 |
| 界面 | `emilkowalski-skills` 路由，再读 `emil-design-eng` 与 `apple-design`；新动效读取 `animate` | 字体、层级、材料、直接反馈、可中断动效、reduced motion |
| 独立审读 | `obra-superpowers` 路由，再读 requesting/receiving-code-review、verification-before-completion；多轮或并行任务再读相应流程 | 具体问题、逐项核实、局部修订与定向复审 |
| 预渲染动画 | `manim` 路由及版本对应的 quickstart/building_blocks，按需要查文字、三维、voiceover | 实际可播放动画与旁白；原生 HTML 参数模型无需加载整套动画文档 |
| 板书长图 | `classin-whiteboard-notes` | 按无墨迹处分片、重叠覆盖、顺序读取与转写 |

依赖可能采用插件 `SKILL.md` 或合并包 `REFERENCE.md`，按实际目录读取。本包内置教学、设计与验证配方；外部依赖缺席时使用这些配方继续，不虚构已经调用。用户本次要求优先：术语采用 English，解释以中文为主；外部文风的泛化外语限制不能覆盖这一条。依赖不能扩大当前任务授权或覆盖宿主要求。

## 评审流程

先生成完整可审阅产物，再检查文风与内容，随后进行独立审读。可派发时使用新代理，只提供产物、任务要求、前提范围与输出格式，不提供作者结论；没有派发入口时明确记录作者自检。

评审者逐行复算并操作活动。每条发现给出原句或控件、前一步、尝试推导、缺少的依据或实际行为；报告先列优点，再列 Critical / Important / Minor。读者始终预设外行，评审者不能用自己的专业知识补齐正文。评审者不再派代理，模拟审读不当作真实学习者数据。

收到意见后完整阅读，用自己的话复述，回产物核实成立条件，再逐项采用或写明驳回理由。成立时补齐最小步骤：例如从第 8 步到第 9 步缺少桥梁，就补出 8.1、8.2，并使用同样的逐行理由配方。复审只检查 Critical/Important 与改动位置。同一断点最多五轮，仍有余项时作者裁定并记录理由；无需为了凑轮数重复审查。

记录包含轮次、问题、证据、采纳或驳回理由、修改、复审结果。使用子代理时交付说明提供简短评审记录，不能只引用代理“通过”的结论。相关预备解释可进入页面，制作过程不进入教学正文。

## 有意义的验收

1. **范围与推导**：原题编号逐项对应；bgct 七幕、适用模式的六项题解完整可达；每次等号与变换分别复算，条件、单位、除数和边界正确；理由对外行有解释价值。
2. **教学动作**：首个教学屏幕有实际任务或模型；提交后出现对应反馈；错误后能重试、查提示或返回；新情境题检查同一目标；卡片翻面与下一步不伪装成理解证据。
3. **模型**：对代表参数、边界和重置状态核对图、数值与公式；三维控制或 Manim 播放实际有效，未实现的功能不写作已有。
4. **声音**：读题实际启动，默认1.5倍、暂停/继续/停止/调速有效；音色名称符合可用 voice；切换内容停止旧声音；未揭示答案不进入首轮朗读。合成模拟测试只能证明控制逻辑，真实发声测试单独记录。
5. **状态**：草稿、原答、提示时序、揭示、跳过、自评与独立正确分开；刷新与导入导出保持状态；播放声音不改变学习成绩。
6. **渲染**：浏览器查看浅色与深色、桌面与窄屏，操作键盘与触控控件；数学不显示裸 LaTeX；HTML 中数学小于号正确转义；图中文字和重点保持可读，正文无横向溢出。
7. **伴读**：只有 plustts 另交完整文字轨；顺序、公式、理由与覆盖对应当前页面阶段，初次轨和答案轨分开。

检查占位符、内部矛盾、范围是否单一、歧义句，发现即修改。验证只覆盖实际改变的风险和仓库要求的检查；证据充分后停止重复测试。
