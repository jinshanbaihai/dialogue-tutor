# 让学习者愿意继续：任务循环与讲述

以下抽样示例限定为三个身份不同的单位（N=3），均匀抽取两次（n=2）；放回例另明确两次独立。9条各1/9、无放回6条各1/6及身份对角排除只属于该例。其他总体、次数、统计量和机制按实际条件重新枚举，不照抄这些数字；不同单位即使数值相同也保留身份。通用课程使用当前学科的对象、条件与推理，四组路径构造仅适用于本类有限分布构造，并非微积分、经济或每一道题的必选流程。

## 目标及失败实例

目标是让学习者主动持续学习、体会能力增长并愿意回访，这些目标服务理解与独立应用，优先于停留时长和按钮数量。本文件把用户所说的“成瘾性”落实为有内容的继续动机。

候选技能曾经只要求挑战、结果和下一步，却允许作者写成“选择→对错→下一节”；唯一示例的错误反馈只命名误解，没有可执行修复。普通 quiz 提交又立即显示参考，和“先预测、再通过探索揭示”发生冲突。以下配方分别修正这些实际指令缺口，避免增加一层空泛奖励。

## 一次有后果的学习循环

作者蓝图为核心任务填写：**当前前提、数学缺口、可回答的问题、免打字选择、conditionKey 与 lineId、真实 Manim 帧及揭示时点、完整依据、原判断回应、可选新题**。字段属于作者材料，不是新增运行时 schema。

1. **当前需要。** 用一至两句交代要解决的问题。需要可以来自数学对象之间的差异，不必安排角色。现实情境只有在解释约束或选择后果时出现。
2. **选择产生后果。** 学习者的预测、路径集合选择、条件选择或步骤/依据选择，决定随后突出检查的对象和解释；数学真值不随所选答案改变。界面让学习者看到自己的选择，不能把任意点击都导向相同演出。
3. **证据带来发现。** 图示展示样本怎样产生统计量、参数怎样改变关系、哪些路径合并等真正数学变化。结果回应先前问题，学习者能够指出支持依据。
4. **兑现理解。** 结果一致时指出具体支持；不一致时指出差异并提供局部检查。随后安排独立新题，使刚发现的方法得到使用。
5. **带着明确问题继续。** 下一项挑战改变一个有意义的条件、提示需求或统计量。按钮标明“改为无放回再验证”等实际任务，而不只显示“继续”。

需要直接查定义、获得完整答案或建立尚缺前提时，先提供相应支持。每个小活动不必完整重复这个循环，更不能用长篇剧情延迟第一次操作。

## 预测与揭示的两种时序

- **提交就是验证：** 使用普通 quiz，提交后立即给参考。后续图示明确用于解释已知结果，不能声称结论仍待首次揭示。
- **探索承担验证：** 使用同一自定义 interactive 收集未评分预测，提交并冻结后才提供“运行／归组／揭示”动作。普通即时评分 quiz 不承担这一未揭示预测。新题辨析用 choice；整份构造用一个 interactive 四组统一提交，组件核对结果与公共探索记录分开。

探索预测状态采用一个明确的数据对象，例如 `phase`、`predictionDraft`、`prediction`、`predictionAt`、`revealedAt`、`history` 与 `parameters`，通过 `dt:exploration` 保存；这些是该组件的自定义字段。提交后保持原预测与时间，参数变化不覆盖原判断；新一轮预测追加历史记录，不把上轮改写成从未错误。

初始化和 `dt:restore` 按同一状态重建控件、图示、锁定状态与原预测比较。`reset` 明确开始新一轮，保留已提交历史。预测只作为参与和判断记录，不能自动变成客观掌握证据。

统计探索区分单次样本量、重复抽样次数与抽样机制。一次样本怎样形成一个统计量落点需要可追踪；手选样本标为枚举或演示，不能混入随机频率。随机模拟的频率与枚举所得理论概率分开标示，改变条件后保留原条件和预测身份。

必要定义和前提先在正文讲透，不为悬念延后。首屏标题、lead、图形初态、默认选项、按钮、可访问文字和伴读前行轨，不提前给出当前新题要验证的结果。学习者主动查阅全解仍然开放；组件如实显示已经获得参考，不假装仍是未接触答案的预测。

首版实测中，先看全解再导入旧记录会抹掉组件的参考标识。自定义探索按 [interactive-html.md](interactive-html.md) 的参考接触配方合并运行时记录与当前全解状态；提交新预测时同步冻结辅助快照。初始化、恢复和普通导航不产生新的学习动作。

## 三次有内容的继续动机

完整七幕与两半照 SKILL.md；③逐行构造和④完整原创例题最重，②来源/⑤另一角度短，⑥条件边界说清，⑦准确索引下半。每个下半小问六项齐全；布局与故事不能取代这些职责。

开场的缺口是“会算一次均值，还不知道每种均值出现的概率”。先用一条路径交代机制和平均，随后进入可承担的问题，不虚构平均数失效、学者独白、学习者情绪或能力。

| 当前关系 | 免打字动作 | 图与逐行推导的后果 | 可选下一题 |
|---|---|---|---|
| 有序路径到均值 | 点第1/第2筹码或路径，选下一运算/均值 | 两个抽值进入同一均值式，对应柱和真实帧同步定位 | 换路径，判断是否同均值 |
| 同均值路径到概率 | 多选完整路径集合与相加依据，统一提交 | 先显示选择，后对照多选/漏选；各互斥路径权重进入求和行和柱段 | 新数据归组，不先送答案 |
| 无放回改变条件 | 先选预计排除路径及第二次可抽对象 | 对角被排除，余下六条重新赋权1/6，逐行重建分布 | 新条件下点选构造 |

漏反向、误认均值等可能、无放回仍保留对角/1/9，分别有真实断点补讲；主行8→8.1→8.2→9同一密度。保留原选择，用“这个选项……”说明证据差异，不说“你粗心/忘了”。解释后回到准确原行并给可选新题，不仅送回整章。

任意有效提交、跳过后继续、直接全解都能读下去；不要求做对、不要求输入困惑。已揭示主行不随回退消失。预测一致、不一致、未预测、已见参考各有真实措辞。无放回可能某根柱概率不变，文案按精确数据而不是预设“所有柱下降”。来源与历史缺证明确标明，不为凑幕补人名年份。

## 挑战节奏与胜任反馈

任务开始时提供能承担的选择；随后逐步增加需要协调的关系。完整示例、局部补全、独立新题与改变条件的挑战构成递进。只增加数字大小而没有增加当前目标的要求，不算新的难度设计。

| 真实记录 | 反馈配方 | 继续动机 |
| --- | --- | --- |
| 独立客观正确 | 指出这次使用的关键关系或检查，再指明下一题增加的要求 | 用新条件验证方法能否继续成立 |
| 借助提示后正确 | 具体承认已完成的修正，保留辅助来源 | 在另一道未揭示答案的题目中独立执行 |
| 选择可诊断的干扰项 | 说明该选项和可见证据的差异，给一个立即可做的局部操作 | 修复一个明确环节后重新判断 |
| 数值错误而过程未知 | 只指出结果差异，邀请核对一个关键关系，不臆测错误原因 | 通过可见检查定位问题 |
| 跳过、未预测或先看示例 | 如实描述当前状态，给具名支持或后续任务 | 能够继续，也知道返回时需要完成什么 |
| 已操作但尚无独立应用 | 描述观察到的关系和已经记录的动作 | 将观察变成一次真正作答 |

修复后只有在实际记录支持时才说“这次合并了两条路径”“这次保留了放回条件”。没有过程证据时用中性参考说明。表扬不评价智力、人格或努力，也不用“没想到吧”预设所有学习者都预测错误。

## 讲述的感染力

讲述从刚出现的差异出发，给出解释差异所需的条件与关系，再回到当前题目的量。每段围绕一个关键选择；每个数学变换仍单独一行并给具体依据，常规运算也不压缩；不按每个等号强制暂停。公式之后说明这条关系如何回答眼前问题。

开场只保留一个当前可回答的问题，结尾用实际证据回应这个问题。正确预测与相反预测收到不同、如实的回应；未提交预测的人不会看到“你原来以为”。叙事惊喜来自发现数学结构，不通过修改抽样机制、概率权重、未知参数或题目条件制造反转。

结果文案由当前计算结果和真实阶段共同决定。首版在样本量改为 1、两个概率相等时仍提示“找出这个差异”，而先看全解再直接揭示仍称“首次观察”。比较反馈至少覆盖小于、等于、大于三个实际关系；相等时解释为什么相等。未揭示、已揭示、已接触参考分别显示对应时态；“首次”“再次”须有该动作的记录。不能只根据预测答案是否正确套用一段含固定关系的结语。

每个阶段在作者表中分别列入口条件、已显示的数学事实、尚待问题和下一个实际动作。完成映射后提示找同输出的其他路径，不再说“下一步代入”；归组后提示按当前权重核总质量，不假装原像尚未显示。教学阶段与图像加载状态分别保存；请求/失败不等于已看到图，回退也不抹去历史。逐阶段保存预期文句，实际前进、后退、改条件和失败后核对。

## 收束与再次进入

最后一项任务不只给“已到最后一项”。作者可以生成一项 `interactive` 收束活动，在 `dt:activity-mounted`、`dt:restore` 或 `dt:navigate` 到达该活动时，读取 `DialogueTutor.instance.getState()`，按活动标题显示本次真实证据与尚可验证的目标。自评、辅助和独立客观结果分别标明；仅凭进入结尾不称全章完成。

首版只检查 `revealedAt` 就称学习者亲自把样本映射、合并路径；直接观察结果的人也收到这句话。收束逐条选择实际事件能够支持的动词：

| 实际证据 | 可以写入收束的内容 |
| --- | --- |
| 只揭示或查看结果 | “已查看样本与统计量的对应”，不能说本人完成计算或合并 |
| 学习者主动选择了一条路径 | “选择查看了这条路径”；默认选中项和导入参数不算主动选择 |
| 运行随机抽样，保存次数与结果 | “运行了几次抽样”，仍不代表本人推导出分布 |
| 实际提交了步骤、归组或依据选择 | 描述选择内容及可核验结果；心答翻卡仍自评，完整构造标组件核对，不称独立书面证明 |
| 没有相应事件 | 指明可做的下一项任务，不以展示内容代替本人经历 |

作者先列“收束句→支撑字段→触发条件”的对应，再实现动态叙述。揭示时间、页面位置、默认参数不能代替作答证据；原预测与结果的关系必须保留正确、不一致、未预测和已获参考各自的口径。

收束同时回答开场问题：用**当前轮条件→实际已显示的结果及关系→原判断身份→具名下一行动**连接。只把“你已经完成”改成“你看到了”，却不说明当前证据回答了什么，仍缺少呼应。尚未揭示者提供下一项可做的验证；已揭示者使用与本轮图表同一模型的结果，不能把默认条件的结论套到改变参数后的轮次。

在编码前交一张 `openingQuestionId / conditionKey / target / resultSource / lineIds / displayPredicate / evidenceFields / nextAction` 表。结果是否显示、是否作答、答得怎样、是否辅助是独立字段，不把“正确/错误/跳过/已参考”写成互斥枚举。没有预测活动不编“原预测”。已显示时先用当前精确结果回答开场，再说明实际动作及下一题；未显示时给当前缺的验证入口。至少分别预写未作答未揭示、只观察、无辅助正确、辅助正确、不一致、跳过的期望事实和可点目标，切条件后重算；计数不能代替这段数学回应。

核心活动的四类后续都落到实际任务：正确后给新增判断的题，辅助后给未揭示的新条件核对，错项给差异对应的局部完整检查，跳过给具名支持或可选任务。可使用现有 `pathways` 或等效自定义控件；交付要实际点击验证目标，不能只写字段。已经完成且锁定的答卷只能标为“回看”，不能继续称新挑战。复选的反馈从精确 missing/extra 生成差异及对应推导行，三类单选补讲不能代替这一检查。

收束提供两项具名动作：一个改变条件的实际挑战，一个下次回忆的实际活动；目标 ID 确实存在。普通继续或浏览调用 `DialogueTutor.instance.navigate(activityId)`。回顾入口用 `DialogueTutor.getReviews(lesson,state,Date.now())` 取得该题的真实记录 `item`，调用 `DialogueTutor.instance.navigate(item.activityId,item)`，复用收起旧输入和答案的现有流程。只有到期记录标为到期；提前练习不能推进间隔。尚无复习记录时提供具名初次任务或继续未完成作答，不伪造 `item`、时间或分数。到期日期读取既有记录，不由叙事推进调度。

每个回访按钮的作者表写明“浏览/继续草稿/提前练习/到期复习”、活动ID、真实卡片index与完整review item来源。提前练习可以使用实际存在的非到期item启动原生重试/闪卡重启，明确标名，不制造item或到期时间；没有item就提供真实初次任务。不能把单参navigate换个“回忆”标签当成重启。实测第一卡已完成、当前第二卡背面开着时，提前及到期入口均定位正确卡并先给正面，历史保留，提前不推进间隔。模拟测试时钟只作事件验证，不冒充真实延迟学习。

回访先出现待提取问题，旧答案保持关闭；首次提交后才核对。若原题有未完成草稿或尚未自评的开放题，现有流程保留该工作，入口标为“继续未完成作答”，不称新的独立回忆。需要新的无提示尝试时按既有重试或到期复习流程进入，不把先前已揭示的结果包装成新证据。已有完成感来自具体能力与作品，不依靠积分重刷。

## 体验验收

对一条核心路径分别留下预测一致、预测不一致、未预测/跳过和辅助修正记录，检查实际显示的证据、回应与可执行下一行动。改变条件后的挑战与前题确实不同，错误修复确实改变当前数学要求；场景不能只换名字。

检查结尾与返回：收束没有凭空授予成就，回访入口确实存在并先呈现问题。专家记录活动 ID、输入、主要输出和裁定。真实学习者是否愿意回来仍由后续使用检验；模型专家的通过只覆盖已经操作和审查的设计。

同时操作“仅揭示→结尾”“先全解→直接观察”“导入更早记录→提交新预测”和使比较量相等的参数。核查实际句子、辅助标识与记录一致，不用只走完整成功路径的结果代替这些检查。

新课第一屏和结束把注意力放在数学问题与其答案；记录面板收起。结尾用当前条件和真实证据回答开场，再给“新条件构造”和“回忆定义/条件”两个实际入口，不以成就话术代替知识收束。动作按 interactive-html 的 conditionKey/referenceCoverage 接触并集合并，旧记录导入不抹已见，当前图/行/揭示范围一起恢复。真实持续参与尚需真人使用观察，模型专家不证明留存。
