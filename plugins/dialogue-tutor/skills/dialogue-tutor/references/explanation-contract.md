# 逐行解释与完整解题

旧示范把展开、代入和通分压进连续等号，最终答案正确却掩盖中间运算错误；只写“移项”也让外行读者自己补齐逻辑。本文件用可检查的步骤结构保留深度，减少无增量文字。

## 一次变换建立一个结果

每个推导步骤写入以下内容。字段是备课槽位，界面采用自然语言和数学排版，不需要机械展示字段名。

| 必填内容 | 读者实际获得什么 |
| --- | --- |
| 已有结果 | 明确引用上一项结果；用到更早的定义时就地指出具体内容 |
| 当前操作 | 展开、代入、积分、改变条件等只处理一个动作 |
| 合法依据 | 中文说明为什么这个动作保持等价或推出新结论；定理名称后面解释实际作用 |
| 当前结果 | 完整显示变换后的表达式或命题；本次变化换色、加粗 |
| 前提入口 | 新记号、定义、除数非零等在使用前说明；较长前置解释就地展开 |
| 视觉对应 | 有可视关系时指出图形中的哪个量、区域或状态与变换对应 |

前三项与结果始终伴随当前步骤出现。前置解释可以展开；维持当前步骤成立所需的直接理由不藏在多层折叠内。多个变换拆成多个步骤；一行不串联几个等号。等式本身两侧的同一次操作可以在同一式子表达。

### 简短而完整的示范

已知 `2x + 3 = 11`。`x` 表示尚待确定的数值；两边表示相同总量。模型用两份相同的未知量与三个单位方块表示左边，十一个单位方块表示右边。

| 步骤结果 | 当前步骤的理由 |
| --- | --- |
| `(2x + 3) − 3 = 11 − 3` | 两边原本相等，同时移走三个单位，剩余数量仍然相等 |
| `2x = 11 − 3` | 左边增加的三个单位与移走的三个单位抵消，剩下两份相同的未知量 |
| `2x = 8` | 右边十一个单位移走三个单位，剩下八个单位 |
| `(2x)/2 = 8/2` | 两边都平均分成两份，每份仍然相等；除数 2 非零 |
| `x = 8/2` | 左边两份相同的未知量平均分成两份，每份就是 x |
| `x = 4` | 八个单位平均分成两份，每份四个单位 |

独立检查：将 4 代入原式，分别计算左边乘法得到 8、加法得到 11；与右边 11 比较。模型同步移走与分组，读者不需要在图外猜测符号的含义。正式 HTML 使用数学排版；此表仅说明写作形状。

更深入的内容仍按这个粒度建立依赖。介绍 Gradient 时先建立可操作的局部变化，再解释方向与变化率；介绍 Conditional probability 时先说明哪些结果仍然可能，再改变分母对应的样本空间。术语越专业，前提越需要落实；不能以“高阶内容”跳过依据。

## 概念先可辨认，再准确命名

先给具体对象与必要示范，让读者观察可重复的关系。然后给定义、符号和适用条件，将实例对应到一般式，最后使用一般式解释新的实例。需要问下一步时，问题只使用当前已经建立的前提。读者答错后的反馈定位实际选项或作答中的具体条件，不预设读者具有某个误解。

把说明缩短时删除重述、预告、情绪形容与版面播报；保留未知记号、条件、推导理由、例子和反例。篇幅由需要建立的前提决定。采用交互来分配阅读节奏，不用字数比例驱动内容扩写。

## 每个原题小问保留六项

1. **题面与拆解**：原题英文及中文译文就地提供；逐句说明给定信息和限制。小问摘录从总题面取，保留单位、随机性、放回、至少、恰好、取值范围和精度等条件。引用只在本次材料授权和适用引用范围内进行。
2. **方法线索**：具体指出哪个条件允许使用什么方法。命令动词、分值仅是线索，不能单独决定数学方法。例如 `algebraic integration` 明确要求代数积分；`show that` 重点保留论证过程。
3. **回接前提**：指向概念单元、板书解释或 `olct` 前置卡的具体公式与条件。
4. **选择公式**：先说明一般关系和条件，再映射本题变量并代入；需要比较方法时说明各自要求与当前条件。
5. **完整推导**：按本文件逐步组织，先建立规则再使用。完整解法可在提交或主动揭示后查看；原题所有小问分别给出过程。
6. **答案与评价**：给结果、单位、精度、适用边界及有依据的得分位置。没有原 mark scheme 时，将评价标为参考要点。

六项内容按题目自身的顺序呈现；同一概念的上半示例不能替代作业过程。`show that` 已经给出结论时使用开放过程题与参考要点，不能把选中题面答案计为理解证明。

## 逐项核实

- 纵向核实：只利用已经明示的前提，能否从上一项结果得到当前结果；不能借助作者额外知识补齐缺口。
- 横向核实：每一步检查变量含义、条件、单位、定义域、零除、符号方向、舍解和近似精度。
- 题面核实：原材料、总题面、小问摘录逐级对照；共享条件明确回接；不根据中文译文重新编造英文原文。
- 模型核实：初始、边界和至少一个中间状态的数值与推导相符；图形位置、坐标方向和标签也对应。
- 语言核实：English terms（首次中文解释）保持定义稳定；理由句主要中文；每条理由新增实际依据。
- 理解核实：先独立审读，再用新题或变式收集表现。模拟审读与点击次数不充当真实学习效果数据。
