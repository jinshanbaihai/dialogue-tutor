# 统计术语中英对照

配合 `../SKILL.md` §5 的「关键术语中英并列」。他的考卷、mark scheme、
官方答案全是英文，概念通了却认不出词，等于没通。首次出现时给出英文全称与卷面写法。

这份列的是常用的那些，还列不全，遇到新的随手往下加。

## 两处容易丢分的地方

- **拼写当场提一句**。板书里出现过 trials 写成 trails 这类笔误，看到就说。
- **mark scheme 的标准搭配优先于同义词**。写 `constant probability`，
  别写 `fixed probability`；`in context` 要的是现实语境里的名词，
  抽象的 `trials` 顶不上。
