# 从学习动作组织课程

## 设计前件

目标是让学习者理解、独立应用并能够回顾，这些目标优先于操作数量和停留时间。交互＞可视化＞文字是当前用户的呈现偏好；该排序不是任何学科和任务都通用的效果定律。

旧样章展示完整推导后再次用步进重复同一内容；学习者点击时没有需要完成的推理。采用活动配方：先定义需要改变的理解或能力，再选择能够暴露该能力的动作。每项新规则对应以下观察实例或明确待测情形。

| 失败实例或待测情形 | 设计形式与活动 | 验证方式 |
| --- | --- | --- |
| 1.6.0 §0.5 明确先写足长文，图解之后才出现探索 | 配方：任务先行，图形承担关系，解释按需展开 | 首屏有可执行任务；蓝图逐目标记录动作及用途 |
| 旧 steps 只需持续点击“下一步” | 必填：新程序包含不同题的步骤补全和独立题；补全实际接收判断或表达 | 补全和独立题分别形成作答记录 |
| 待测：看到模拟结果后才填写“原预测” | 条件：预测提交前暂不揭示目标结果；提交后冻结原预测 | 改变参数不能覆盖此前预测；重开预测保留尝试序列 |
| 待测：选择题依靠选项线索正确，独立任务失败 | 配方：辨析题后按目标安排开放解释或数值/过程新题 | 不同活动分别记录；选择题不单独证明整章掌握 |
| 原正文完整推导与新增组件的解释局部不同步 | 必填：同一条件、数值与结论在全解、活动反馈和图示逐项对应 | 数学核算表覆盖所有表达位置 |
| 待测：知识任务结束后只剩长文，没有下一步 | 必填：结果含当前变化、具名后续行动及清晰收束 | 错误、辅助正确、独立正确、跳过都能继续 |

## 目标对应的证据下限

基线存在“解释 CDF 关系”的目标只连接翻卡、步进和探索的实例。因此蓝图逐目标检查：
需要独立解释或应用的目标，不能仅绑定翻卡、阅读步进或探索；另设真实提交的解释、计算或新情境题。
每个核心目标至少绑定一项活动是结构下限，不能替代该目标所需能力与题型的语义审核。
开放解释可以采用保存原答与自评要点，汇总仍注明自评，不升级为客观独立通过。

## 支架与独立活动

1. **辨认当前前提。** 首次使用符号时，给含义、条件和一个可检查例子。诊断问题允许直接进入示例；缺少前提不靠反复失败补足。
2. **获得可见关系。** 可操作图示围绕一个观察问题。图示显示当前参数、量纲、样本或模型假设。数学变化和显示变化使用同一状态。
3. **示例解释关键选择。** 完整例题说明为何选择该方法、每个主要变换的依据及最终检查。可以整段查阅，不把每个等号拆成强制按钮。
4. **渐隐提示。** 另一道题让学习者补关键概率、步骤或依据。提供可选最小提示，按提示记录辅助；不同题的缺失部分由目标决定。
5. **独立新题与迁移。** 新题的数字、情境或结构确实不同。只更换选项顺序仍是原题。若只改变数字或对象名称，标为同构练习；迁移题说明新增的判断要求。
6. **回顾与再次进入。** 结束时显示已经留下的证据以及一个具体回顾入口。复习记录依据真实时间安排，同会话重试不被解释为延迟保持。

完整章节按实际目标覆盖上述环节；短问题选择足够的活动即可。独立正确后可以进入更复杂任务，借助提示的正确后可以进入另一道无提示任务，错误后可以进入具体误解的补救活动。`pathways` 的条件基于真实作答、求助或跳过事件并注明来源；开放题自评与探索参与不触发独立正确路径。

## 渐隐路径的实际组件配方

`steps` 只负责展示，不接收缺失步骤。需要补全时，另建 `quiz/choice`、`quiz/numeric` 或
`quiz/open`，通过实际提交形成记录。不能仅把步骤标题改成“补全”却仍然只提供下一步按钮。
下面以平均值方法说明角色，题目数据互不复用；ID 是作者组织课程的示例名称。

| 学习身份 | 活动 ID 与实际类型 | 学习者承担的内容 | 证据与后续 |
| --- | --- | --- | --- |
| 完整例题 | mean-worked，steps | 查看另一组数据怎样求和、确定数量、相除及解释单位 | 仅记录示例参与；导航可进入 mean-completion |
| 步骤补全 | mean-completion，quiz/numeric | 新题已给求和与数量，提交缺失的平均值 | 实际提交；提示后保留辅助；进入 mean-independent |
| 独立新题 | mean-independent，quiz/open | 再换数据，自行写出方法、计算及含义 | 保存原答与自评要点；需要客观核对数值时另设 numeric 子任务 |

每份实际课程的蓝图另外记录 `example`、`completion`、`independent`、`transfer` 或
`delayed-same-item` 身份。身份字段属于作者蓝图；运行时评分以实际题型和作答来源为准。
步骤补全后的独立题需要重新组织方法，仅重复前一题的相同答案不满足独立题条件。

## 活动选择

| 目标 | 主活动 | 图形用途 | 文字承担的内容 |
| --- | --- | --- | --- |
| 定义与条件提取 | 闪卡、简短开放回答 | 必要时显示例与非例 | 判定要点及成立条件 |
| 相近概念辨析 | 分类或选择，必要时理由说明 | 并置有意义差异 | 各干扰项对应的误解 |
| 数量或参数关系 | 先预测，再操作，再解释 | 同步呈现模型和数值变化 | 因果依据、适用边界 |
| 方法与推导 | 示例、步骤补全、独立题 | 过程状态或结构变化 | 关键选择和等式依据 |
| 迁移与评价 | 新条件下作出选择并论证 | 比较条件改变后的结果 | 评价维度和可接受答案 |

静态图能够解释关系且操作没有额外用途时，采用静态图，并把学习动作放在图前预测或图后解释。没有额外学习用途的拖放、动画、随机奖励和重复点击不进入蓝图。

## 数学与统计的检查槽位

每个例题和评估活动记录：变量含义、允许范围、单位、假设、题目全文、参考答案、可接受表达、计算精度和评价方式。总体/样本、参数/统计量、模型概率/模拟频率、抽样分布/一次样本的分布分别检验。

枚举型抽样明确有无放回、是否独立、是否有序、基本结果是否等可能；从有序样本合并成统计量取值时累加概率。模拟频率与理论概率并列但清楚标名；概率表合计为一。随机模拟用于观察，理论结论由枚举或推导核算。

不能仅凭未知参数的数值在演示中可见，就把含未知总体参数的表达式判为统计量；定义讨论保留“仅由样本和已知常数计算”的条件。超出当前章范围的中心极限定理、置信区间和假设检验按题目需要另行处理。

## 保留与测量

页面记录参与、独立客观结果、辅助尝试、自评及延迟回顾；章节进度表示已覆盖活动或目标，不能标成科学校准的掌握率。学习收益的比较使用难度相近的新题、实际间隔、提示使用和耗时；即时交互通过仅说明产物行为符合定义。
