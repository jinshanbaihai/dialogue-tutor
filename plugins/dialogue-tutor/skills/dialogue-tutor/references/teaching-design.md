## 蓝图与先备链

从每个下半小问反向列对象、公式、条件及前提。bgct 每个所需对象映射七幕及完整原创例题；每个小问映射六项。蓝图另记稳定 lineId、activityId、conditionKey、题目身份（示例/同构新题/改变条件/延迟同题）、动作、首次揭示时点、来源、错项补讲、下一可选新题。字段是作者材料，不冒称 runtime 已实现评分。

每个未知前提先讲透再问。足够标准是读者能复述含义并据已有内容说明为何成立，不能用“展示过一个短例”充数；字数不限。首次符号给读法、对象与条件。逐层追问为什么，补齐相邻推理需要的定义、运算与合法性。

抽样分布先备依次检查：总体/样本/统计量，等可能选择、有序结果、平均、事件与互斥、独立与条件改变、概率乘法与加法，再从路径到统计量构造分布。X₁、X₂、X̄、P、∩、∪ 实际使用时就地解释。无放回的 1/3 乘 1/2 须分别解释第一抽与给定第一抽后第二抽概率；同一筹码第二次被抽到的条件概率为 0，不能只说“不独立”便跳到 1/6。

## 一步一依据与完整支持

主构造、完整例题、所有练习全解、错误补讲都按 SKILL.md §1.9：每个数学变换一行，每行具体依据。展开、合并、原函数、代入、通分、约分分开；读者能沿上一行推到下一行，同时核本行条件、单位、非零除数和舍解。8.1/8.2 与主行同密度。无需每个等号强制点击；checkpoint 只放方法选择、关键映射或条件变化。完整静态行持续可查，图帧控制节奏不把已揭示正文撤掉。

未知内容先获得解释和完整例题，随后做新题。移除上半仍须下半逐问六项齐全；移除作业，上半仍有完整对象构造与原创例题。来源/另一角度/边界保留准确短段，历史无证不编人名年份；原创评价不称官方 mark scheme。

## 免打字选择配方与证据

| 目标 | 默认动作 | 实际证据 |
|---|---|---|
| 定义、符号、条件提取 | flashcards：心答、按需提示、翻面看完整要点、自评 | 自评回忆，不能证明客观独立推导 |
| 相近概念、方法与条件辨析 | quiz/choice，选择后明确提交；逐错项反馈 | 本题辨识或应用核对 |
| 缺失一步或依据 | 新题中选择下一步/依据，提交后显示全部小步 | 具体步骤选择核对 |
| 完整有限构造 | 一个 interactive 内选择路径集合、统计量映射、概率依据、分布，统一提交 | 组件“新题构造选择核对”；公共面板仅探索 |
| 关系变化 | 原生点选参数/路径，同源 Manim 帧与当前算式联动 | 探索与可见关系，另用新题核对 |

新课主路径禁止 quiz/numeric、quiz/open 和可编辑文字/数值答案控件；只读上下文、原生 radio/checkbox/button、有限状态选择和独立可选笔记分别处理。旧类型保留运行与导入兼容。不能以“show that 要证明”为由改回输入框：保留原题全文和完整书面全解，主动作选择步骤/依据或整份构造，证据如实标名。更换选项顺序不是新题，仅换数字通常是同构练习，迁移需明确新判断要求。

## 三个数学闭环

| 闭环 | 学习者操作 | 数学后果 | 补讲与新题 |
|---|---|---|---|
| 路径→均值 | 点第 1、2 次筹码/有序路径，再选均值或下一步 | 两抽值、当前逐行均值式、目标柱同一对象同步定位 | 换一条路径检查同均值可能 |
| 同均值路径→概率 | 选完整路径集合及互斥相加依据，可取消，统一提交 | 保留自己的集合，多选/漏选对照；每条路径权重进入求和行及对应柱 | 漏反向、把均值取值误当等可能分别逐行解释，再做新数据小题 |
| 条件改变→重建分布 | 无放回揭示前选消失路径/第二次可抽对象 | 同时排除对角与把六条权重改为 1/6，重建柱图及理由 | 保留对角或沿用 1/9 各定位断点，再检查一个新条件 |

一个精确有理数 JSON 生成路径、均值、概率、柱图、Scene、正文及核对数据。随机模拟频率不能混同枚举概率；每个机制概率和为 1。条件切换改变允许结果和条件概率，不只改标题。图式实际状态和行号对应，静帧也能完成全部关键题。

## 完整构造与反馈时序

四组选择形成一份答卷，提交前不逐组判分，也不提前显示当前新题最终图/表；先冻结完整 draft 和 assistanceAtSubmit，再统一反馈。构造控件是 interactive，自身确定规则核对可展示各组结果，不能写入 runtime attempts 或冒称统一独立评分/复习调度。choice 与 flashcards 使用既有组件。

错误保留选择，用“这个选项对应……”描述可见差异，不推断心理。至少区分漏反向、均值等可能、无放回保留对角/旧权重，给局部完整小步、回到原 lineId 的入口和可选新题。答错、提示、揭示与跳过都能继续；正确分支只是建议。直接看完整讲解永远可用，记录接触，不能要求做对或先写困惑。

conditionKey 包含数据身份、机制、抽取次数、统计量与内容版本；referenceCoverage 映射每个提示/全解/结果帧入口覆盖的条件。提交前同步检查所有真实入口，已发生接触在回退、重试、旧记录导入后继续保留，冻结的首答条件不倒改。详见 interactive-html 的状态契约。

## 验收边界

逐行复算全部主链及补讲，核七幕/六项实际内容、各题原文和图式同源；仅按钮或标题数量不算覆盖。实际走正确、三类错误、直接全解、跳过、完整构造、翻卡和回访，保存最终文件 hash、条件、活动/行/帧 ID 与操作证据。独立断点审读按 §1.85，专家实物审核按 expert-review。模型审读或界面通过不证明真实学习收益、留存或书面证明能力。
