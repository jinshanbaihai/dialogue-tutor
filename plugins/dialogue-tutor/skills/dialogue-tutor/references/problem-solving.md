## 1.9 下半 · 做题篇：按题目自己的顺序，一个小问一段

**三类指令的下半都照这一节写。** `bgct`、`bbct`、`olct` 在下半这里没有差别（§1.65）。

**上半有例题，下半照旧全额写。** 上半第④幕那道例题讲得再细，
也不构成下半可以收束的理由，两处各花各的篇幅（§1.7 第④幕末尾那两条判法）。

### 先把那个坏念头点名

他的原话：**不耐心的老师非常无助于学习。Claude 可能认为前面讲解细致，
后面就可以用一个章节快速收束题目，这是错误的思想，应该被算作无耐心，应该杜绝。**

2026-08-14 那份 HTML 正是这个样子，数据摆出来看得很清楚：
讲解那六幕平均每幕 375 到 875 字；第七幕 7730 字要装 23 个小问，
**平均每个小问 336 字**。Q4(c) 那道 6 分题，从被积式到 39.2 五个等号挤在两行，
展开、原函数、上限代入、下限代入、通分，五步全在纸面之外。
而且四个小问被按「都在用 ∫f = 1」合并进一节，Q1(c) 整个漏掉了，
只在末尾速查卡里露了一行。**技法相同，他要走的路并不相同。**

### 结构

上半讲完之后，下半**从第一道题的第一个小问开始，按题目自己的顺序往下走**。

- **一题一节，一个小问一段。** 小问有几个就写几段。
- **不合并同类项。** 四个小问都在用归一化条件，就写四遍，
  每一遍连着它自己那道题的题干。
- **一个也别漏。** 交付前拿原卷点一遍小问编号，缺一个补一个。
  速查卡里有、正文里没有，算漏。
  读作业与读产物都以一道大题为最小单位，从总题面读到最后一个小问，读完再下判断（§1.95）。

### 一个小问要写到的六样，顺序固定

**① 题干拆解**（他 2026-08-14 点名要求的，这一样别省）。
先引用再拆解：上面一层是这一小问对应的英文原题原句，从总题面照搬，一字不改；
下面一层是对应的中文题面原句，同样照搬（§1.95）。
引用完了再一句一句拆开，每一句写出两件事：它给了什么，它限制了什么。
包括括号里的单位、取值范围、分值、以及那些看着像装饰的话
（「In the summer Kylie catches a local steam train」这一句正是在撑住「概率恒定」）。

**② 题干昭示了哪个方法**。指出题干里的哪个词、哪个给定条件、哪个分值
指向哪一个方法，**并且说清楚别的方法在这里为什么不合适**。
这一条是拆解与公式之间的联动，缺了它，拆解就成了复述题面。
几个常见的对应关系：

| 题干里的话 | 它在昭示什么 |
|---|---|
| specify fully / for all values of | 区间外那一行「其余为 0」也要写 |
| show that | 目标式已经给了，每一步都要落纸，跳步扣过程分 |
| write down | 不必计算，出题人等的是一眼看出来的理由（对称性之类） |
| 只给 1 分 | 同上，动手积分就说明读错了信号 |
| algebraic integration | 面积公式再快也不能替代，展开那两行要写 |
| one decimal place | 多半是在为下一问查表做准备，位数是给表册对齐的 |
| Given that…（开头） | 分母常常就是上一问的答案，先回头看上一问 |

**③ 回接上半**。这一步用的是上半哪一章第几幕造出来的东西，指名道姓写出来。
「这就是第一章第三幕造密度时那条可加性」这样写。
他手上的东西是上半给的，接口要对得上。

**④ 公式的选择**。为什么用这一条而不是别的，为什么这么用。
**担心讲不清楚就单独开一段专门讲它**（他的原话）。
同一个量有两条路可走的时候（积分还是面积公式、定义式还是 E(X²)−μ²），
两条都摆出来，说清楚这道题为什么走这一条。

**⑤ 步步推导：上一行推出下一行，每一行都挑不出毛病**。
他的原话：**具体解题还需要非常逻辑匹配的上一行必须推下一行的推理，
每一行都不能被不理解或者指出问题。**

先立形式：**每一个等号单独占一行，每一行旁边写出这一行凭什么成立。**
展开、求原函数、代上限、代下限、通分、约分，各算一行。

然后是两条独立的检查，分开跑（这两条管的是推导的行与行之间；
§1.8 那两个检验管的是一段讲解够不够深，两处别混）：

- **纵向，上一行推得出下一行。** 从上一行到这一行，中间那一步推理写得出来吗。
  写得出来就写在旁边：用了哪条定理、代了哪个值、约掉了什么、凭什么可以约
  （约掉 k 之前先说 k ≠ 0）。一行里连着放三个等号，中间那两步就消失了，
  纵向在那里断掉。
- **横向，这一行自己立得住。** 把这一行单独拿出来，他能不能指出问题。
  记号定义过没有、条件满不满足、取值范围对不对、单位对不对、
  符号方向对不对、除数会不会是 0、多解的时候舍掉哪一个又凭什么舍。

**查法**：假想他拿着笔逐行审。
**任何一行他停下来问「凭什么」或者「这里不对吧」，那一行就没写够。**

**⑥ 答案与得分位置**。mark scheme 认哪一步、哪一句话是得分点、
他的错题本里有没有这一条。这一样放在最后，篇幅最短。

### 压缩会把错藏起来，有一个现成的证据

2026-08-14 那份 HTML 的 Q4(a) 写成这样：

> ∫₂¹⁰ (s − 2)(10 − s) ds = [ −s³/3 + 6s² − 20s ]₂¹⁰ = 200/3 − (−88/3) = 256/3

下限代进去的正确值是 **−56/3**，那里印成了 −88/3；
而且 200/3 − (−88/3) 等于 96，并不等于 256/3。
最终答案 k = 3/256 是对的，中间那一行是错的。
**三个等号挤在一行，错的那一步没有地方露出来。**
一步一行的时候，这个错在写的当下就会被自己看见。

按这一条重写，计算与规则分别展开；HTML 使用数学排版，以下是内容配方：

| 步骤 | 当前表达式 | 这一行凭什么 |
|---|---|---|
| 1 | ∫₂¹⁰ k(s−2)(10−s) ds = 1 | 总概率为 1，区间外 density 为零，所以面积只计算 2 到 10 |
| 2 | k ∫₂¹⁰ (s−2)(10−s) ds = 1 | 每一条小面积都乘同一个常数 k，总和也乘 k；所以先算不含 k 的面积再整体乘 k |
| 3 | (s−2)(10−s) = 10s−s²−20+2s | 左侧每一项分别乘右侧每一项，保留正负号 |
| 4 | (s−2)(10−s) = −s²+12s−20 | 合并一次项 10s 与 2s，其他项保留 |
| 5 | G(s) = −s³/3+6s²−20s | 选择 antiderivative；三项求变化率分别得到 −s²、12s、−20。幂次变化率规则先在前置解释中建立 |
| 6 | G(10) = −1000/3+600−200 | 将上端点 10 代入 G 的三项 |
| 7 | G(10) = −1000/3+400 | 合并两个整数项 |
| 8 | G(10) = −1000/3+1200/3 | 将 400 写成分母为 3 的分数 |
| 9 | G(10) = 200/3 | 同分母分数相加只相加分子 |
| 10 | G(2) = −8/3+24−40 | 将下端点 2 代入同一个 G |
| 11 | G(2) = −8/3−16 | 合并整数项 |
| 12 | G(2) = −8/3−48/3 | 将 16 写成分母为 3 的分数 |
| 13 | G(2) = −56/3 | 合并分子，保留负号 |
| 14 | ∫₂¹⁰ (s−2)(10−s) ds = G(10)−G(2) | Fundamental theorem of calculus 将面积对应到两个端点的累计变化差；该关系已在概念部分建立 |
| 15 | ∫₂¹⁰ (s−2)(10−s) ds = 200/3−(−56/3) | 代入两个端点，负的下端点值用括号保留 |
| 16 | ∫₂¹⁰ (s−2)(10−s) ds = 256/3 | 减去负数等于增加同样的正数，两个分数同分母 |
| 17 | k × 256/3 = 1 | 把计算出的面积放回步骤 2 |
| 18 | k = 1 ÷ (256/3) | 两边同除非零数 256/3，等量关系不变 |
| 19 | k = 3/256 | 除以非零分数等于乘它的倒数；倒数相乘得到 1 |

每次变换单独呈现。规则名称后面写明本题为什么适用；尚未建立的基础规则在该步骤就地展开。依据槽位不能只填“线性”或“代入”。

### 分量

**下半保留完整解题。** 上半写得好，下半照样一步一步走。
上半负责让他理解这个对象，下半负责让他看着这个理解被用出来，
两件事谁也替不了谁。

## 1.95 小问的题干块从总题面逐字取，上英下中 ★ 2026-08-30 新增

核心指标，他的原话：**讲解一道题的语法和用词必须「宁滥勿缺」**。
滥只在两处：一处是陈述题干、讲题干，一处是讲那些被压缩过的定义。
这两处都是原文短、讲解长。他收窄过一次：
**我这里仅限于陈述题干，具体讲解过程没有这个冲突。**

### 两种块，先把名字定下来

- **总题面**：一道大题开头那一块，装着这道题各小问共用的情境与给定量。
  产物里两层的标签逐字写「英文原题」与「中文题面」。
- **小问的题干块**：每一小问开头那个标签逐字写「题干：」的块。

**总题面是这道题的权威题面块**，来源分两类：
作业题的权威题面是原卷英文，配一份我译的中文；
自己写的例题（§1.7 第④幕）没有原卷，那个例题框就是权威题面，
写它的时候一次把英文层与中文层都写定，英文照考试局的命令动词写法。
两类都有对得上的原文，小问块才有地方逐字取。

### 原文一直在产物里，掉词的是复述那一步

S2 CH6 数出来：15 个总题面，「英文原题」与「中文题面」两层齐全（下半各 15 处）；
下半 57 个小问的题干块，带英文层的 0 个。上半例题另有 24 个题干块，
它们照搬的是例题卡那两栏。

**核心动作：小问的题干块从总题面逐字取，上英下中，引用而不是复述。**

**这一条只管 HTML 上的块。** 音频那一侧照 §1.65 六不动：英文原题不整段念，
讲的时候用中文把随机、每一组抽完放回、题目给的那个情境一个不落地说出来，
命令动词照旧点名英文。上英下中说的是屏幕上两层的位置，跟先念哪一层没有关系，
因为英文层根本不念。

**取哪几句，写死两条**，免得同一段情境在页面上印十几遍
（他说过：**你不要反复给我讲左边中文题面，右边英文题面，这是浪费我的时间**）：

1. 这一小问自己那几句，从题号底下那一段起到命令句（含分值括号）为止，中间连续搬，一句不跳。
2. 它依赖的限定词所在的那一句（random、replaced 这类，掉了就算不出来的）。

各小问共用的情境句在总题面出现一次就够，小问块里用带引号的短语回指
（「那袋 50 个 counters」）。上一小问已经证出的结论另起一行写在两层之外并标出处。

中文那一层的标签写「中文题面（我译的那一份）」。考卷、mark scheme、官方答案全是英文（§5），
中文没有外部原文可对，所以判据分开：英文层对着原卷逐字核，
中文层对着本题总题面那份译文逐字核；两处译文只留一版，改一处两处一起改。

英文层与中文层的句数对不上的时候，页面上留字，别拿自己翻的英文凑数：
原卷英文未收录的写「原卷英文未收录」，这一小问的要求落在共用段落里的写「见本题总题面第 N 句」。

### A1 (c) 的小问块复述掉了什么

现在的小问块：

> 题干：抽 n 组「2 个 counters」，每组抽完放回。T = 这 n 组里 mean 等于 4 的组数。
> 求使 P(T=0) < 0.15 的最小 n。（由 (a)：单独一组的 mean 等于 4 的概率是 9/245。）

总题面里那两层原样写着：

> **英文原题**
> A random sample of n sets of 2 counters is taken. The random variable T represents
> the number of these n sets of 2 counters that have a mean of 4.
> Given that each set of 2 counters is replaced after it is drawn,
> c calculate the minimum value of n such that P(T = 0) < 0.15 (3)
>
> **中文题面**
> 现在随机抽取 n 组「2 个 counters」。随机变量 T 表示这 n 组里 mean 等于 4 的组数。
> 已知每一组抽完之后都放回袋中。计算使 P(T = 0) < 0.15 成立的最小 n 值。(3)

复述掉了两样，压缩了一样，原文三处都写着：

| 掉的或者压的 | 原文写着 | 掉了之后 |
|---|---|---|
| 随机（丢） | A random sample of n sets | 只剩「抽 n 组」，random 是走得通 binomial 的前提 |
| 随机变量（丢） | The random variable T represents | 「T =」像在定义一个数，B(n, 9/245) 没有出处 |
| 每一组抽完之后都放回袋中（压成「每组抽完放回」） | each set of 2 counters is replaced after it is drawn | 「之后都……袋中」没了，放回落到哪一层要读者自己补 |

那句「由 (a)：……是 9/245」现在在小问块第二行，原卷上没有，是我加的，
按上面的规矩它另起一行写在两层之外并标出处。

**下游出现一句澄清，往上游查那个词。** 这道题的拆解表花一整行还原「每一组」：
「放回说的是「组」与「组」之间，组内那两个筹码仍旧无放回」。
做法分两步：先回题干层把那个词放回去；那一行澄清**留着**，
改成挂在拆解里的一句依据（「原句的 each set 管的是组与组之间，组内那两个筹码仍旧无放回」），
别再以「注意」开头当补丁写。原句自己并不说穿组内那一层，删掉它读者就少知道一件事。

### 这几个限定词丢掉之后，答案跟着错

| 原题里的词 | 丢掉之后答案怎样错 |
|---|---|
| a bag contains **50** counters | 按 10/50 再算一次得 1/25，正确值是 9/245 |
| a **random** sample of 3 light bulbs | (3/4)³ = 27/64 没有出处 |
| **exactly 2** / **at least 8** / **no more than 3** | P(X=2)、1−P(Y≤7)、P(X≤3) 三条路互相串号 |
| calculated **only** from the observations | ΣX/n − μ² 被当成了 statistic |
| **in a 4-hour period** / **in a 12-hour period** | λ 忘了按比例缩放 |
| two assumptions, **in context** | 答案不带情境，那一分不给 |

### 压缩的定义那一侧，原句里每个实词都要有一行

`A statistic is a quantity calculated only from the observations in a sample.`
第 2 章那张定义卡六行里没有一行专讲 only，而例题的失分栏写着这一分常常丢在它上面。
only 把「来自样本」收紧成「除了样本什么都没用到」，
第二句 `It does not involve any unknown parameters.` 是它的推论。

展开覆盖七样：中心名词的语法形状；每个名词落到手上哪样东西（X₁…Xₙ）；
限定词单独占一行，点出哪一条是它的推论；哪些一出现就算不出数（未知的 μ、σ）；
哪些像符号却照样算得出（3、n 是常数，只挑三个观测值也放行）；
一眼查的程序（逐个字母问「这个值我手上有没有」）；要抄进答题纸的那一句。

英文给两份还是嵌短语，分界照文件查：出现在考纲条目原文或者 mark scheme 里的整句
（statistic、population、critical region 这几条定义），给两份；
只在题面里出现一次的说明性句子，嵌短语。拿不准就翻 `考纲与考试局.md`
里这一单元的条目，条目里逐字写着的就是第一档。

### 「讲题，不是读题」管的是版面，学科词照旧都在

§1.65 六右栏那条示例写着「从里面摸 2 个，把这两个数的平均记作 M」，
对着 `A random sample of 2 counters is taken from the bag` 少了 random，
按这一节它是反例；同一批改动里的第 1 条把那一格补齐（§1.65 六）。
那一条管的是不报版面：左右栏、加粗、紫字、栏名、行号都不报，学科词照旧留着。

**这条判据只裁题面块里的字**：题面块里搜不到出处的句子，挪进拆解或者删掉。
讲解那一侧按 `experience-design.md` 补足理由与衔接，不用重复题面增加篇幅。
第②幕的来历、第⑤幕的另一种看法、第⑥幕那条批评、闭眼段、§1.85 那块追问对话卡，
删掉之后他一步也不会算错，可是那几样正是 §1.7「读者是谁」要的东西。

比较小问与例题时，检查的是拆解、方法、逐行推导与依据是否完整，引用题面的长度不作为讲解深度；
检查伴读时，逐项映射题干条件、步骤与理由；不重复朗读英文题面，不用字符倍率代替覆盖检查。

### 交付前跑这几样

先核基准链，顺序是三层：**原卷英文原句 → 总题面两层 → 小问块两层**。
先核总题面（英文层对原卷，中文层拿英文原句回译比对），再核小问块。
总题面自己掉了词的时候，逐字照搬只会把同一个漏洞复制到几十个块里。

HTML 那一侧（并进 §1.10 的交付自检）：

1. **点两个数**：`grep -c '题干：'` 与 `grep -c '英文原题'`。
   分母只算总题面带英文原题的那些题；只有中文的那几题从分母里排除，并在块尾注一句原卷语种。
   两个数打印出来贴在交付回复里。S2 CH6 现在是下半 57 对 0。
2. **全量子串匹配**：把每个题干块英文层的每一句，去空白、统一引号与破折号之后，
   拿去本题总题面「英文原题」栏做子串匹配，打印匹配不上的块号与句子，结果为 0 才算过。
   中文层留人工复核，选法写死：每道大题的最后一个小问，加上分值最高的那一问。
3. **搜补丁句**：搜「说的是」「指的是」「这里的」「其实是」「强调一下」「注意」这几串，
   命中的每一句问一遍「它在还原总题面里的哪个词」，答得出来的把那个词放回题干层，
   那一句改挂进拆解。
4. **数实词**：定义卡跟英文原句并排，中心名词、限定词、介词短语、否定短语逐个数过去，
   卡里有没有专讲它的一行；没有印刷体原句的拿考纲当基准。

讲稿那一侧（并进 §1.65 六的自查）只加一样：题面那几块讲出来的时候，
随机、每一组抽完放回、恰好、至少、只用这类限定词在中文讲述里一个不落；
英文原题照旧不整段念。

阅读顺序那一样归 §1.85 第 1 关：**先从总题面读到最后一个小问，再动手搜。**
他指出过原因：**你总是不能完整阅读上下文，而是只挑选关键词出现的附近。**

A 卷第 4 题有先例：**缺的那一问标为未能核实，别当成漏讲**，并说清缺哪一问；
读不出的词单独指出来问他，别改写成自己的话蒙过去。
