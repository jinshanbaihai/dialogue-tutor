# 视觉模型与 Apple / Emil 设计

旧主题用米黄、暗绿与整片暖色模拟护眼，用户明确否定了这个结果。目标是视觉交互优先且阅读舒适；这个目标高于装饰和主题数量。以中性底色、清楚的字体层级、克制的彩色强调和即时反馈表达精致感。

## 页面与组件共同采用一套设计

| 层级 | 默认形状 |
| --- | --- |
| 页面 | 浅中性灰背景、接近白色的实心内容面、深石墨色文字；暗色为可选的匹配主题 |
| 学习主体 | 一个当前问题与对应模型占据主要区域；桌面可并列，手机按问题、模型、解释顺序排列 |
| 导航与记录 | 紧凑导航、当前位置与次要学习记录；工具不会占据首屏主体 |
| 色彩 | 一个主要蓝色 accent，少量语义颜色表示对象与状态；图形、公式和强调词共享颜色含义 |
| 排版 | 系统字体，中文回退到 PingFang SC、Microsoft YaHei 等；正文约 17–18px、行高约 1.65，标题以字号和字重形成层级 |
| 容器 | 细边界、适量留白、柔和圆角与轻阴影；避免每段一张同样的卡片 |
| 强调 | 对关键因果短语同时换色、加粗；用文字或符号补充状态，不能只靠红绿区分 |

数值是本项目默认设计选择，实际布局以本包 CSS 为准。修改主题时同步页面壳、互动组件、模型图形、焦点、错误/成功状态与窄屏，避免旧正文主题压过新组件。必要正文采用稳定实心底面；少量半透明材料用于浮动工具栏，避免叠加玻璃与渐变遮挡公式。干眼相关需求落实为可调整的阅读方式、字号、亮度主题和语音，不推导出某个颜色能治疗或预防症状的结论。

## 操作反馈与教学动画各有节奏

EMI 的 `emil-design-eng` 与 `apple-design` 提供操作反馈、直接操纵、可中断动画和排版原则。原技能的动效只处理控件开合；现在模型变化也需要与学习目标对应。

- 按下时立即反馈，点击确认与题目评分仍按明确提交发生。滑杆拖拽持续更新当前值、图形和公式。
- 高频开合采用即时切换或轻量过渡；普通控件过渡约 150–250ms，明确指定属性。采用现有 easing token，避免 `transition: all`。
- 每段教学动画解释一次具体变化，保留不变对象；提供暂停、重播或逐步操作。教学过程的时长由理解目标决定，不套用控件 300ms 的限制。
- 新操作可以打断旧动画；拖拽保留指针抓取偏移，键盘提供等价操作；数字变化不等待装饰动画结束。
- `prefers-reduced-motion` 下提供静态步骤或轻量切换，解释和模型状态仍然可用。悬停动效只在支持悬停的精细指针设备启用。

设计审读采用 **Before / After / Why** 三列表。通过桌面与手机截图、实际操作检查留白、公式溢出、文字层级、图例和焦点。源代码有 CSS token 不能代替视觉检查。

## 选择能够解释关系的模型

| 读者需要观察什么 | 载体与动作 |
| --- | --- |
| 数量、比例、函数、概率区域、二维关系 | 优先内联 SVG / Canvas；改变参数后同步更新模型、数值和公式 |
| 空间方向、遮挡、曲面、投影、旋转本身就是学习目标 | 可操作的 3D；提供旋转、重置、轴向标签与需要的二维投影，避免只有装饰性旋转 |
| 一个连续过程的精确预渲染演示 | Manim；分段播放、暂停与重播，配对应步骤说明或旁白 |
| 固定结构或离散推导 | SVG / MathML 与步骤状态；当前步骤高亮实际发生的变化 |

Manim 名称来自 `3b1b/manim`，其 ManimGL 与 Manim Community Edition 的 API 分开维护。本包的 `manim` 技能路由采用 ManimCE；开始场景前确认版本，读取 quickstart 与 building blocks，公式排版、3D、voiceover 按任务追加对应资料。不能混用 `manimlib` 与 `manim` 导入。

浏览器需要实时选择任意参数时使用 `interactive`；Manim 视频承担预渲染演示。选择视频不意味着已经实现参数互动。Manim 环境不可用时交付实际运行的 SVG/Canvas 状态模型并记录载体，不能以未渲染脚本或分镜作为已可播放模型。

每个核心对象至少有能够解释其关系的视觉表达；抽象论证可以使用可切换前提与结论的结构模型。每个模型标明变量含义、单位、定义域、初始状态与重置入口。先计算预期，再核对初始值、边界值和中间值。采用 3D 时先写明二维表示遗漏的哪项关系，避免为了高级感增加空间负担。
