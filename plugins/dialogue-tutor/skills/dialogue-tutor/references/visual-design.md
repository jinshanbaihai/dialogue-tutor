# 数学学习界面的色彩与真实图帧

以下抽样示例限定为三个身份不同的单位（N=3），均匀抽取两次（n=2）；放回例另明确两次独立。9条各1/9、无放回6条各1/6及身份对角排除只属于该例。其他总体、次数、统计量和机制按实际条件重新枚举，不照抄这些数字；不同单位即使数值相同也保留身份。通用课程使用当前学科的对象、条件与推理，四组路径构造仅适用于本类有限分布构造，并非微积分、经济或每一道题的必选流程。

1.7.1 修订。视觉服务完整推理；正文继续可读，图与操作插在准确行旁。新课使用单一明亮主题 `theme:"light"`，明确 `color-scheme:light`。下表是本项目审美与可读性选择，不是临床建议或学习效果研究。

## 共享身份与浅色 tokens

HTML 使用 runtime 的 --dt- 变量；Manim 使用同一 JSON 色表的确切值。数学对象身份不能被章节色、按钮色或正误色覆盖。

| Token（--dt- 前缀） | 值 | 用途 |
|---|---|---|
| canvas | #F6F5F2 | 页面背景 |
| surface | #FFFFFF | 正文、图底 |
| surface2 | #EEEDE8 | 辅助区、选中/提示/反馈容器底 |
| ink | #202C39 | 正文、概率、通用数字 |
| muted | #586674 | 依据、轴、非当前路径文字 |
| line | #D4D8DC | 装饰分隔/网格 |
| control-line | #7B8792 | 可操作边界、必要图边界 |
| action | #8C4A25 | 当前提交/前后步操作 |
| on-action | #FFFFFF | 实心操作按钮文字 |
| focus | #195FC4 | 3px 焦点环、3px 间隔 |
| math-x1 | #2364AA | X₁，第1次；圆形并带文字 |
| math-x2 | #7250A4 | X₂，第2次；方形并带文字 |
| math-stat | #0F7074 | 均值/统计量；菱形并带文字 |
| success | #176B4B | 正确图标与边线 |
| error | #AE3447 | 错误图标与边线 |
| hint | #775918 | 提示标签 |

每个对象在共享数据中有 objectId、role、label、token、精确值、stageId；manifest 记录它出现在哪些 lineIds/帧。筹码用值和编号区分，不给九条路径九种颜色。选错后 X₁ 仍蓝、X₂ 仍紫、均值仍青，外侧显示文字/图标/边框；不能把全式染红或绿。非选中不是不可用，不给整项低 opacity。相邻对象用 surface 间隔/描边与形状区分。

旧无 theme 课程保留旧自动主题兼容。新稿如另做暗色，须从同一 Scene 数据实际渲染暗图并全套检查；不得 filter/invert 光栅图，不因旧 CSS 有 dark 便称新 Manim 图双主题通过。

## 正文与手机构图

页面暖灰底、白色正文和图面、深墨文字；标题用墨色，少量暖棕标记操作。记录工具默认轻量收起，第一屏先给当前学科必要条件、一条可承担示例和具体问题；抽样课在这里说明抽样机制。定义不整体折叠，已揭示行保持正常对比度，当前行用细线/行号定位。完整讲解随时可打开，错答不锁阅读。

正文建议 17px/1.8，手机不小于16px；选项/按钮16px，按钮最小高44px；辅助说明14px；公式默认18px，分数上下标宜20px。文字列约700–760px，图可适当拓宽，不用多层嵌套卡压窄。手机逐行表改为“行号+公式”“依据”上下排列，数学变换不合并；长公式在合法断点分行。

数学教学图真实 Manim 渲染静帧或视频；HTML 原生按钮承担选择和焦点。手机九路径用3×3矩阵，行标第1次、列标第2次，单格有序对；均值计算放紧邻 HTML 当前行，路径矩阵与完整柱图分帧或分面。不要同时塞九行算式、树、柱图和图例，也不能把桌面全景缩成小字。

桌面可从1600×1200、4:3起步；手机专用可从1000×1250、4:5起步。360宽两边16留白时图宽328；源PNG实际字形高约49px才能显示约16CSS px，关键符号约55px对应18px。Manim font_size 不等于实际字形高度，检查最终PNG和浏览器截图；不足就拆图或改构图。必要轴在最终尺寸≥1.5px，主对象≥2.5px，当前强调≥3px，网格≥1px。

有放回/无放回概率柱图共用同一纵轴范围与真实数值横轴间距，零概率用空心基线标记及“0”。排除的路径有斜线和“不允许重复”说明；两机制以标题/分面区分，不替换数学对象色。条件切换同时删除对角并重赋1/6，保留数据正确比例；少路径不等于每根柱都下降。

## 图帧和交互分工

同源精确状态供路径、公式和目标柱同步高亮；每步保留条件、行号和图下 HTML 说明。前后按钮选择真实帧，暂停可读，视频可选；减少动态使用同源静帧并保留全部推理。动画只动必要对象，不在视频里画假按钮。界面新增动效按 SKILL.md 的 emi 完整路由，频繁展开直接切换或轻量 opacity/transform。

## 实物检查

至少360×800、390×844、1280×900截图，200%文字缩放和键盘完成主路径；检查无页面横向溢出、按钮可操作、图文相邻、实际数值≥16px/关键符号≥18px。以上字号是本项目目标，不称WCAG一律规定图标签16px。

从 computedStyle 检查正文、依据、链接、选项默认/选中/悬停/焦点、提示、正误、按钮；Manim真实帧核对色表、对象标签和源图字号。透明色先与背景合成；普通文字≥4.5:1，必要图形/控件≥3:1，不四舍五入判过。深色若未提供不计通过。灰度仍以形状、标签、位置识别对象与反馈，不能只靠红绿。

保存最终 HTML、Scene、媒体 hash、实际状态/行与截图；色表计算不是浏览器实物通过。依据：[W3C文字对比](https://www.w3.org/WAI/WCAG22/Understanding/contrast-minimum.html)、[非文字对比](https://www.w3.org/WAI/WCAG22/Understanding/non-text-contrast.html)、[不用颜色作为唯一信息](https://www.w3.org/WAI/WCAG22/Understanding/use-of-color.html)。
