# 考纲与考试局

**出题、估难度、判断「这个该不该会」之前，先读一遍这一份。**

考试局决定了同一个知识点的记号、方法和评分方式。用错考试局的解法，
在考试里是拿不到分的。这一种比算错更难自己发现，因为它看起来是对的。

## 统计这门课是 Edexcel IAL 的 S2

**这门课是 Edexcel IAL 的 Unit S2。** 一度被写成 S1，2026-08-08 已更正。

分清这两个单元很重要，因为它决定什么算「前置知识」、什么算「超纲」：

| 单元 | 官方单元描述 |
|---|---|
| **S1**（前置） | 概率统计中的数学模型；数据的表示与概括；概率；相关与回归；**离散**随机变量；离散分布；正态分布 |
| **S2**（本课） | 二项分布与泊松分布；**连续随机变量**（p.d.f. 在条目 2.2）；… |

由此可以推出一条：**S1 的全部内容都是可以直接用的前置知识**，属于范围之内。
学生做 S2 的题时用离散型的 $E(X)$、$\operatorname{Var}(X)$ 做类比，
或者用到正态分布，都是正当的。CH4 板书本身就写了「把 $\sum$ 换成 $\int$」这个对照。

出题时把 S1 内容划进「不要使用」，题目会浅很多，所以 S1 留在可用的那一侧。

## 数学 / 高数 / 统计 · Edexcel IAL

规范一份 PDF 同时覆盖数学、高数、纯数的 AS（IAS）和 A Level（IAL）：

| 资格 | 代码 |
|---|---|
| 国际 AS 数学 / 高数 / 纯数 | XMA01 / XFM01 / XPM01 |
| 国际 A Level 数学 / 高数 / 纯数 | YMA01 / YFM01 / YPM01 |

IAL 是**单元制**：纯数 P1–P4、进阶纯数 FP1–FP3、力学 M1–M3、统计 S1–S3、决策 D1。
「这一章之前教过什么」按**单元**来看，Paper 的分法在这里对不上。
具体单元包含哪些内容，去查本地那份规范原件，比凭印象稳。

- 记号和方法按 Edexcel 的习惯。**数学科用 Edexcel 的考纲和写法**，
  CIE 那一套只用在经济
- **考试提供公式册**（Mathematical Formulae and Statistical Tables）。
  所以「这个公式要不要背」按公式册判断。**这一条和 TMUA 正好相反**，
  TMUA 不给公式册，公式都要背下来
- 允许使用计算器（见规范 Appendix 6）。**TMUA 那边不用计算器**，
  两边的练习分开出

## 经济 · CIE 9708（A Level 阶段）

现行考纲版本：**2026、2027、2028 年考试适用**（Version 2）。六月与十一月场次。

四张卷，**A Level 阶段考的是 Paper 3 和 Paper 4**：

| 卷 | 阶段 | 形式 |
|---|---|---|
| Paper 1 | AS | 选择题 |
| Paper 2 | AS | 数据分析题与论述题 |
| **Paper 3** | **A Level** | 选择题 |
| **Paper 4** | **A Level** | 数据分析题与论述题 |

**AS 的内容是 A Level 的前置知识**，考纲原文：AS Level content is assumed
knowledge for A Level Paper 3 and Paper 4，但 AS 内容不会成为 P3/P4 的直接考点。
所以出 A Level 题时：AS 的东西可以用、可以要求他会，题目本身落在 A Level 内容上。

- 术语、图表画法、答题结构全部按 CIE 的评分标准（mark scheme）来
- CIE 经济的评分很看重**答题结构**：定义 → 解释 → 图 → 应用 → 评价。
  出题和讲评时按这个结构走，比写成一整段论述文更贴评分标准
- 评价题（evaluate / discuss）要给出两面并落到一个有条件的结论，
  「it depends on...」式的结尾正是 CIE 想要的收尾方式
- 历年卷用 `9708_<年份场次>_qp_<卷号>` / `_ms_` 命名，
  `qp` 是题目卷，`ms` 是评分标准。**讲评时以 ms 为准，得分点照它写**

## TMUA · 2026 年 10 月场次

本节写于 2026 年 8 月 8 日，依据当期官方内容规范。

### 考试形式（这些直接决定出题方式）

- **两张卷，各 75 分钟，各 20 道选择题**，连着考完
- **不要用计算器**
- **不给公式册**，所有公式要背下来
- 答错不倒扣，所以**每一题都填一个答案**
- 成绩 1.0–9.0，保留一位小数，**没有及格线**

> 出 TMUA 练习题时：**要是选择题、要不依赖计算器、要能在约 3.75 分钟内做完。**
> 一道要按计算器的题，或者一道要写两页证明的题，练的东西和考场上要用的对不上。

### Paper 1：Applications of Mathematical Knowledge

考 Section 1（Part 1 ≈ AS 纯数，Part 2 ≈ GCSE Higher）。

Part 1 的题目编号是 `MM1`–`MM8`：

| 编号 | 内容 |
|---|---|
| MM1 | 代数与函数：指数律、根式化简与分母有理化、二次函数与判别式、配方、联立方程、一次与二次不等式、多项式运算与因式定理/余数定理、函数的多对一概念 |
| MM2 | 数列与级数：通项与递推 $x_{n+1}=f(x_n)$、等差级数、有限等比级数、无穷等比级数收敛（$\|r\|<1$）、二项展开 $(1+x)^n$ |
| MM3 | 坐标几何：直线方程、圆的方程与圆的性质 |
| MM4 | 三角：正弦/余弦定理、面积公式 $\tfrac12 ab\sin C$、弧度制与弧长扇形面积、特殊角三角函数值、三角函数图像与周期性、基本恒等式、区间内解简单三角方程 |
| MM5 | 指数与对数：$y=a^x$ 图像、对数律、解 $a^x=b$ |
| MM6 | 微分：导数即切线斜率、$x^n$ 求导（n 为有理数）、切线法线与驻点极值 |
| MM7 | 积分：定积分与曲线下面积、$x^n$ 积分、微积分基本定理、区间合并、梯形法则、解 $\frac{dy}{dx}=f(x)$ |
| MM8 | 图像：常见函数作图、图像变换、$y=mx+c$ 与 $y=a(x+b)^2+c$ 的参数影响、用微分判断图形、交点、方程解的几何意义 |

**Part 2（GCSE Higher）里有统计和概率**，考的范围比代数宽：
频数密度、分组数据的众数组/均值/中位数估计、数据集比较、
何时用加法何时用乘法、条件概率、双向表 / 树状图 / 文氏图、
独立与不独立情形的树状图。另外还有比例与百分比、相似与比例因子、
向量（用向量构造几何证明）、三视图与体积公式等。

Part 2 里另外写明：**不要求记忆或使用正弦/余弦定理**（那是 Part 1 的要求），
球/棱锥/圆锥的公式如需要会给出。

### Paper 2：Mathematical Reasoning

考 Section 1 + Section 2。Section 2 是 TMUA 真正的分水岭，A-Level 里基本不练：

**论证的逻辑（Arg1–Arg4）**
- true / false，and / or（or 是**兼容或**）/ not
- `if A then B`、`A if B`、`A only if B`、`A if and only if B` 四种句式的区别
- 逆命题（converse）、逆否命题（contrapositive），以及三者真假之间的关系
- **必要**与**充分**
- for all / for some（至少一个）/ there exists
- 对以上各种陈述**取否定**
- 注：符号记法和形式真值表都在要求之外

**数学证明（Prf1–Prf5）**
- 直接演绎证明、分情况证明（如奇偶分开）、反证法、举反例否证
- 从给定陈述推出蕴涵
- 从小情形做猜想再证明
- **把打乱的证明步骤重排成正确顺序**
- 需要长链条推理的问题

**找出证明中的错误（Err1–Err2）**
- 识别伪证里的错误
- 常见谬误，例如「由 $ab=ac$ 推出 $b=c$」、「由 $\sin A=\sin B$ 推出 $A=B$」。
  两者都不成立

### 出 TMUA 题时照这几条

1. **只出选择题**，给 4–5 个选项，错误选项对应真实的典型错误，别拿凑数的选项填位置
2. **要按计算器才做得出的题不用出**：难算的小数、开不尽的根号求近似值都别出现
3. **公式不给出来**，题目本身要求学生记得公式
4. 单题目标 3–4 分钟
5. Paper 2 的题要真的考推理，Paper 1 的计算题换层皮不算数
6. 内容留在上面 MM1–MM8 + Part 2 + Section 2 的范围里，
   **范围外的都不出**（比如 A-Level 才有的乘积法则、商法则、链式法则、
   $e^x$ 与 $\ln x$ 的微积分、参数方程、复数、矩阵。TMUA 规范里都没有）
