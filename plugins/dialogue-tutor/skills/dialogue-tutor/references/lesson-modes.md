# 模式决定内容范围

旧课程把上半例题当成下半作业的替代，部分小问只剩答案。模式只决定内容范围；每份 HTML 都采用交互、模型、必要解释的呈现顺序，原题与自编示例分别覆盖。

| 指令 | 概念学习范围 | 原题解题范围 |
| --- | --- | --- |
| `bgct`（默认完整讲解） | 按对象组织七个教学环节；作业提供问题背景，概念单元可以独立学习 | 按原题与小问顺序，全部提供题面、方法依据与完整推导 |
| `bbct` | 按板书顺序解释，保留教师记号与课程边界；板书中的公式与判准仍有完整示范 | 全部覆盖作业，板书缺少的知识点按对应考纲补充 |
| `olct` / `onct` | 只提供本题必要的公式、条件、定义与记号；省去背景章节、历史与拓展例题 | 每个小问保留完整推导，回接必要公式卡；采用考纲范围内的方法 |
| 任一模式加 `plustts` | 页面范围跟随前面的模式 | 额外交付按内容与活动阶段对应的伴读文字，见 `narration-tts.md` |

普通模块读题适用于所有模式；是否带 `plustts` 仅决定额外伴读稿。

## bgct 的七个环节承载不同学习动作

七个环节是内容覆盖关系，页面可用模块、模型、短说明表达；禁止把每个环节展开成一篇文章。

| 环节 | 内容与呈现 |
| --- | --- |
| 具体缺口 | 给已经具有必要前提的读者一个具体问题；通过预测或操作观察现有办法缺少什么 |
| 来历 | 用两三句交代有出处的人物、问题与贡献；资料没有核实时保留已知动机，不编造历史 |
| 构建 | 用模型与因果步骤从已有前提建立公式；每次变换解释依据；对象出现后再准确命名 |
| 完整示例 | 独立于作业的完整例题，承担主要教学分量；给题面、作答机会、完整推导与反馈 |
| 另一种看法 | 简短比较另一种表征、推导或有出处的观点，说明具体差异 |
| 适用边界 | 用反例、条件切换或变式说明何时成立；有出处的批评简短交代 |
| 回到任务 | 明确链接对应原题小问，具体解题留在原题区域 |

概念推导与完整示例承担主要学习时间。历史和观点不会挤占模型与解题。给定题目移出后，概念单元仍有独立的对象、模型与示例。没有作业的概念请求，最后一个环节以新情境迁移检查收束。

自编例题交代情境、给定量、单位、取值范围、问题与适用的分值；与原题区别需要落在情境或结构上，只更换数字仍会泄露作业路径。考试练习参考对应官方真题的表达、难度和考场条件，不把自编题标成真题。保留已给原题的选项数量；四选一是新概念检查的默认形式。

## bbct 按材料与考纲补齐

板书长图先按顺序读取，使用可用的 `classin-whiteboard-notes` 处理分片与重叠；不清楚的记号回到原图核实。按教师顺序解释每项内容；已有例题直接解释，例题与作业重合时再补独立示范。板书仅作为 `bgct` 指导材料时，沿用板书记号和学习范围，章节仍按概念对象组织。

板书未覆盖作业时，先从题面识别科目与单元，读取本包考纲参考并核实相关官方条目，将缺少的条目作为补充板书。只有作业而没有板书的 `bbct`，整份采用此流程。每个小问都能对应板书内容或补充的考纲条目。背景与另一种观点只保留板书涉及的范围。

数学与统计使用对应 Edexcel 记号，经济使用对应 CIE 9708 口径；TMUA、S2、经济的题型与考场规则按官方材料核实。跨领域请求保留同样的前提、模型、示范、完整任务解释；用户未指定考试时不强行套入某个考试局。
