# 数学里互相冲突的读法

配合 `../SKILL.md` §1.7 的第⑤幕（另一种看法）与第⑥幕（边界与批评）。
这份文件对应每日简报 `references/解释工具.md` 里那张「配对学派表」，
用法也一样：**每一行是一对看重的地方不一样的说法，两边都要能教。**

数学课本把结论写成没有争议的样子，这是教材的体例，与那些结论当年
怎么被吵出来的没有关系。**吵过的地方正是本质所在**，因为一件事只有在
有人反对的时候，它的边界才会被说出来。

每一行里六样东西在稿子里都要出现：**学派名、代表人物、代表著作与年代、
它从哪来、一个经典例子、一条有名有姓的批评。**
经典例子那一栏最要紧，它跟当天的作业题毫无关系，正好拿来讲透主张本身。

**查不准的条目就别写进稿子。** 看起来合理的年份、书名、人名一个也别添补，
拿不准写「未能核实」。下面这些我按印象写的年代与书名，用之前值得再核一次。

## 一、概率是什么

| | 甲方：频率派 | 乙方：主观概率 |
|---|---|---|
| 人 | 冯·米泽斯（Richard von Mises），奥地利 | 德·菲内蒂（Bruno de Finetti），意大利 |
| 著作 | 1919 年论文；1928 年《概率、统计与真理》 | 1931 年《论概率的主观意义》；1937 年《预见：它的逻辑法则、主观来源》 |
| 从哪来 | 他要把概率变成一门像力学那样的经验科学，对象是可以无限重复的试验 | 他要回答「明天下雨的概率」这类不能重复的事情，频率派对这种问题说不出话 |
| 经典例子 | 一枚硬币抛无穷多次，正面的相对频率趋于一个极限，那个极限就是概率；他把这样的序列叫作 Kollektiv | 荷兰赌（Dutch book）：你若给出的赔率不满足概率公理，我就能设计一组赌注，无论结果如何都稳赚你的钱。**概率就是你愿意接受的赔率** |
| 批评 | 维尔（Jean Ville）1939 年的博士论文证明，冯·米泽斯定义随机序列的办法挡不住某些系统性押注策略 | 批评者指出主观概率约束不了两个人给出完全不同的数；德·菲内蒂用可交换性定理回应，说观察够多之后两个人会收敛 |

**两边差在哪**：同一句「这枚硬币正面朝上的概率是 0.5」，一边说的是一个客观的
极限频率，一边说的是我愿意以 1 赔 1 下注。**对不可重复的事件，一边不发言，
一边照常给数。** 他的 S2 课本从头到尾用的是频率派的语言。

## 二、假设检验那一套是谁的（S2 直接相关）

| | 甲方：费希尔的显著性检验 | 乙方：奈曼-皮尔逊的假设检验 |
|---|---|---|
| 人 | 罗纳德·费希尔（R. A. Fisher），英国 | 耶日·奈曼（Jerzy Neyman）与埃贡·皮尔逊（Egon Pearson） |
| 著作 | 1925 年《研究工作者的统计方法》；1935 年《实验设计》 | 1933 年《论统计假设最有效检验问题》 |
| 从哪来 | 洛桑农业试验站，他要从田间试验的数据里判断一个处理有没有效 | 他们要把检验写成一个能给出保证的决策程序，用在工业抽样验收这类反复进行的场合 |
| 经典例子 | 女士品茶：一位女士声称能尝出奶茶是先倒奶还是先倒茶，费希尔设计了 8 杯的试验，算出她全猜对的概率是 1/70 | 两类错误、功效、拒绝域：一批零件抽检多少个、判多严，取决于把误判的两种代价各定成多少 |
| 批评 | 奈曼批评 p 值不带长期错误率的保证，单看一个 p 值说不出这套做法用一辈子会错多少次 | 费希尔 1955 年《统计方法与科学归纳》反过来说，他们把科学推断降成了工厂车间里的验收程序，科学家面对的是一次性的推断，不是流水线 |

**两边差在哪，以及为什么这一行值得单独讲**：
**课本上那套程序是两边缝起来的。** 「设 H₀、算检验统计量、跟显著性水平比、
拒绝或者不拒绝」里，H₀ 与 p 值来自费希尔，H₁、显著性水平 α、
「拒绝 / 不拒绝」这套措辞来自奈曼-皮尔逊。两个人当年吵得很凶，一辈子没和解。
**S2 那套程序读起来像两种语言，因为它本来就是两种语言。**
知道这一点，他就不会再把「为什么是 5%」当成一条需要背下来的规定。

## 三、连续情形下「随机」指什么

| | 甲方：几何概率 | 乙方：测度论概率 |
|---|---|---|
| 人 | 布丰（Buffon）、拉普拉斯 | 柯尔莫哥洛夫（A. N. Kolmogorov），苏联 |
| 著作 | 布丰 1777 年《道德算术试论》 | 1933 年《概率论基础》 |
| 从哪来 | 十八世纪的人拿几何图形上的长度、面积比当概率用，直觉上很自然 | 贝特朗 1889 年《概率演算》里那条弦逼出来的：同一句「在圆里随机取一条弦」，三种都说得通的算法给出 1/2、1/3、1/4 三个答案 |
| 经典例子 | 布丰投针：针长 ℓ、平行线间距 d、ℓ ≤ d 时，压线概率是 2ℓ/(πd)。历史上第一次有人用概率去量 π | 先指定一个测度，再谈概率。「随机」这个词本身没有含义，含义由那个测度给出 |
| 批评 | 贝特朗悖论指出「随机」在几何里根本没定义 | 杰恩斯 1973 年《The Well-Posed Problem》主张最大熵原理能从对称性里挑出唯一的那一个答案，测度论把这个问题推给了使用者。这一处分歧到今天还在 |

**两边差在哪**：一边认为「均匀」是一件不言自明的事，一边认为它必须先被指定。
连续随机变量那一章的全部记号（密度、cdf、积分）都长在乙方那一边。

## 四、无穷小算不算数（微积分那一章）

| | 甲方：无穷小 | 乙方：极限 |
|---|---|---|
| 人 | 莱布尼茨、欧拉 | 柯西、魏尔斯特拉斯 |
| 著作 | 莱布尼茨 1684 年那篇微分法论文 | 柯西 1821 年《分析教程》；魏尔斯特拉斯 1860 年代的 ε-δ |
| 从哪来 | 他们要算切线与面积，手上的工具是「一个比任何正数都小、又不是 0 的量」 | 十九世纪的人要把分析建在能经得起追问的地基上 |
| 经典例子 | dy/dx 当成两个无穷小量真的相除，分离变量法之所以「可以把 dx 乘过去」，来源就在这里 | ε-δ：说「趋于」的时候，说的是给定任意 ε 都能找到 δ，从头到尾没有出现过无穷小 |
| 批评 | 贝克莱主教 1734 年《分析学家》嘲讽这些量是「已逝之量的幽灵」：它既不是 0（可以做分母）又是 0（可以丢掉），这不成体统 | 罗宾逊 1966 年《非标准分析》给无穷小造了一套严格的地基，证明莱布尼茨那套写法本身没有毛病，只是当年缺一个说法 |

**两边差在哪**：他在课本上被要求「dy/dx 是一个整体，不是分数」，
转过头分离变量法又让他把 dx 乘过去。**两句话来自两个不同的年代。**
这一行讲清楚，那个长期的别扭就消掉了。

## 五、积分是什么

| | 甲方：黎曼积分 | 乙方：勒贝格积分 |
|---|---|---|
| 人 | 黎曼 | 勒贝格（Henri Lebesgue），法国 |
| 著作 | 1854 年的就职论文 | 1902 年的博士论文 |
| 从哪来 | 他要给「积分」一个不依赖原函数的定义 | 黎曼那套在很多函数上失效，而且取极限时不好用 |
| 经典例子 | 把定义域切成小段，每段用一个矩形近似，加起来 | 勒贝格自己的比喻：数一堆钱的时候，黎曼是按拿到的顺序一张张点，他是先按面额分成几堆再数。**一个按定义域切，一个按值域切** |
| 批评 | 狄利克雷函数（有理点取 1、无理点取 0）在黎曼那里不可积 | 学起来抽象得多，A-Level 与本科前两年都不教；工程上黎曼够用 |

**两边差在哪**：他学的是黎曼那一套，而概率论建在勒贝格那一套上。
连续型随机变量里的 ∫ f(x) dx 严格说是勒贝格积分，两者在他遇到的函数上一致，
所以课本不提。提一句，他就知道自己站的地面比看上去大。

## 六、期望这个概念从哪来

不是一对冲突，是一条来历，第②幕常用。

- 1654 年，帕斯卡与费马通信讨论「分点数问题」：一局赌到一半被打断，
  赌本该怎么分。他们的答案是按各人**将来可能赢**的机会分，
  而不是按已经赢了几局分。
- 1657 年，惠更斯《论赌博中的计算》（*De ratiociniis in ludo aleae*）
  把这个东西摆到全书中心，用的词是 *expectatio*。
  **这是概率史上第一本印出来的书，而它的中心概念是期望，不是概率。**
- 所以 E(X) 的本义是「一场赌局现在值多少钱」，
  「平均值」那个含义是后来长出来的。
