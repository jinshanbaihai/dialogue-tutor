# DialogueTutor 2.0 修改与评审记录

日期：2026-09-12。范围：skill 生成规则及其配套运行组件、可重建样例和导入包。目标为交互优先、模型联动、外行可懂的行行理由、TTS 读题与新的视觉设计。

## 主要改动

| 修改前 | 修改后 | 原因 |
| --- | --- | --- |
| SKILL.md 162,264 字节，混合规则、模式和历史补丁 | 主入口7,196字节，模式与详细教学按需读取 | 降低每次入口加载量；实际总读取量仍取决于课程范围 |
| 长篇讲解先写，交互后插入 | 先设计读者动作与模型，将理由放进步骤和反馈 | 让交互承担教学过程 |
| 新活动来源只接受 DeepTutor | 保留旧schema，新增 provider/HTTPS URL/mechanism | 支持官方核实的其他教学产品机制 |
| 普通HTML没有活动语音 | 所有活动提供读题、暂停、继续、停止、调速；默认1.5× | 普通页面也支持听觉辅助；plustts继续承担完整伴读 |
| 偏黄纸张底、棕色强调 | 中性浅灰白/石墨暗色、蓝色强调、语义反馈色 | 采用用户指定的Emil/Apple设计方向 |

主入口缩减约95.6%，这是字节口径，不宣称后续生成token固定减少95.6%。没有复制私有skill全文进入公开包。

## 第一轮：规则保留与冲突审查

| 意见 | 严重度 | 复述、核实与处理 |
| --- | --- | --- |
| 旧“正文先行”、文字层固定先行、追问零工具会抵消新顺序 | Critical | 核实原§0.5/§1.6/§4后采纳；替换入口流程，行行配方允许模型承载；普通追问按具体断点使用工具 |
| 中英并列及外部文风优先可能覆盖英文术语 | Critical | 采纳；入口、对话细则与依赖调用约定统一English术语+中文解释，保留英文原卷 |
| 每活动TTS与plustts容易混为一项 | Critical | 采纳；全部活动挂载语音工具条，完整伴读仍独立按后缀交付 |
| 旧正面示例存在多等号、依据仅写规则名称 | Critical | 采纳；concept-teaching与problem-solving示例展开独立变换，说明本题条件与前后继承 |
| 模式、六项题解、原题保真、完整伴读、学习证据与审读应保留 | Important | 逐项迁移到明确引用；未把细节截成摘要；仅替换与新版冲突的呈现约束 |
| 旧固定颜色词典与伴读字符倍率增加冗余 | Important | 采纳；颜色跟随实际页面，伴读按学科信息覆盖检查，不再设固定倍率 |
| 历史规则混入常规读取、跨节引用失效 | Minor | 历史交给版本控制；入口保留旧编号→新文件映射；本地Markdown链接检查无缺失 |

上述意见没有未处理的Critical。用户明确要求优先于外部skill的一般性约定。

## 第二轮：独立代码审查

评审者只接收产物路径、任务要求与检查范围，不接收作者结论。初始审查未发现Critical，发现以下问题：

| 原意见 | 严重度 | 核实与修改 |
| --- | --- | --- |
| 暂停后停止或切换，下一次读题可能永久静音：cancel/speak不改变全局paused | Important | 采纳。模拟引擎增加paused/queue/current状态，新测试修复前两项失败；新播放执行清空队列、解除暂停、加入新utterance，避免恢复旧内容 |
| MathML逐节点拼接丢失分数与指数关系，忽略aria-label | Important | 采纳。当前可见math使用完整aria-label口播，先检查隐藏状态；分数、指数、隐藏父节点和关闭details加入测试，样例公式增加口播标签 |
| S2 SVG固定浅色值在深色背景对比偏低 | Minor | 采纳。改为var(--accent)/var(--gap)/var(--ok)，使用已有深色主题值 |

定向复审仅检查上述意见及对应修改，不重审全文；结果见本记录末尾。

## 独立前向试用

新的代理只接收skill路径与原创长方形题目，按olct制作课程数据和HTML。产物保存在 `examples/rectangle-perimeter.json`，由 `scripts/build_demo.py` 生成 `docs/interactive-first.html`。

范例包含二维逐边模型、四选一、原题输入、9步推导、完整解答和迁移题。主代理对最终生成HTML执行jsdom检查：5个TTS入口；模型四边、后退与重置；错误反馈与重试；原题4 cm通过；9步导航与重置；运行错误0。几何核算为6+4+6+4=20，迁移题8+5+8+5=26。
