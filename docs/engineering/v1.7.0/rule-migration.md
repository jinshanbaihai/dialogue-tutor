# 从 1.6.0 到 1.7.0 的规则迁移

改造基线为用户附件中的公开技能 1.6.0，与仓库固定提交一致。旧入口全文保留在 Git 历史中；本轮没有访问作者本机正本或不存在于附件的私有关联文件。

| 旧规则或已见问题 | 新落点与行为 | 依据与验证 |
| --- | --- | --- |
| 保留整篇讲解后插入活动；固定七幕和字数地板 | SKILL 先生成目标与活动蓝图，studio 一次显示主要任务，完整解释按需展开 | 用户明确优先级；教育与色彩结构审查；实际 HTML 首屏与目标证据检查 |
| steps 推导播放可被误当步骤补全 | teaching-design 要求学习者提交的真实补全，例题、补全与独立题使用不同材料 | B2 渐隐研究及适用边界；目标活动矩阵、真实输入与原答 |
| 主动预测可能使用立即揭示答案的 quiz | engagement-and-narrative 区分即时核对与延后探索；自定义组件冻结原预测，再操作揭示 | 游戏和教育联合意见 G1/P1；预测一致/不一致/恢复检查 |
| 挑战—反馈停留在标签；错误后只看长文 | 作者蓝图记录选择后果、新增判断和停点；反馈给可执行修复，pathways 指向实际活动 | 游戏 G2、叙事 I3；错误、提示、正确和跳过路径 |
| 当前记录未自然形成收束与再次学习入口 | 作者收束活动读取真实记录；具名挑战与真实复习 item 的导航 | 游戏 G3、叙事 I1；三类结尾和受控复访 |
| 混用颜色、填色不能单独辨识概率事件 | 一套明暗语义 token；函数/比较/参数分色；事件轮廓和裁剪端点形状 | 色彩专家、W3C 对比度与图形要求；真实浏览器截图与数值 |
| 闪卡先看关联全解后仍记无辅助 | 运行库保留整组卡片对应的全解接触；翻面前的回忆辅助身份被冻结 | 教育 P2 独立反例；卡片、近期接触、到期复习与导入测试 |
| 分支文本将 assisted 误写为辅助答对 | 明确它是求助/参考接触建议；incorrect 可含注明来源的负自评；只有客观独立正确走 correct | 教育 P3；真实 API 事件和显示标签 |
| 兼容样章中循环依据、公式回指、对称期望及积分理由缺口 | 定点修正 source，保持与 JSON 题解一致 | 教育内容对照及 P4；原页面重建回归 |
| 主入口依赖多份本机规则，核心合同淹没在长文中 | 短入口按任务读取教学、模式、运行、视觉、参与和专家参考；运行资源随包提供 | 独立生成者只接收完整技能包和真实请求 |
| 研究结论、界面选择与模型模拟混在一起 | learning-evidence 保留旧核查层级，新增 B1–B3；明确研究边界、工程参数与真人效果 | 教育定点证据复核；本轮不声称用户已经保持或迁移改善 |

每个新阶段都可以查看解释、跳过与返回。交互优先表示先设计有数学后果的动作，不表示禁止文字，也不把点击数量作为掌握证据。旧 document 数据与 `--base-html` 保留兼容；旧示例不再指导新课程布局。
