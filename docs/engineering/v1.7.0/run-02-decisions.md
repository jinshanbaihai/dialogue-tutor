# 第二次生成中发现的接口缺口

2026-09-08。本轮在课程生成阶段中止，没有 HTML 成品。完整草稿和最小复现保存在 `runs/run-02/`；不能把15项活动的蓝图写成15项已经通过验证的活动。

独立生成者和教育评委分别确认：`dt:restore` 传入 exploration 副本；在闭包中合并接触不能立即进入公共导出；改发 `dt:exploration` 会增加参与计数。用递归 `importState` 或另一份存储绕行，会把通用接口缺口转移给每份课程的作者。

主作者采纳这项 Important 工程意见。此前四位专家批准的是技能文本的定点修订；实际生成进一步暴露了支持该合同的接口不足，因此暂停生成，先完成下列公共修复及复审，不将原许可当作实现已完成。

教育学与游戏评委在实施前提出的条件包括：只接受 interactive、完整校验和深拷贝、同步写回、不派发递归事件、保持参与与评分字段、多组件不互相覆盖、导出及刷新保留接触、存储失败如实提示。主作者据此新增 `instance.restoreExploration(activityId,value)`；明确仅探索快照与保存元数据可变，存储失败时保留完整内存快照并可导出，不声称已经持久保存。

技能的交互参考新增实际接口、同步调用时序及返回值；专家参考加入立即导出、重新打开与多个组件的验收。新增3项集成测试覆盖这些真实风险，全部11项studio测试通过；完整Node回归66项、Python15项通过，原始输出另存。

修复后的技能再次由四位专家定点审阅。下一次使用新的无历史代理与空目录生成，输入仍只有当前技能与官方章节范围。第二次未完成的作者源不会作为新生成者的参考答案或布局范本。
