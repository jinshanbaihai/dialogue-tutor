1. **章目和教学内容对应真实范围。** 页面以第六章 Sampling and sampling distributions 为题，内容覆盖6.1总体与样本、6.2统计量、6.3抽样分布，没有将假设检验误作本章。总体、样本、抽样单位、抽样框和普查/抽样调查优缺点都有具体题面与解释。
2. **目标中的解释和应用有实际提交任务。** `frame-repair` 要求指出遗漏并修复；`survey-justify` 要求基于成本和测量条件选方案；`statistic-explain` 要求解释计算所需输入。它们保存原答，再由学习者按 rubric 自评，没有用关键词自动宣称理解。
3. **例题—补全—独立题是不同的数学任务。** `mean-worked` 使用 `{2,8}` 的完整四路径示范；`mean-completion` 在 `{1,3,4}` 上提交归组概率；`mean-independent` 在 `{0,4,10}` 上独立组织门槛事件；`max-distribution` 另收完整分布及过程。逐步显示不产生答对记录，最终数字相符也没有被宣称为推导每步正确。
4. **大多数预测与操作边界实际生效。** 首屏只有 `sampling-lab`；结果区隐藏、图内无结果节点、全解关闭。选择 `equal` 并冻结后仍未显示结果；程序化尝试改为 `centre` 也不能改写已保存预测。揭示才出现原判断与枚举结果的比较。
5. **图表数据与数学机制一致。** 六种 `n=1/2/3 × 有/无放回` 条件的路径数为3/9/27和3/6/6，实际表格与独立枚举一致。手选路径2显示 `(1+5)÷2=3` 且不增加B；控制随机数为0.9后抽1份得到C、C，均值5，B=1，只给该均值频数加1。手选被标为枚举，模拟频率与理论概率分别标示。
6. **错误、辅助、正确和跳过均有具名后续。** 核心补全题实际点击推荐后能到目标活动，记录保留原答案与来源；跳过不伪造错误尝试。查对应全解后答 `mean-independent` 的5/9会记为辅助；关联闪卡也保持 `source:self, assisted:true`。

### E1：旧记录导入让自定义预测丢失已看全解的事实——未解决

**位置。** 活动 `sampling-lab`；完整讲解 `#dt-explanation-opening-scene`；HTML L1733–1744 `initial/normalize`、L1906–1908冻结时的 `predictionHadReference`、L1923–1933恢复及 `toggle` 监听、L1838/L1855显示文案。

**实际输入与输出。** 核心日志 `reference-before-import` 和 `older-import-after-reference`：

1. 冷启动，导出本人当前尚未查看参考的状态。
2. 打开 `#dt-explanation-opening-scene` 并等待 `toggle` 事件处理。观察到自定义 `referenceViewed:true`，公共活动 `exposure.reference:true`，说明接触已成功记录。
3. 导入步骤1的原始导出，没有篡改JSON；随后选择 `centre`，点击冻结和揭示。
4. 导入后的公共运行状态仍是 `exposure.reference:true`，全解也仍然打开；但实验自定义 `referenceViewed:false`、该预测 `predictionHadReference:false`。

页面因此显示“实验结果尚由你的操作揭示；也可随时主动查阅完整讲解。”；比较显示“结果与本轮判断一致”，没有应该出现的“提交该判断前已看过参考，本轮不作为未接触答案的预测”。这是同一成品内部的状态冲突，不是对学习者是否真的阅读文字的推测。

**教育影响与裁定。** 主动获得参考是允许的，问题是恢复之后漏记这一可观察接触，导致新判断的证据条件被错误表述。违反H4“漏记辅助”及技能已通过的“如实显示已经获得参考”。本次未发现它生成客观正确分数；不能把缺陷升级描述成已经伪造客观掌握，但预测的证据来源仍必须准确。

**补充边界。** 新探针 `repeat-known-conditions-after-observation` 还显示：直接观察默认条件→新一轮但保持同样条件→选择 `centre`，历史正确保留上轮已揭示，同轮 `predictionHadReference` 仍为false，也没有已见相同结果的区分。这不等于历史被删除，也没有另授分数；它提示接触配方不能只关注“打开全解”这一来源。

**应先写回技能的修复配方。** 在 `interactive-html.md` 的自定义组件/恢复规定及 `engagement-and-narrative.md` 的预测时序中加入可实现的要求：自定义预测初始化、恢复和冻结时，将公共活动接触记录、当前已打开的关联解答及本组件已发生的相关结果揭示统一核对；不能仅相信导入对象中的布尔值或等待下次 `toggle`。导入旧存档不能清除当前会话已发生的参考接触；历史中同条件已揭示的结果需要标成已见后的再判断。新题/新参数应按实际覆盖范围判断，不能把无关参考一律连带标记。预测冻结时保存当时的条件，后看全解不能倒改此前已经完成的原预测。

**关闭证据。** 下一轮实际HTML须重跑“未看参考导出→看全解→导入旧记录→新预测”，在全解仍开、先关再导入、刷新恢复及同条件新一轮中保持真实接触；同时验证预测后才看参考不倒改原预测，尚未见过结果的冷启动预测仍保持该身份。

| 受控七日后真实回访入口 | `NOW+7×86400000+1` 进入后输入为空、答案关闭；再答5/9的第二次尝试 `assisted:false`，`intervalIndex`由0变1，按已有规则安排三日后。它是同题回忆程序测试，不是七日真人保持或新题迁移 |
