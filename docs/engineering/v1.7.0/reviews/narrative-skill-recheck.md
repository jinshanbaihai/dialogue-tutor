## Important：逐字保留原项标题并定点复核

### I1：流程已有挑战与结果，生成合同却没有要求二者通过学习者原判断形成呼应

**实际改动。** `SKILL.md:25` 要求章节或讲述任务读取新增参考，并把选择后果、结果呼应和递进写入蓝图。`engagement-and-narrative.md:11` 补齐“当前需要、一个可回答的悬念、影响数学对象的选择、揭示时点与可见证据、对原判断的回应、具体下一行动”。`:13–17` 将字段进一步变成从问题到发现、使用与继续的配方。`:51` 明确开场问题由实际证据回应，正确与相反预测分别如实回应，未预测者不得被代言。

**我的复核。** 这已覆盖我原意见中的三处缺口：场景何以必要、结果何以承接本人动作、结尾怎样收住开场问题。正文没有要求每个小活动重复整套循环，既能产生推进，也保留数学推算的连贯性。`teaching-design.md:31` 对同构练习与迁移的区分、`:62` 对无效操作的限制仍然保留，新增叙事规则没有越过这些边界。

**裁定：I1 已解决。** 实际生成后仍须沿一条核心路径对照本人输入、可见证据与回应句；这属于既定成品验收，不构成本轮未解决的技能项。

### I2：探索验证型预测与普通 quiz 的反馈时序存在歧义

**实际改动。** `SKILL.md:37` 已把探索预测限定为未评分、自定义 interactive 保存阶段与历史，普通即时反馈 quiz 只用于提交即验证。`interactive-html.md:106–109` 删除了原先“预测 quiz 或自定义记录，再另行揭示”的含混合同。新增参考 `:23–24` 明确两种时序；`:26–28` 列出阶段、草稿、冻结原预测、时间、历史、参数及恢复要求；`:30` 将泄题检查覆盖标题、lead、图形初态、默认选项、按钮、可访问文字和前行伴读，并保留主动查看全解的权利。

**我的复核。** 普通 quiz 提交即给参考的约定仍在 `interactive-html.md:126–128`，现在与延后揭示型探索明确分开，因此原矛盾已经消除。参数变化和重置不能改写原判断，且预测不冒充独立正确证据。作者可以在现有 interactive 的自定义状态合同内实现这些要求，不需要猜测一个不存在的预测评分组件。

**裁定：I2 已解决。** 下一轮实际 HTML 需验证提交前、提交后未揭示、主动揭示和恢复这几个状态，以及查阅全解后的如实标识；本轮没有运行页面，不作这些行为已经通过的声明。

### I3：错误反馈有诊断原则，缺少让学习者恢复行动的情绪配方

**实际改动。** `engagement-and-narrative.md:36–43` 按真实记录分别处理独立正确、辅助正确、可诊断干扰项、原因未知的数值错误、跳过及仅探索。`:45` 限定修复后的具体肯定必须有记录支持，没有过程证据则用中性参考说明，也不预设所有学习者都曾预测错误。

`interactive-html.md:229` 的最小示例已由单纯命名混淆，改为“先比较高度 2、宽度 0.5 的矩形：面积等于多少，再判断概率条件约束哪个量”。这给了可以立即心算的局部检查；它没有承诺示例里不存在的图形控件，也没有把数字错误直接诊断成人的能力问题。

**我的复核。** 原意见要求的是“已观察差异—可执行检查—修正后的如实回应”，现在已落入具体生成表，而不是只增加鼓励语。辅助和跳过也有可进入的后续任务，情绪上的继续与证据来源的准确性同时得到保留。

**裁定：I3 已解决。** 成品抽查时继续使用一项可诊断错误、一个未知原因的错误数值、提示后正确和跳过，核对局部检查确实可执行及后续回应不虚构进步。
