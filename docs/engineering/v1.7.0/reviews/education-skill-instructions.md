## Important

### I1：逐目标的能力证据要求不够明确——已修订并关闭

**初审观察。** 初版候选入口要求逐目标蓝图，但没有明写：活动与目标 ID 对应，并不足以保证活动测到目标能力。基线已经存在 CDF 解释目标只连接翻卡、步进和探索的实际实例。我的意见针对这条生成规则的空缺，不声称尚未生成的新 HTML 已再次失败。

**我的修订要求。** 需要独立解释或应用的目标，必须有相应的真实提交任务；schema 的活动覆盖只是结构下限，语义仍由蓝图与专家评审。开放题可以形成原答与自评证据，不能因此宣称自动判定独立正确。

**实际修改与复查。** `teaching-design.md` 新增“目标对应的证据下限”（L18–23），逐项包含以上要求。我确认它现在可以否决“列了概念目标，却只挂滑杆”的课程蓝图，同时没有要求所有目标都用同一种题型。

**关闭条件已满足。** 后续全包检查验证每目标至少绑定活动；课程评审验证目标中的解释、计算、比较或迁移要求是否由对应任务承担。这两个关卡不互相替代。

### I2：渐隐补全缺少真实 schema 实现配方——已修订并关闭

**初审观察。** 初版候选要求渐隐补全，但 `interactive-html.md` 的 `steps` 只有标题、正文与前后步，没有缺失步骤输入。虽然文件正确说“下一步不计答对”，生成者仍缺少把补全任务落实为接收原答组件的直接配方。

**我的修订要求。** 明确 `steps` 用于示范；补全另用实际接收答案的 quiz。至少给一条完整例题、另一题补全、独立新题的 ID/类型关系，并保留自评与客观判定边界。

**实际修改与复查。** `teaching-design.md` 新增“渐隐路径的实际组件配方”（L36–50）：`mean-worked` 是 `steps`；`mean-completion` 是不同数据的 `quiz/numeric`，必须实际提交；`mean-independent` 是再换数据的 `quiz/open`，自行组织方法并保存原答。`interactive-html.md` L124–128 同步说明补全必须另设接收提交的 quiz，不能重命名 steps 代替。

**关闭条件已满足。** 配方已映射到现有 schema，不需要虚构运行时能力。示例说明的是组件角色；实际 CH6 仍须按抽样分布目标安排缺步，例如补样本分组、概率权重或条件判断，不能仅用算平均数替代整章程序证据。

## 下一轮需要的实际证据

我批准这些指令进入后续阶段。全包与新 HTML 的教育评审仍将核对以下事实：

1. 目标蓝图包含来源、先备支持、活动身份、对应证据、具体分支和全解位置；概念与程序目标都有相应产出。
2. 从空白状态进入课程，首次动作可完成，未先显示待判断结论；不熟悉前提时有直接可用的示例。
3. 预测真实提交并冻结，补全真实接收答案；正确、错误、辅助、跳过均有可执行后续，同时允许自由查阅和返回。
4. 独立新题与例题/补全在题目身份上不同，迁移说明新增判断，同题延迟保持不冒称新题迁移。
5. 全解、题面、反馈、图示与 TTS 的条件和结论一致；主动查看关联答案后再次作答仍保留辅助来源。
6. 记录刷新、导入导出、revision 与旧版兼容确实工作；页面行为检查不被包装成真实学习成效。
