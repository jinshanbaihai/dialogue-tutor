## 优点

1. **三个目标都有与能力相符的实际提交任务。** `survey-plan` 要求给总体、样本、单位、框和破坏性调查取舍；`statistic-check` 判断未知参数依赖，`without-replacement` 进一步提交理由及抽取前随机变量/抽取后观测值的区别；分布目标有数值计算和完整分布开放题。概念或解释目标没有仅靠探索次数认证。
2. **示例、补全、独立题和迁移有实质区别。** `{1,7}` 的均值完整示例之后，`{0,3,6}` 补一个归组概率；再用 `{1,4,9}` 的最大值自行构造完整分布、用 `{2,5,10}` 的极差求新事件概率。无放回题另外改变允许样本、基本结果概率与独立性。它们不只是换选项顺序。
3. **抽样机制和数学一致。** 12组允许实验条件的实际样本表、归组概率、路径及概率条宽度，与本评委按个体索引和精确分数独立枚举的结果逐项相符。无放回只保留允许路径；每条概率的乘法依据、统计量分布与单次观测区别都写明。本实验明确采用穷举，不把手选路径称为随机抽样。
4. **上一轮 E1 的恢复漏洞在本轮实际产物中关闭。** 全解保持打开及先关闭两种情况下，导入未看全解的原始旧档后，立即公共导出、实际 localStorage 来源和重新打开后的新预测均保留参考接触。恢复不增加探索计数、作答或参与标志。已见结果和原预测历史同样能即时写回与恢复。
5. **原预测、当前接触和本次揭示条件分开。** 冻结之前看全解，包括不等待 toggle 的立即提交，记为参考后判断；预测提交后才看参考，不倒改该条预测。旧档恢复后的同条件新预测标为已见结果，改为未揭示的无放回条件不误继承该结果接触。
6. **上一轮 E2 的收束虚构已经关闭。** 只点揭示时，收束说明没有原预测、没有主动选路径，默认展示不算本人计算。主动选择路径只记为选择查看。仅辅助数值正确、自评达到要点和客观独立正确保持各自来源；完成数值核对没有被称作已经证明完整推导。
7. **实际后续入口能承担相应任务。** 错误、辅助、独立正确和跳过分支的真实按钮分别到达具名活动；错误与跳过没有混成同一种尝试。极差回顾入口能区分初次任务、未完成草稿、提前练习和到期回顾；真正回顾收起旧答案并保留历史，普通浏览保留原答。
