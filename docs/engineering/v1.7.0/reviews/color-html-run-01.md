## 已落实的优点

1. **实际自定义组件延续同一套冷白、墨蓝与铜橙。** HTML 第 7–40 行和第 371–395 行提供明暗 token；页面底色、任务面板、实验选择器、总体标签与反馈框都引用这些 token。自定义 `bodyHtml` 没有另造十六进制正文色、图底色或卡片主题。图的透明背景最终落在 `.dt-scene` 的 `--dt-surface` 上，不会在暗色中留下白色图块。
2. **图中文字没有退回默认黑色。** 第 1807、1816、1818 行的概率刻度、均值刻度和轴名都显式使用 `fill: var(--dt-ink)`。第 1806 行使用 `--dt-control-line` 画概率基准线；理论柱使用 `--dt-plot-function`，与技能中的理论分布身份一致。
3. **选中对象有色相以外的提示。** 第 1815 行给当前路径所归入的柱添加 2 SVG 单位的 `--dt-ink` 轮廓，其他柱的轮廓宽度为 0。第 1867 行还明确写出当前样本、计算式及均值，并说明这是非随机的枚举定位。不能只凭铜橙与蓝色的色相差识别选中状态，但源码确实另提供了轮廓和文字。
4. **图宽适配容器，而非把固定大图持续缩小。** 第 1795 行以 `host.clientWidth` 重建 viewBox；第 1921 行用 `ResizeObserver` 响应尺寸变化。图字为 16 SVG 单位，常见视口下预计约为 16 CSS px。它没有继承旧样章双图仅约 10.74px 的缺陷。
5. **控件值在冻结后仍有明晰读性。** 自定义选择器使用 `control-line` 边界、16px 字与至少 44px 高度；禁用选择器明确使用 `opacity: 1`、`ink` 与 `surface2`。原预测和抽样条件没有因禁用而一起淡出。小屏在 520px 以下改为单列控制区。
6. **长讲解和工具没有重新套住主图。** HTML 第 315 行取消 studio 活动的内层边框、阴影和 padding；第 318–322 行允许 `.dt-custom` 使用舞台宽度。完整讲解是具名的关闭 `details`，工具位于关闭的“学习工具”入口。蓝图中“首次预测后再揭示分布”的呈现次序也落实为结果区的 `hidden` 状态。首屏最终占比仍须真实截图确认。

## Minor

### M1. “铜橙色轮廓”与实际填充、轮廓身份不一致

- **输入与位置：** `lesson.json` 第 226 行，`activities[id=sampling-lab].bodyHtml`，图前说明“铜橙色轮廓标出当前所选路径归入的位置”；实际绘制位于 HTML 第 1815 行。
- **观察：** 所选柱的 `fill` 是 `--dt-parameter-a`，`stroke` 是 `--dt-ink`。因此铜橙对应柱面，不对应轮廓。浅色轮廓是深墨色，深色轮廓是浅色。第 1867 行的“带轮廓的铜橙色柱”才与实现一致。
- **影响：** 不改变概率、路径或实际可辨认位置，但会让学习者寻找一种并不存在的铜橙轮廓，损害图文对应的准确性。
- **裁定：** Minor，确认成立，当前未关闭。应在规则修订后的重新生成中统一图文描述；无须因此替换已经合格的色值。按冻结方案不能直接手改这份 HTML 后宣称同一轮生成通过。
- **若启动修订，先补的可复用技能条款：** “为自定义图形描述颜色、轮廓、填充或线型时，逐项核对实际绘制属性及明暗主题；图例、就地说明和动态反馈必须指向同一对象。不要把填充色称为轮廓色；非颜色辨认线索也必须真实存在。”该条款面向所有图形，不要求未来生成器照抄本课件布局或题面。
