# DialogueTutor run-01：叙事与情绪感染成品评审

评审日期：2026-09-08。评审身份：承担编剧、叙事与艺术创作视角的模型评委，不声明真人职业认证。此前叙事技能评审与复审已通过；本次评审对象是固定 `generation/run-01/lesson.html`、`lesson.json`、`blueprint.md`，不是对作者自查声明的转述。

## 已成立的优点

1. **开场需要简短而可回答。** `sampling-lab` 用 A=1、B=3、C=5 的微型总体提出“均值3与均值1哪个更常见”，抽样条件在题面给足。情境没有另造角色危机，也没有为了反转修改有放回、均匀抽取和样本量。它把章标题转成了学习者可以先作判断的问题。
2. **默认条件下，判断与发现确实连接起来。** 实测选择 `centre` 或 `equal` 后冻结，结果区仍隐藏、预测控件锁定；点击“枚举样本，检查预测”才得到 `1/3` 与 `1/9`。前者得到“一致”，后者得到“不同”，并获邀定位、比较路径。没有对所有人都说“没想到吧”。
3. **可操作证据有内容。** 揭示后选择有序样本 AC、BB、CA，实际 trace 分别给出 `(1+5)÷2=3`、`(3+3)÷2=3`、`(5+1)÷2=3`，SVG 中对应均值的柱由当前路径决定。原预测时间未被这些选择改写；手选明确标为“枚举定位（非随机）”。在叙事上，这为“不等可能怎样形成”提供了可追踪的对象，而不只是一句答案。这里确认的是 DOM、运算和 SVG 属性的响应，没有作截图美感结论。
4. **错误后有可继续的局部任务。** `population-check` 选择 `frame` 得到“这组把目标总体和实际清单对换了”，随后要求指出目标工单数和实际清单，按钮可进入 `frame-repair`。`mean-completion` 输入 `1/9` 后参考要求核对两个顺序；提示后改为 `2/9` 保留辅助身份，并能进入另一道 `mean-independent`。反馈没有用人格评价代替修复。
5. **辅助、跳过与独立证据多数被如实保留。** 不预测者在实验中被告知没有原预测；`frame-repair` 暂时跳过不会被计作答错。提示后正确与随后新题首次正确的记录不同，收束列表能分别显示辅助尝试和独立客观核对。未做实验直接到结尾，也没有被宣称完成全章。回访无记录时的入口实际进入 `return-recall`，先出现第一张卡正面。
6. **推进指向新要求。** 实际按钮“换数据独立算事件概率”“改为无放回后重新计算”以及“相同数值、不同个体”都有对应目标。完整例题、局部补全、独立事件计算、改变机制与保留个体标签构成可辨的递进。对用户“交互＞可视化＞文字”的要求，开场已有互动驱动证据的基础；下面的退回项主要是讲述越过了实际动作和结果，不能靠增加鼓励文字补偿。

## Critical

**本轮未发现已证实的 Critical 叙事缺陷。** 以下 I1 会虚构本人做过的具体数学动作，但没有生成一条假的客观通过记录，也没有宣称整章掌握，因此列为 Important。不能由“无 Critical”推得成品通过。

## Important

### I1：收束仅凭揭示结果，就称学习者已经完成映射和归组

**位置与原句。** 活动 `evidence-close`，`lesson.html:1948`；同一内容位于 `lesson.json` 的 `activities[id=evidence-close].script` 第13行：

> 你已经在实验中把一份样本映射为一个均值，再把同值的路径合并。

这句唯一的条件是 `lab.revealedAt`。`sampling-lab` 的揭示与直接观察事件只设置 `phase`、`revealedAt` 等字段；见 `lesson.html:1910`、`:1911`。初始 `selectedPath=0`，结果表与默认路径由程序自动构建。没有要求或记录学习者亲自提交均值映射、路径归组的答案。

**实际输入与输出。** 独立空白状态中，只点击 `sampling-lab` 的“不预测，直接观察”，随后导航至 `evidence-close`。没有选择有序路径、没有随机模拟、没有提交任何题目。保存状态是：`prediction=null`、`predictionAt=null`、`selectedPath=0`、`simulation.B=0`、`attempts=[]`。页面仍显示上述首句，接着说“最近一轮选择了直接观察，没有预测记录”。同页证据列表则正确写着“参与或查阅，尚无作答证据”。这是实际显示的自相矛盾，不是从代码猜测可能发生。

`prediction-matches`、`prediction-differs` 两路也在揭示后、尚未选择路径之前得到同样的首句。先查全解再揭示的路径同样如此。因此它不是未预测路径的孤立措辞问题。

**影响与裁定。** 收束要把刚发生的行动组织成可信的完成感，此处却把系统完成的枚举说成学习者完成的推理。`blueprint.md:62` 将“归组”写入学习者动作，`:63` 同时又承认探索只记录参与和预测；成品沿用了前者的动词，却没有后者所要求的证据边界。只给正确的辅助/独立列表，不能抵销首句的虚构。

该句也没有用最近一轮的条件、概率及比较关系真正回答开场问题，只重复预测并让学习者返回找依据。把“你已经”替换为“你看到了”只能修掉一半；收束仍应说清此次证据回答了什么。

**优先写回 skill 的修复配方。** 在 `engagement-and-narrative.md` 的反馈与收束配方中，要求作者先写“记录→允许称述的动作”表，并在蓝图中逐项核对：

| 实际记录 | 可以称述 | 不由该记录推出 |
| --- | --- | --- |
| 只有 `revealedAt` | 已打开/显示枚举结果；枚举表显示某种关系 | 本人计算、映射或归组成功 |
| 实际选择某条路径的记录 | 已定位该条路径，界面显示它对应的统计量 | 本人完成全部样本归组 |
| 一道数值题核对正确 | 该次提交的数值通过核对 | 本人必定用了某个未记录的推导方法 |
| 有实际映射或归组提交及核对 | 按记录具体称述完成的那一步 | 超出该任务的掌握或迁移 |

这些是作者证据合同，不需要假装已有新的运行时字段。若活动希望以本人归组形成完成感，就必须提供一个有数学意义、可记录和核对的归组动作；若采用自动枚举，则保留自动枚举，使用中性证据陈述。不能为支持一句表扬追加无意义确认按钮。

收束按**当前轮条件＋已显示结果＋原判断身份＋实际下一行动**生成。例如在默认条件、仅直接观察时，可以写：“本轮有放回、n=2的枚举中，均值3对应三条路径，均值1对应一条，所以概率分别为1/3和1/9。本轮没有提交预测；可在‘补全一次归组概率’中独立合并路径。”这只是技能配方示例，不能硬编码到 n=1 或其他条件。已看参考者保留其接触身份；预测一致和不一致者据本人原记录补相应呼应。

**复查要求。** 重新生成后，重走“只揭示”“直接观察”“先看参考”“实际完成目标动作”四种收束输入；逐句核对动词是否有记录。只揭示者不能再被称为已算出或归好。当前轮 n=1 与 n=2 的结尾应回答各自的比较关系，不把上一轮结论套入新一轮。

### I2：相等结果仍被讲成需要解释的“差异”

**位置与原句。** 活动 `sampling-lab`，`lesson.html:1854`；`lesson.json` 的 `activities[id=sampling-lab].script` 第133行。反馈只按“预测是否等于 truth”选择一段句子，没有按实际关系区分相等与不等。

**实际输入与输出。** 新状态将 n 改为1，保留有放回，选择 `equal`，冻结并揭示。页面实际显示：

> 枚举得到 P(均值=3)=1/3，P(均值=1)=1/3。结果与本轮判断一致。检查下方路径，找出这个差异怎样形成。

表格同时显示均值1、3、5各一条路径、各1/3。再从 n=2 的错误预测开始新一轮，改为 n=1，并作同一预测，同样复现。旧轮条件和预测保存正确，因此问题不在历史丢失，而在文案没有服从新条件的结果。

**影响与裁定。** “改变一个条件会怎样”是本核心活动主动继续的理由。学习者正确发现两者现在一样常见，页面却要求解释一个不存在的概率差异。这破坏了条件改变所带来的发现，也违背了正确预测应得到具体、如实支持的合同。数字表正确不足以消除讲述的矛盾，故本项列为 Important，而不只作措辞润色。

**优先写回 skill 的修复配方。** 生成回应前先由与图表相同的模型得到实际比较关系，再与原预测身份组合：相等时指向相同概率为何成立；不等时指向较多或较少的基本路径；不可能事件说明没有允许路径；之后才说该证据与本人预测一致、不一致或无法比较。不要用“一致/不一致”两句固定文案承担所有数学关系。

对本例，相等结果可要求“比较均值1和3各对应几条等可能路径”，不等结果再要求“比较多出的路径来自哪里”。这一要求应写入 `engagement-and-narrative.md` 的结果呼应配方，并在 `expert-review.md` 加入一个**改变条件后比较关系发生变化**的成品样本，而非只验默认题面的正误二选一。

**复查要求。** 默认 n=2、预测 `centre` 应说明较多路径；n=1、预测 `equal` 应说明相等依据。两路都检查表格、回应、下一问题与收束中的关系词，不能只核对数值或“预测一致”标签。保留现有新轮历史，不以重置原判断修正叙事。

## Minor

### M1：揭示时态与参考接触状态没有贯穿所有说明句

**实测现象。** `sampling-lab` 的 `data-lab-reference`（`lesson.html:1838`）在未查看全解时，一直显示“实验结果尚由你的操作揭示”，包括结果表与比较文案已经出现的状态。另一方面，先打开 `dt-explanation-opening-scene` 的完整枚举，再点击“不预测，直接观察”，`data-lab-comparison` 仍说“这是本轮首次观察，尚无预测可比较”。此时 `referenceViewed=true`，旁边又明确说“已查看本实验完整参考”。

**影响与裁定。** 参考身份本身确实被记录，没有由此产生独立得分，故列为 Minor。问题是同一屏幕对“答案是否已出现”的描述不一致，会削弱首次揭示的可信度。先看全解后再预测的分支已正确附加“本轮不作为未接触答案的预测”，应保留这一正确行为。

**写回 skill 的配方。** 所有“尚未、首次、已看、再检查”的语句均由阶段和参考接触状态生成。预测存在与否、预测提交前是否见过参考、当前是否已见结果是不同问题。未预测者只需如实说“未提交预测”；已经看过相关全解时，可说“现在把参考中的结果放到实验中检查”，不要再称首次看到结论。

**复查。** 只测三个实际受影响状态：冻结未揭示、普通揭示后、先开全解再直接观察。语句、可见结果与记录应一致；不改变主动查看全解的权利。

## 叙事评分（0–3）

评分是本模型对当前设计的专业判断，不是学习者情绪、学习效果或回访率的实测。0为关键结构缺失或失真主导；1为有结构但核心联系断裂；2为主要结构成立但有需修订处；3为在本次审查范围内连接完整、记录可信。

| 维度 | 分数 | 依据 |
| --- | --- | --- |
| 当前需要与可回答问题 | 3 | 抽样差异承担情境，条件明确，首个判断具体 |
| 预测保留与揭示时点 | 3 | 默认双预测冻结成功，结果延后出现，恢复及新轮保留原记录 |
| 行动、图示与数学发现的连接 | 2 | 路径定位与柱图有真实联系；自动枚举不能被当作本人归组 |
| 结果呼应与错误后的继续 | 2 | 默认双分支与辅助修复成立；相等结果误称差异，阶段文案有矛盾 |
| 讲述节奏与下一挑战 | 2 | 具名任务和条件递进成立；反馈主要靠参考解释，完成感仍需与真实操作更紧密地衔接 |
| 收束与本人证据的可信度 | 1 | 列表身份准确、入口存在；首句虚构动作，未用本轮具体关系收住问题 |

**总体：2/3，需修订；本轮成品不通过。** 评分不能抵销未解决的 Important 项。
