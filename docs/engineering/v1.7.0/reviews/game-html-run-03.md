## 优点

1. **选择确实改变数学对象。** 实验 `sample-lab` 在提交预测前不显示结果表。默认三张卡 2、4、8，放回抽 2 张，得到 9 条有序路径及 `P(均值≥5)=5/9`；点击改为无放回会开始新轮、保留原判断，变成 6 条允许路径及 `2/3`。选择 `(2,8)` 可直接追踪到均值 5、路径概率 `1/9`，不会把这次查看当作独立计算或随机模拟。
2. **悬念由证据兑现。** 预测“大于”和“小于”分别收到一致和不一致的准确回应，随后明确检查达到门槛的均值行及相应概率。关系相等时解释相等，关系较小时报告较小；收束使用当前轮条件与实际已显示结果，不把默认结论套到改变后的轮次。未预测和先看全解者都有如实的身份表述。
3. **继续的理由来自新要求。** 完整例题 `{1,7}` 的均值分布提供“路径→统计量→互斥概率相加”；`{0,3,6}` 补全要求找到均值 3 的路径；辅助后推荐的 `{1,4,9}` 新题改为最大值，要求完整分布、等可能依据和单次观测的区别。独立正确后的 `{2,5,10}` 极差题要求自行组织样本空间并筛选 `R≥5`。无放回挑战又要求排除重复抽到同一张卡、重定每条路径概率，并解释不独立、统计量定义及抽样前后的随机性。增加的是协调关系，不只是换大数字。
4. **修复与支持可执行。** 数值错误显示可检查的有序样本，不臆测学习者的错误原因；实际推荐按钮能进入完整例题。重试正确保留辅助身份，然后进入另一道答案关闭、输入为空的新题。跳过不记错，自由导航仍可用。
5. **完成感与回顾有可核查来源。** 只揭示的人没有被称作本人推导或合并过路径；主动查看路径、自评解释和客观数值核对分别记录。初次、提前、到期及未完成草稿入口均有真实去向；普通返回不冒称新提取，实际回顾入口先收起旧输入与答案，保留历史。

### MG31：补全题称“已列出”路径，初态却没有路径列表

**位置与输入。** G16 首次进入 `distribution-completion`，完整解释关闭。`.dt-prompt` 写“已列出9条等可能有序路径，且每条概率为1/9”；实际活动内表格数为 0，题面也没有逐条列出有序对。

**裁定。** 本轮接受为不阻断的措辞 Minor，未在冻结课件中修改。可复用配方是在生成时区分“共有 N 条”等已知数量与“如下已列出”等实际展示承诺；只有已展示路径列表才能使用后者。下次维护可将本句改为“共有9条等可能有序路径”；若选择增加列表，应保留求解工作、避免顺带显示事件答案。复查仍看首次作答 DOM，而不是只查 JSON 中存在一份关闭的全解表。
