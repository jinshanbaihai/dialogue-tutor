# 游戏策划与持续学习动机审核：DialogueTutor 1.7.0 修订技能，run-02

日期：2026-09-08。评委角色：游戏策划／持续学习动机模型专家。

复核范围固定为：首版退回报告 `reviews/game-html-run-01.md`、修订补丁 `reviews/run-02-skill-patch.diff`，以及当前 `SKILL.md`、`engagement-and-narrative.md`、`interactive-html.md`、`expert-review.md` 的上下文；同时核对补丁涉及的 `visual-design.md`。本轮只复核首版的虚构完成感、参考接触恢复、同条件结果接触和 n=1 相等关系措辞，以及选择后果、真实收束和继续动机是否仍受规则支持。不重新全量调研，不把尚未生成的 run-02 HTML 作为已通过产物。

## 裁定

**批准修订技能进入下一轮从空白重新生成。**

`Critical`：无。

`Important`：无。首版 GR1（收束虚构本人完成映射／归组）与 GR2（导入旧记录丢失本会话参考接触）均已由生成契约关闭；补充的结果接触身份规则也覆盖了直接观察后同条件再判断、导入／刷新保留和改变条件不误标无关参考。

`Minor`：无。首版 MR1（概率相等仍要求寻找“差异”）已要求按实际小于、等于、大于关系分支，相等时解释相等原因，并列为固定验收路径。

该批准只覆盖当前修订技能的生成规则，不代表新的 HTML 已生成、可玩路径已通过或真实学习者已经形成持续学习和延迟保持效果。

## 复核结论与依据

### GR1：虚构完成感——已关闭

`engagement-and-narrative.md` 的收束证据表（约第 63–71 行）把可用动词绑定到真实事件：只有揭示／查看时只能说已查看对应关系；主动选路径、运行抽样和实际提交计算／归组／解释分别有各自表述；没有对应事件时只能给下一项任务。其后要求作者先列“收束句→支撑字段→触发条件”，并明确揭示时间、页面位置和默认参数不能替代本人作答证据（约第 73 行）。

同文件还要求收束把当前轮条件、实际显示结果及关系、原判断身份和具名下一行动连起来；只把“你完成了”换成“你看到了”仍不够（约第 75 行）。`SKILL.md` 的交付检查同步要求结果与收束文案逐句对应事件，不能用揭示页面代替本人推理记录（约第 55–57 行）。`expert-review.md` 明确加入“只揭示、没有模拟或作答便进入结尾”的最小反例（约第 27–30 行）。因此首版“仅揭示便称学习者映射／合并”的完成感断言已被禁止，且有生成前字段映射与生成后定点验收。

### GR2：导入后参考接触——已关闭

`interactive-html.md` 先明确 `dt:activity-mounted` 与 `dt:restore` 的 `state` 只含当前活动的 `exploration`（约第 184–188 行），再要求恢复时将参数／历史、运行时 `activities[id].exposure` 中的参考接触、提交预测时冻结的辅助快照分开处理（约第 193–198 行）。冻结新预测前还必须同步检查关联全解是否展开，不能只等待异步 `toggle`；示例函数只在新预测提交动作中写入辅助快照（约第 199–218 行）。这直接覆盖“先看全解→导入旧记录→再预测”的边界，同时防止后续查阅倒改旧预测时点。

补充规则把实验结果本身定义为独立接触来源：已揭示结果保存题目与条件身份、揭示时间和来源；身份包含总体、机制、参数和目标事件。恢复／导入时合并本页已发生的结果接触，刷新从保存记录恢复，且不新增模拟、作答或重新揭示（约第 220 行）。提交新预测时须同时检查全解接触和结果身份；同条件再判断要标识为已见结果后的检查，改变条件只有在先前参考实际覆盖时才连带标记（约第 222 行）。因此历史结果接触不会被旧参数抹掉，也不会把无关条件的接触泛化成辅助。

`engagement-and-narrative.md` 同步规定导入旧记录后合并运行时与当前全解状态、提交新预测时冻结辅助快照，且初始化、恢复和普通导航不制造新的学习动作（约第 32–34 行）。`expert-review.md` 将导入／刷新、同条件再判断和改变条件不误标列为固定定点路径（约第 27–33 行）。首版报告中关于运行库双向导入／收束恢复的既有实际排除结论保持，不在本复审中重新列为故障。

### MR1：n=1 的相等关系措辞——已关闭

`engagement-and-narrative.md` 明确指出首版在样本量为 1 且两概率相等时错误使用“找出这个差异”，并要求比较反馈至少覆盖实际小于、等于、大于三种关系；相等时解释为什么相等，且“首次／再次”等阶段词必须有对应动作记录（约第 51–57 行）。`expert-review.md` 把改变参数使比较量相等列为首轮和重新开始都要核对的路径（约第 31–33 行）。这为生成者提供了关系分支与时态分支，不能再只按预测对错套固定的“差异”结语。

## 规则仍支持的游戏化学习循环

修订没有削弱原有的数学后果和继续动机配方：

- `engagement-and-narrative.md` 继续要求选择改变数学对象，结果回应悬念，随后进入独立新题（约第 9–19 行）；挑战递进明确区分完整示例、局部补全、独立题和改变条件（约第 36–49 行）。这仍支持有内容的选择后果，不需要积分或空转点击。
- 收束必须根据实际证据描述已经做过的动作，同时给一个改变条件的实际挑战和一个下次回忆的实际活动；入口使用真实活动／复习记录，先呈现问题并保留辅助、自评、独立客观和未完成工作的来源（约第 61–79 行）。这支持真实收束和可执行回访，不凭进入结尾授予掌握。
- 体验验收仍要求预测一致、不一致、未预测／跳过和辅助修正四条路径，逐条核对证据、回应和下一行动；改变条件后的题目必须真正增加数学要求（约第 81–87 行）。因此继续动机来自下一项可用能力和新条件验证，而不是重复奖励。
