## 自查中修正了什么

1. **自查脚本修正**：第一轮在第9场景将公共复习对象字段误写为 `review.level`，实际 API 是 `review.intervalIndex`。因此首轮报告失败，保存在 `records/dom-check-initial-failure.json`；修正断言后通过。这不是运行时或课程缺陷。
2. **真正课程修正**：直接观察的收束虽未冒称首次预测，但应明确“揭示前已看全解”。作者源增加 `revealHadReference`，只在真实揭示时冻结；收束按该字段显示，之后接触不倒改过去。重新生成JSON并组装，没有改已组装HTML。
3. **真正课程修正**：原无放回题已检查统计量定义，为让“解释统计量随机性”的目标有真实作答证据，在同一道题增加抽样前随机变量与抽样后7.5分钟观测值的区别，补齐参考和自评要点。活动数保持9；题目含义变化后revision更新为`run03-v2`。
4. **作者蓝图同步**：调查情境从初稿概称的灯具落实为灯罩抗压试验，并同步记录以上触发字段与证据。
