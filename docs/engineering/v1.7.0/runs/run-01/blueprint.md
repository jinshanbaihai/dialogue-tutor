## 核心问题与活动顺序

同一个总体，为什么每次样本给出的答案会不同？开场为三个校园服务点的微型总体 A=1、B=3、C=5 分钟。默认每份样本独立、有放回地均匀抽取两次，先预测样本均值 3 与 1 哪个更常见；冻结未评分预测后才枚举归组，再追踪一份样本怎样形成一个统计量落点。

首次到达不显示抽样分布、理论答案或模拟结果。支持入口只用另一个数对 2、8 示范平均值，允许直接浏览完整解答。实验可改变样本量 n=1、2、3 及有无放回；改变条件必须开启新一轮并保留旧预测。模拟的重复数 B 与单份样本量 n 分开显示；手选路径是枚举定位，不加入模拟频率。没有投机刷分或自动掌握宣称。

随后依次确定调查对象、修复抽样框、比较普查与抽样调查、判定统计量、完成例题与渐隐路径、改变抽样机制、处理相同数值的不同个体、解释抽样分布，最后用真实记录收束并提供回访。

## G1：准确指定总体、样本、抽样单位与抽样框

- 明确待测情形：把实际使用的电子名册当作目标总体，从而遗漏纸质工单。
- 目标能力：在语境中区分 population、sample、sampling unit、sampling frame，并解释框遗漏的后果。
- 先备支持：题面给出所有对象数量与调查目标；完整解答提供四个定义及一一映射。
- 学习者动作：population-check 选择四项对应；frame-repair 在新图书馆语境中写出遗漏和修复。
- 可观察证据：选择题原选项及客观核对；开放题本人原答与自评分别保存。
- 可视化关系：总体480张、电子框420张、已抽30张的嵌套关系表；题前仅给事实，题后才显示正确术语映射。
- 必要解释：框是操作清单，目标总体由问题界定；框完整与样本随机分别检查。
- 错误后的下一步：核对没有机会进入样本的对象，进入 frame-repair。
- 辅助后的下一步：换图书馆情境尝试 frame-repair；不将自评升级为客观通过。
- 正确后的下一步：census-sample，加入检测成本约束。
- 完整解答：dt-explanation-population-scene、dt-explanation-frame-scene。
- 来源与适用条件：Pearson S2 4.1、教材目录6.1；对象边界按题面，遗漏可能造成覆盖偏差，不能仅凭遗漏断言均值向哪边偏。

## G2：结合约束比较普查和抽样调查

- 明确待测情形：认为普查必然完美，或者认为随机抽样必然与总体完全相同。
- 目标能力：说明 census 与 sample survey 的优缺点，按规模、时间、成本、破坏性及覆盖条件作有依据的选择。
- 先备支持：提供现实目标和明确检测约束；全解给两者比较。
- 学习者动作：census-sample 选择适合破坏性检测的方案；survey-justify 在小型完整电子记录语境中独立建议并说明局限。
- 可观察证据：客观选择及开放论证自评，均保留原答。
- 可视化关系：完整解答中按同一维度比较两种方案；不添加无意义拖放。
- 必要解释：普查无抽样波动仍可能有测量/录入错误，样本调查更省资源但有抽样波动与可能的偏差。
- 错误后的下一步：survey-justify 对照“检测会破坏”和“读取不破坏”两种条件。
- 辅助后的下一步：独立写出新语境方案；正确后进入 statistic-check。
- 完整解答：dt-explanation-census-scene、dt-explanation-survey-scene。
- 来源与适用条件：Pearson S2 4.1、教材目录6.1；题中抽样随机且框完整并不保证实现样本完全代表总体。

## G3：判定统计量，区分随机统计量与实现值

- 明确待测情形：把含未知 μ 的表达式当作 statistic，或因为演示给出总体数据而混淆定义。
- 目标能力：按“只由样本和已知常数计算”判定 statistic，并区分 population parameter 与 statistic。
- 先备支持：X₁、X₂、n、μ 在题面说明；前置例子可主动查看。
- 学习者动作：statistic-check 辨析表达式；statistic-explain 在未知总体均值的新题中解释 range 和含 μ 的表达式。
- 可观察证据：选择客观核对；新题开放理由自评；不使用关键词自动评分。
- 可视化关系：输入可获得性表展示样本、已知常数、未知参数。
- 必要解释：抽样前 T 是随机变量，观测后 t 是数值；统计量定义不要求它估计某个参数。
- 错误后的下一步：statistic-explain 逐项检查能否计算；辅助后进入 mean-worked；正确后进入 mean-worked。
- 完整解答：dt-explanation-statistic-scene、dt-explanation-statistic-explain-scene。
- 来源与适用条件：Pearson S2 4.2、教材目录6.2；μ明确未知，演示总体已知不改变新题条件。

## G4：从抽样机制构建统计量的抽样分布

- 明确待测情形：把统计量的不同取值当作等可能，忘记同一取值可能由多条基本路径产生。
- 目标能力：列基本结果、按机制赋概率、计算统计量、归组求概率、核对和为1。
- 先备支持：平均值、乘法法则、互斥加法；mean-worked 是独立的完整例题 {2,8}、n=2、有放回。
- 学习者动作：sampling-lab 预测、冻结、归组、追踪样本；mean-completion 在 {1,3,4} 上补 P(均值=3.5)；mean-independent 在 {0,4,10} 上独立算 P(均值≥5)；max-distribution 在 {1,3,7} 上提交完整最大值分布与过程。
- 可观察证据：探索只记录参与和预测；补全2/9与独立数值5/9客观核对；完整分布原答与自评单列。
- 可视化关系：有序样本→统计量值→合并概率的对应；理论条形图与模拟频率并列区分。
- 必要解释：有放回且独立等概率时每个有序样本概率3^(-n)，合并互斥路径；一次样本的两个观测值不是抽样分布。
- 错误后的下一步：mean-worked 或 mean-completion 对应局部修复；数值错误只提示核对门槛，不推断其具体错因。
- 辅助后的下一步：mean-independent 的未揭示新题；正确后进入 mechanism-transfer 改变条件。
- 完整解答：对应各 scene 的 dt-explanation-…；不同独立题分开解答，避免查例题即接触后题答案。
- 来源与适用条件：Pearson S2 4.2、教材目录6.3；小总体精确枚举，默认均匀抽取且有放回时独立；没有使用CLT、置信区间或假设检验。

## G5：在抽样条件变化时重建概率

- 明确待测情形：无放回仍使用独立乘法；相同数值的不同个体被合并后错误等权。
- 目标能力：按放回条件、样本量和个体标签重建基本结果及权重。
- 先备支持：实验可切换有无放回，示范有序路径；题面保留每个个体标签。
- 学习者动作：mechanism-transfer 在 {2,4,10} 无放回抽2个上计算最大值10；repeated-values 在 A=1,B=1,C=1,D=5 有放回抽2个上计算极差非零。
- 可观察证据：两个不同条件新题数值分别核对2/3与3/8；不是选项重排。
- 可视化关系：无放回排除对角样本；重复数值保留4个单位的16条路径再归组。
- 必要解释：单个基本结果等可能不意味着统计量取值等可能；同值个体仍是不同抽样单位。
- 错误后的下一步：sampling-lab 改变放回条件，或 mean-worked 重看基本单位；辅助后到 repeated-values；正确后到 distribution-meaning。
- 完整解答：dt-explanation-mechanism-scene、dt-explanation-repeated-scene。
- 来源与适用条件：S1概率法则是允许前置，服务S2抽样分布；无放回按每次剩余个体均匀抽取，n≤N。

## G6：正确解释证据，并能够再次提取

- 明确待测情形：将模拟频率叫理论概率，将看过答案后的熟悉感叫独立掌握。
- 目标能力：区分总体分布、一次样本、统计量抽样分布、有限模拟频率；解释开场现象与抽样波动。
- 先备支持：同一实验分别标 n、B、理论概率与模拟频率；提交后给核对依据。
- 学习者动作：distribution-meaning 客观辨析；sampling-conclusion 用新随机调查情境解释差异；return-recall 提取三张核心概念卡并自评；evidence-close 查看本人真实证据并选择改变条件挑战或回访。
- 可观察证据：选择题结果、开放原答/自评、闪卡自評及真实时间记录。收束仅读取已有状态，不授予整章通过。
- 可视化关系：实验条形图与概率表共用枚举数据；模拟序列另有分母B。
- 必要解释：统计量随机性来自随机样本；模拟结果不会保证恰等于理论概率；理论分布依赖总体、机制、n和统计量定义。
- 错误后的下一步：返回 sampling-lab 定位一份样本；辅助后进入 sampling-conclusion；正确后进入收束。
- 完整解答：对应 scene 的关闭全解；return-recall 全解覆盖全部三张卡并关联 solutionId。
- 来源与适用条件：Pearson S2 4.2；复习采用运行组件已有1/3/7/14/30天工程规则，仅真实到期显示到期；自评一直标为自评。

## 收束和回访的操作契约

- sampling-lab 的一致预测、不一致预测、未预测直接观察、先查参考分别显示真实状态；新一轮保留前轮历史。
- evidence-close 读取 instance.getState()，按活动标题列独立客观记录、辅助记录、自评记录和尚无尝试的目标，不以浏览次数当掌握。
- 改变条件挑战：navigate('repeated-values')；若已有作答，标签明确“返回已有作答”。
- 回访：从 getReviews(lesson,state,Date.now()) 选择 return-recall 的真实 item，再 navigate(item.activityId,item)。有未完成草稿/待自评内容则继续未完成作答；无记录先进入 return-recall。未到期显示实际日期与提前练习，不伪造到期。
