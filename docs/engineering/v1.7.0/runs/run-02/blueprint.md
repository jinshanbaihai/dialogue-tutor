## 核心循环与渐隐

开场问题是“相同总体在取平均之后，超过门槛的概率怎样变”。改变n、门槛或放回条件影响数学对象；冻结后控件锁定，不可覆盖原判断；下一轮保留历史。揭示后比较文字有小于、等于、大于分支，n=1说明X̄=X。可不预测直接观察，措辞只写查看。无随机抽样按钮，所有路径明确标成枚举演示。

程序渐隐由四个不同总体承担：完整例题3/9两台→补全2/5/8三台→独立0/0/6三台并保留重复标签→独立0/2/2/6四台求门槛概率。最大值挑战新增无放回和统计量变更，不以数字更大冒充结构迁移。完整例题入口随时可查，steps不充当补全。

## 记录与恢复

探索字段包含phase、parameters、predictionDraft、prediction、predictionAt、predictionParameters、predictionHadReference、predictionHadResult、revealedAt、revealSource、history、contacts、pathSelections。预测历史、揭示身份及标签按条件保留。运行时参考exposure与当前全解open在提交前同步检查。导入更早记录不能撤销本页已发生的参考接触或相同条件结果接触。

仅“恢复显示”不应派发探索事件、不应增加参与次数。当前公共接口缺少不计参与地合并并持久化自定义状态的能力，因此“导入更早记录后立即导出/刷新仍保留既有结果接触”尚不能按公共契约实现。此前考虑的单独本地接触账本会绕开公共状态，未实现、未采用。本轮因此中止，等待公共接口与技能先修订，再从空白重新生成。所有客观评分原计划交由真实quiz；自定义探索不写分数。
