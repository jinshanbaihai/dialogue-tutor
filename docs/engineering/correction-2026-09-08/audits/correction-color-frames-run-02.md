## 数学、路径与比例

从题设单位身份和值，按有序两抽独立构造全部候选路径：WR 权重为 1/n²；WO 排除相同单位身份后权重为 1/[n(n−1)]。均值取 (x₁+x₂)/2，最大值独立取 max；再聚合同值路径。共核对 49 条候选记录（43 条允许、6 条禁用），以及路径概率分解与全部分布原像集合。

| 条件 | 独立分布（统计量值→概率） |
|---|---|
| 主例 WR 均值 | 1→1/9，3→2/9，5→1/3，7→2/9，9→1/9 |
| 主例 WO 均值 | 1→0，3→1/3，5→1/3，7→1/3，9→0 |

主例 15 条有效路径分别具备 paths→mapping→bars。AB 与 BA 各保留身份及先后色，分布阶段聚合到同一数值；AC、BB、CA 同归均值 5。WO 划去 AA/BB/CC，仍保留原位置，不将剩余格重排成误导的另一坐标系统。全部高亮帧在 326 宽逐帧目视，当前格、映射数值、目标柱及原像下划线对应一致。

## 角色与字形

574 个角色区域按预期颜色投影提取真实墨迹，排除禁用黑斜线污染。整体 coloredInkRows 最小 56 源 px；这不是用整条公式 bbox 宣称每个字都达标。独立混排样本（`mixed-text-samples.json`）分别量列头 A/B/C 字母主体与 1/5/9 数字：字母 57–58、数字 56；行头数字均 56 源 px，即 18.256 CSS px，满足原先关键字形 18、数字 16 的合同。AB/BB 真分式分子主体 62–64、分母 2 为 62（约 20.21 CSS px）；BB 中性和 10 的两个主体为 62/64；结果为 76。X 主体 91，脚标 62–63，不能用 X 加脚标 124–126 的总体框冒充主体尺寸。
