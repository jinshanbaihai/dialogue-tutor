## 教育评议后的实施补充

六项 Important 均采纳并进入实现验收：

- 修正原SKILL八行示例的串等号和合并操作；上传件原文保持只读，迁移的是教学方法，其数学错误不移植。一次变换一行不是按HTML物理行计数。
- 课程先备链明确建立等可能、有序结果、平均、事件互斥、独立/条件改变、乘法与加法，再构造分布。所有首次符号有读法、含义、适用条件；无放回1/3×1/2每个因子由抽样机制解释。
- 新题以完整路径集合、统计量映射、概率依据和分布组合选择形成一份答卷，提交前不逐格判分。界面记录“新题构造选择”，不声称完整独立书面证明。笔记之外主流程无文本或数值输入。
- 三类错项分别处理：统计量取值误当等可能；遗漏反向路径；无放回未去对角或仍用1/9。补讲从具体断点逐行展开；后续新题独立保护答案；所有结果均可继续、直接阅读全解。
- 选路径使两个抽值、均值算式、目标柱同步定位；无放回同时删除对角且重赋1/6。真实Manim静帧与视频源数据相同，按需高亮可用同源预渲染状态，不把静态文件冒称实时引擎。
- 七幕/六项按实际内容检查，不以标题数量通过。原创练习明确原创评价要点。

本补充仅记录经核验采纳的设计要求。教育设计通过不代表技能修改或课程已通过；最终九项实物测试见 correction-education-design.md。

## 根代理裁定：其余专家条件进入实施契约（2026-09-08）

教育 I1–I6、游戏 I1–I4、叙事 I1–I6、程序 I1–I7、色彩 C1/C2 与 I1–I5 均采纳。评审只批准实施方向，未批准成品。

- 三个主操作回路是选有序路径→映射均值、选同均值路径集合→归并概率、预测无放回变化→删除对角且重新赋权。选择即时标记，完整提交后统一核对；错误补讲具体到漏反向、误认均值等可能、无放回仍用旧权重。答错和直接看讲解都能继续。记录面板轻量收起。
- 新样章使用单一明亮主题，明确 color-scheme:light。采纳色彩报告的精确 tokens。X1 蓝圆、X2 紫方、统计量青菱有稳定身份，正误以外框/图标表达。图与式使用相同精确数据、对象标识。手机图使用真实适配构图，不将桌面密图缩成小字。至少360/390宽验证。
- 正文、行号、solutionId、activity mount 均为静态；动态组件内部不嵌活动。新生成 document 默认，保留旧 studio/open/numeric 兼容。新课主路径禁止键入答案。完整推导保持静态可查，已揭示范围不因回退消失；步骤控制以图帧为主。
- 本轮完整构造题采用一个 interactive 内多组原生选择，统一提交，保存冻结答卷/核对结果。通用 runtime 仍计探索；组件明确称“构造选择核对”，不得宣称已接入统一独立评分。普通单选与闪卡仍用既有组件。
- 每道题有 conditionKey；参考入口映射覆盖条件，提交前同步检查。提示/全解/结果接触不可被重试或旧记录导入清除。组件 stateVersion/dataHash 校验；恢复不得新增尝试。可选笔记可保留，主流程无 typing。
- 同源有理数 JSON 生成路径、均值、概率、柱、场景与核对数据。真实 Manim 静帧 manifest 记录数据/源码/产物 hash、条件、行号、对象对应；先给有限完整状态集，选帧与公式同步。视频可选，静帧必须独立完成任务。资源嵌入单 HTML 或明确随目录交付。
- 叙事由具体数学缺口承担；不虚构历史、用户情绪或能力。无放回均值某点概率可能不变，文案随数据。完整七幕及下半六职责保留；原创题明示，无真实史料时不编人名年份。
