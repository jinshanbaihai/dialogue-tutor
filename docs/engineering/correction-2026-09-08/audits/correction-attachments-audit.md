## 原件及当前版本已经做对的事

1. **经济附件保留题目到得分的完整链条。** 418 行起 Q1 至 980 行起 Q13，每问都有题干拆解、方法信号、前置知识、解题路线、逐行推导、评分整理六部分；推导表将答案与“为什么这样写”并排放置。Q7 明确区分“信心和时滞影响 AD 是否移动”与“闲置产能影响 AD 移动后的产出/价格效果”，避免答非所问。

3. **原件追问有明确接续位置。** 物理附件的追问使用 `n.1、n.2…` 补全某两行之间的推理，再回到主线；Q2(b)(iv)，600–679 行，针对“力矩的顺逆时针”用 12 个钟面步骤解释，不另开一篇无关知识文。经济附件 Q5 对“合法市场销量下降不等于实际总消费下降”的追问，也回接税收评价主线。

## Critical：必须修正

### C1. 当前推导被压成少数阶段，未保留原件“每一行及其理由”的教学骨架

证据：`lesson.json` 的 `worked-distribution`，约 106 行起，只有 3 个 steps 阶段：列 4 条有序路径、计算并映射样本均值、合并相同值。`lesson.html` 约 1190–1270 行的 steps 渲染只展示当前阶段正文及上一步/下一步，没有阶段内部的小问题或逐行理由接口。完整参考答案在 section 的 `<details>` 中，活动正文与逐问解释分离。

原件的关键不是长，而是它分别回答“这一行从哪里来”“为什么这样代入”“另一种写法为什么不对”“算完后怎么回到题问”。当前 `1,7` 放回抽 2 次的例题至少应保留如下连续骨架，然后把互动插在行间；不能把这些行换成卡片标题：

| 主线行 | 必须显示的推导 | 该行理由与可插入的免打字动作 |
|---|---|---|
| 1 | 第一次抽取可为 1 或 7，各为 1/2 | 明确总体元素等可能；选择“1/2 / 1/4 / 1”后出现理由 |
| 2 | 放回后第二次仍为 1 或 7，各为 1/2 | 点选“可再次抽到 1”，解释放回改变什么 |
| 3 | 路径为 (1,1)、(1,7)、(7,1)、(7,7) | 先点击遗漏路径，再展开原本四行；保留先后次序 |
| 4 | 每条路径概率为 (1/2)×(1/2)=1/4 | 先选乘法/加法；解释同一条连续路径与互斥路径合并的区别 |
| 5 | T(1,1)=(1+1)/2=1 | 代入不可省略；“分母为什么是 2”翻卡 |
| 6 | T(1,7)=(1+7)/2=4；T(7,1)=(7+1)/2=4 | 两条路径不同，但统计量值相同；点击将两路径归入同一组 |
| 7 | T(7,7)=(7+7)/2=7 | 与前两行同形式，避免只让学生记结果 |
| 8 | {T=4}={(1,7),(7,1)} | 明确事件是路径的集合；选择包含哪些路径 |
| 9 | P(T=4)=1/4+1/4=1/2 | 不相交路径合并用加法；对应画面将两条路径汇入柱 4 |
| 10 | P(T=1)=1/4，P(T=4)=1/2，P(T=7)=1/4 | 分布表与柱形图同步，明确横轴是统计量值 |
| 11 | 1/4+1/2+1/4=1 | 总概率检查，选择缺项或错误概率 |

这是对现有统计题的结构修复示例，不是把物理推导机械改成统计术语。每行都应保持可回看；答错后在当前行展开补充推导，最后明确回接下一行，不能只提示“去看前面的例题”。

### C2. “免打字”尚未覆盖主要学习任务；翻页与显示答案不等于作答

`lesson.json` 的 6 个 quiz 中只有 `statistic-check` 为 choice；3 个 open 和 2 个 numeric 仍需要键盘输入。具体为 `survey-plan`、`distribution-independent`、`without-replacement` 三个开放题，以及 `distribution-completion`、`distribution-probability` 两个数值题。源码 quiz 渲染器约 1090–1190 行，对 choice 使用单选，对其余类型创建 textarea / text input，并在 draft 为空时禁用提交。

当前没有 authored flashcard 活动；steps 的“下一步”和 evidence-close 的导航按钮不承担知识判断。附件自身也不是现成选择题网站：经济全文有 34 个 `<details>`、0 个 button/input；它们是可展开的阅读补充。用户本次要的是在这种逐行讲解上**增加**可点击判断，不是复用 details 数量当互动完成度。

最低修复要求：6 个测验均有无需输入字符即可完成的主要路径；保留开放输入可作为选做补充；每个核心推导至少出现一次“选择下一行或理由”及一次针对误解的反馈。具体活动级改法见后表。

### C3. 现有证据不支持已经沿用 Manim / 3Blue1Brown 作图调用

经济原件的 3 张图均是内嵌 SVG；我读过的物理图同样是内嵌 SVG。它们没有证明曾经使用 Manim。Run 03 的抽样可视化由 `sample-lab` 的 HTML 表格和 `.r3bar` CSS 概率条生成；课程未实例化 runtime 支持的 `explore` 活动。公用代码中存在画图帮助函数，不能当作本课已经使用的图，更不能当作 Manim 渲染记录。静态 HTML 的 tag 计数也不能反推运行后没有图，因为组件在运行时挂载。

须由主任务对照原技能已经存在的具体作图工具/流程调用，保存实际调用输入、产出路径与嵌入位置。只写“3Blue1Brown 风格”、把绿色公式改成黑底、或把来源元数据指向 `code_generator.py`，都不能证明使用了用户指定的作图调用。本报告不发明未读到的工具名、Manim 命令或渲染成功记录。

## Important：影响讲清楚与正确迁移

### I1. 图必须对准某一推导动作，并能解释符号与区域

经济 Q6 659 行起要求比较补贴增减；现有补贴 SVG 173 行附近只画增加补贴的情形。AD/AS SVG 313 行附近呈现一条折线 AS 与 AD 右移，未画出完整的不同初始产能位置比较。它们仍然有价值，但图下必须补出“哪条线/哪个点对应现在这一行”，不能因有图就认为所有比较已展示。

物理 Q1(b)(i) 的面积→位移、Q2 的力臂投影与转动方向、Q7(c) 的平方关系→渐陡曲线，均有明确的推导目标。Run 03 应据此建立以下对应：

| 当前统计推导 | 图示必须呈现的对象与变化 | 适合插入互动的位置 |
|---|---|---|
| 有序样本空间 | 2×2 / 3×3 路径格，或两层树；每个位置保留原始抽样结果 | 列举前选一条遗漏路径；显示每条路径概率的来源 |
| 样本→统计量 | 各路径卡片保留算式，汇入相同均值/最大值的组 | 计算后、合并前点击归组，错误归组显示代入过程 |
| 组→分布 | 同一横轴值接收多个等概率单位，柱高累加 | 选择应该加高的柱；保留 `1/9+1/9+…` |
| 事件概率 | 对选中值/路径统一着色；清楚显示 ≥ 包含边界 | 点击所有满足事件的路径，再累加概率 |
| 不放回 | 从原 3×3 网格移除对角线；分母由 9 变为 6 | 先选择被移除格，再判断第二次的条件概率为 1/2 |
| 预测与实际分布比较 | 保留预测标记，显示枚举结果及差异原因 | 揭晓后选“我忽略了重复路径/边界/抽样条件”等原因，再看解释 |

动画或图应能够停留、重播，并与相邻推导行对应。画面出现不应遮蔽原始解题文本；用户并未要求把逐行讲解改成只有动画。

### I2. 当前反馈较多是答案核对，局部“为什么”追问仍不够

`distribution-completion` 的解释直接给三条均值为 3 的路径；`distribution-probability` 给四条合格路径；`distribution-independent` 给最大值分布。它们的结果有解释，但缺少原件那种针对“为什么 (0,6) 与 (6,0) 都算”“为什么概率加起来”“≥5 是否包括恰为 5”等疑惑的连续补推。

在每个关键行后增加 `details`/flashcard 可保留读者自定节奏，但需使卡片的背面是具体推理，不是单个答案。例：“为什么最大值≤4的概率是 (2/3)²？”背面应写“两个抽值都必须来自 {1,4} → 每次概率 2/3 → 放回独立 → 乘积 4/9 → 再减去两次都为1的1/9得到最大值恰为4”。这是一条可以逐行检视的解释。

### I3. 学习证据说明挤占主线，而概念解释仍然偏短

`sample-lab` 与 `evidence-close` 有完整的预测保存、参考暴露和独立完成状态说明，功能意义明确。但多个段落反复描述记录状态，会让“抽样为什么如此计算”退到后面。建议保留记录机制，将技术性状态文字收进短状态条或可展开说明；把主要版面让给路径概率、统计量变换和分布合并的行行讲解。这里不是单纯追求总字数：记录说明多，仍然可能讲解不足。

以下为本次阅读发现的具体内部一致性问题。原始上传文件应保持不变；迁移或再生成时用明确的“校正说明”保留来源与修正理由。

| 位置 | 原件的问题 | 可核查的修正说明 |
|---|---|---|
| 物理 Q2 图 Fig 3.1，约 411 行 SVG | 水面 y=190，球心 y=255、半径26，整球位于水面以下；题文却说只有球体积的 26% 浸没 | 图只能作为示意且须标明与浸没比例不符，或重画水线；不能从现图视觉理解 `0.260V` |

## Minor：可与修订一起处理

- 经济附件是暗色单文件排版；物理附件支持明暗主题、公式字体及 `prefers-reduced-motion`。能继承颜色的稳定角色，但不能用换色代替推导行的分层。
- 物理 SVG 使用 `role="img"`、`aria-label`；经济 SVG 的辅助说明较少。新增交互要给图、按钮、选项可读标签，选择结果不能只靠颜色；这是延续可操作阅读的具体需要。
- 物理文件顶部依赖 Google Fonts 样式表与 MathJax 3.2.2 的 cdnjs 脚本。经济附件没有脚本或外部资源调用。离线/托管可用性需要另测；本报告没有把这些 CDN 的实际加载写成已验证。
- 物理 HTML 从 `<title>` 等开始，无完整 doctype / html / body 包装；浏览器通常会补结构，但本次没有实测。再生成时可保留内容、补规范文档壳。
