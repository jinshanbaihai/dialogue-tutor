### 2.1 统计量定义必须守住的细节

- 写作 `T=g(X₁,…,Xₙ)` 时，`g` 必须已确定且可由样本和已知常量计算。参数若未知，`X̄−μ` 通常不是统计量；若题面将某常量的数值明确给定，则不能仅凭它原先叫 μ 就判“不是”。选择题必须把未知/已知条件写清。
- 不含未知参数指**计算规则**，并不要求统计量的**抽样分布**不依赖总体参数。不能把这两条混成“凡分布含 μ 都不是统计量”。
- `T` 是抽样前的随机变量；得到特定样本后得到一个观测值 `t`。大写/小写可辅助解释，但不得只靠字体大小考查概念。
- 统计量不必等于样本均值，不必对总体参数作“好估计”，不必无偏；这些不能成为本章额外定义条件。若用常数规则作边界，须准确说明它是退化统计量，不设成无解释的陷阱。
- 自选统计量须在所有允许路径上有定义。例如只有两个不同数值时“众数”可能不唯一；除以某样本表达式可能遇到0。必须明确并处理这些情况，不能在程序中跳过坏路径后重新归一化。

### 2.2 随机性、独立性与等可能不是同一句话

先按题面给出具体抽样机制，再计算概率。对均匀地从 N 个**身份不同的单位**逐次抽取的模型：

1. 放回且每次重新独立、均匀抽取时，每步某个单位的概率为 `1/N`，n步有序身份路径概率为 `1/Nⁿ`。**放回这个动作本身不证明随机化独立**；条件依赖的选择规则即使允许放回也可能不独立。
2. 均匀无放回时，给定前面已抽单位，第 k 步某个尚未抽单位的概率为 `1/(N−k+1)`。允许路径概率为 `1/[N(N−1)…(N−n+1)]`，同一身份不可重复。
3. 当 `N≥2、n≥2` 时，无放回的单位身份抽取不独立：给定第一次抽到单位a，第二次再抽a的条件概率为0，而第二次边际抽到a的概率为1/N。两次边际相同不能推出独立。
4. 若数值全相同，观测数值是常量，值层面的随机变量可能退化并独立；这不使身份抽取变成独立。不要为解释独立性而无条件写“无放回时任何观测事件都不独立”。
5. 若采用“随机样本”专指 iid 观测的定义，须说明该定义；讨论无放回的随机抽取时应直接写抽样设计，不能因为也含“随机”二字就沿用 iid 乘法。多种专业语境的术语不可替代本题已给条件。

## 3. 重复数值与身份：硬性数学检查

总体输入必须是带身份的单位列表，例如抽象结构 `[{id,value},…]`。**允许 value 重复，禁止 id 重复**。课程画面中可以用下标、颜色之外的标记或编号区分同值单位；不能把数值集合 `set(values)` 作为有限总体。

设某数值v出现 `mᵥ` 次，总单位数N：

- 一抽取到数值v的概率为 `mᵥ/N`，不是不同数值个数的倒数。
- 两抽均匀独立放回时，数值路径 `(v,w)` 的概率为 `mᵥm𝑤/N²`，包括 `v=w` 时的 `mᵥ²/N²`。它已经合并了多条身份路径。
- 两抽均匀无放回时，`v≠w` 的数值路径概率为 `mᵥm𝑤/[N(N−1)]`；`v=w` 时为 `mᵥ(mᵥ−1)/[N(N−1)]`。当 `mᵥ≥2`，无放回仍可能得到两个相同数值。
- 身份网格的“对角线”是同一身份再次抽取；数值显示都一样不意味着两个格是同一个事件。图切换无放回时，删除身份对角线，并按剩余身份重算概率。

以上公式是评审核算与防错工具，不要求作者把它们全部变成额外课程练习。作者可以先选不同值简化入门；最终通用交互或生成器若宣称支持重复值，则必须通过重复值回归；即使界面仅采用不同值，也不得在讲解中得出“无放回不可能抽到相同数值”的普遍错误结论。

## 4. 有序路径、无序样本与归并

用有序身份路径作为独立 oracle 的基础，因为它将每一步的条件与概率保留下来。作者可使用有序或无序方法讲解，但须说明合并规则并得到同一分布。

定义有限路径空间Ω，路径概率p(ω)，统计量T。对每个取值t：

`P(T=t) = Σ_{ω∈Ω 且 T(ω)=t} p(ω)`。

这是互斥路径求和；“加法”原因是不同路径不能在同一次抽样同时发生。路径内部使用乘法是条件概率法则；不是因为“看到两个数就乘，看到两条路就加”的词形口诀。

| 检查对象 | 验收条件 |
|---|---|
| 有序路径完整性 | 均匀放回应有Nⁿ条身份路径；均匀无放回应有N!/(N−n)!条；不可因为测量值相同去重 |
| 无序身份样本 | 无放回等可能n元素身份子集可用 `1/C(N,n)`；须说明每个子集对应n!条有序身份路径 |
| 放回无序多重集 | 不同重复次数的多重集对应的有序路径数可能不同；不能默认无序多重集等可能 |
| 顺序有关的统计量 | 如“第一次观测值”，不同排列不能在算统计量前直接合并；不是所有统计量都对顺序不变 |
| 相同统计量值 | 归并的是 `T(ω)` 相等的路径，而非“看起来相近”“排序后相同”或“选择了相同个数” |
| 路径计数替代概率求和 | 只有已证等可能的基础路径才能用 `有利条数/总条数`；不等概率路径要加各自概率 |
| 分布支持集 | 唯一精确值、概率严格正；若画图保留零概率占位须标明为不可能，不当作支持集成员 |
| 事件边界 | `<、≤、>、≥、=`与题面一致；从路径直接求和与从分布求和必须相等 |

不可只用“相同均值有两条路”证明所有均值概率不同，也不可把某组数值的巧合推广到所有总体。样本量增加不意味着每次抽出的均值都更接近总体均值，也不意味着任意阈值事件概率都单向变化。若作者提出这些比较，必须具体核算或给出真正适用的定理条件。

## 5. 免打字互动与图示的数学约束

1. **选项不能修改目标。** 由完整分布构造题改成选择题时，仍要检查支持值、每组原像、路径概率及归并理由；只让选一个最终分数不能证明完整构造。
2. **数学等价选项不能误判。** `1/3` 与 `2/6` 等价；单选题若两者都满足题意必须重写，不能凭格式把正确表达判错。多选题采用精确集合比较，不能只比较选中数量。
3. **合并对象必须稳定。** 交互状态储存单位ID/有序路径ID及统计量的精确值；显示文字或颜色不可充当唯一身份，四舍五入字符串不可作归组键。
4. **每一行说明条件与变换。** 代入、算术运算、归并、化简及最终解释按实际推理动作拆解；不能用“选对后直接给表”替代中间过程。以均值为例，每条路径都应能查到代入两次观测、计算分子和、除以样本量的接续行及依据。公式选择的理由需要对应当前条件，不是泛写“根据公式”。原技能旧例若一行串联多个变换，也按此标准修正，不因它来自baseline就自动合格。
5. **推导、反馈和图用同一数学题设。** 选中路径后，筹码身份、样本数值、当前统计量算式、目标柱/组同步；切换放回、n或统计量后，全部重算，清除或明确标注旧题设下的选中对象。
6. **横轴与柱高有含义。** 分布图横轴为统计量值；纵轴若是概率则等于精确概率的显示近似，若为路径数则明确标单位并说明等可能前提。若用不等宽柱，不可把面积与概率关系说错；常规离散分布优先明确每根柱高的含义。
7. **动画只是数学的呈现。** Manim场景及静帧中的数字、路径和柱高应可追溯到审阅过的题设及精确表。动画资源成功生成不构成数学通过；还须核对实际显示的标签、条件与帧。
8. **模拟与枚举分开。** 模拟频率会波动，应注明次数；不能把模拟值当成精确分布，或因模拟接近就放过错误公式。穷举必须无截断；超预算明确失败或改模型，不得悄悄用模拟顶替。
9. **反馈不作过度诊断。** 相同错误答案可能有不同原因；先展示该选项所对应的计算/条件，再给具体补讲。答对选择只支持此项识别或构造结果，不标成已独立书写证明；翻卡自评不是客观核验。
10. **错了仍能读完整数学。** 不得以必须答对才能看到后续推导的方式截断原文；已揭示的主链可回看。教学提示后作答应标辅助，不得伪装成全新独立正确。

## 6. 独立 Fraction oracle：文件、接口与限制

配套参考实现：`reviews/correction-s2-fraction-oracle.py`。仅使用 Python 标准库 `fractions.Fraction`，**不导入课程作者代码、课程答案表、JS分组函数或Manim场景**。评审者从最终可见题干独立录入单位与条件，选择/独立编写统计量函数，再与作品输出比较。

### 6.1 核心接口

```python
enumerate_paths(units, sample_size, replacement, max_paths=100_000)
# -> list[{ids: tuple[str,...], values: tuple[Fraction,...],
#          factors: tuple[Fraction,...], probability: Fraction}]

distribution(rows, statistic_fn)
# statistic_fn(values: tuple[Fraction,...]) -> Fraction
# -> ({statistic_value: exact_probability},
#     {statistic_value: [identity_path,...]})

solve_case(case)
# -> JSON-compatible path table, conditional factors, statistic mapping,
#    grouped distribution, total mass and optional exact event probability
```

`enumerate_paths` 只适用于“放回时每次独立均匀按身份抽取”及“无放回时从剩余身份均匀抽取”。权重抽样、非均匀抽取或其他依赖设计不能套此函数；若作者选用该类拓展，由评审者另建显式的条件概率核，并独立验证每个前缀的下一步概率和为1。

`distribution` 可接受评审者自行写的统计量函数；命令行预注册 `mean/sum/minimum/maximum/range/first/median`，只是通用验证能力，不要求课程包含这些全部统计量。自定义函数应由评审者从数学定义独立重写，禁止从作者函数复制。函数正确返回某些数值不能证明“不含未知参数”；未知参数、闭包依赖、定义域和统计量身份仍需人工语义审阅。

### 6.2 机器输入契约

```text
case = {
  units: [{id: 非空唯一字符串, value: 整数或精确有理数字符串}, ...],
  sample_size: 正整数,
  replacement: true | false,
  statistic: 注册名称,
  event?: {op: eq | ne | lt | le | gt | ge, value: 精确有理数},
  max_paths?: 正整数
}
```

- `value` 可为 `"1/3"`、`"0.125"` 或整数；拒绝二进制float和bool，避免浮点误差先进入计算。分数序列化统一为 `numerator/denominator`，包括 `1/1` 与 `0/1`。
- 单位列表不可空、ID不可重复，值可重复；n必须≥1；无放回要求n≤N。n=N可用于审阅退化分布；不因不适合某堂入门课而把合法边界删掉。
- 输出每条路径的身份、数值、条件因子、路径概率与统计量值，以及各组原像路径。结果不只给一张最终分布表。
- 运算超预算抛出错误，不返回部分空间；没有随机模拟回退。检查器也不能把作者漏掉的路径自动删掉后重新归一化。
- 此实现仅处理有理数统计量值。若作者选用无理数结果，应另用独立的符号表示和严格等价检查；不可把近似浮点分组当作本 oracle 已支持。

### 6.3 调用方式

```bash
python reviews/correction-s2-fraction-oracle.py --self-test
python reviews/correction-s2-fraction-oracle.py --case path/to/reviewer-case.json
```

第二个路径是评审者独立录入的未来题设文件，不是本轮已经存在或已经验算的课程题目。命令可将输出保存为 review evidence，再用精确分数解析与作品快照比较。禁止把 oracle 生成的期望表直接写回作品后称作“独立发现作者正确”。作者可以在开发时使用自己的核算器；最终验收仍由不同实现和题面复录做一次。

## 7. 最终作品的独立检查程序

### 7.1 先冻结版本，再录入条件

记录最终HTML、JSON、作者数据文件、动画Scene与实际产出资源的路径及SHA-256。逐题从**最终可见题干**录入总体单位、数值、n、抽法、统计量、所求事件；不要直接复制答案数据。若题干省略影响计算的条件，立即报内容缺陷，不能用代码里的默认值替作者补上题设。

需覆盖所有不同数学题设：主讲例、免打字练习、错误分支的新题、可选全解、参数/条件切换、flashcard中有计算的正背面、图帧中独立出现的数值。仅换选项顺序不算新数学题；同一数学题复用可共享oracle结果，但每个呈现位置仍需一致性检查。

### 7.2 分层比较，禁止只比较最终答案

| 层级 | 独立精确比较 | 失败时需要报告的最小证据 |
|---|---|---|
| 身份层 | 单位ID唯一，值与题面一致，N与n正确 | 缺失/重复/误合并的单位 |
| 路径层 | 作者路径集合与oracle集合完全相同，包括顺序与重复身份是否合法 | 第一条缺失、多余或重复路径；不得只报计数不同 |
| 条件层 | 每个前缀的条件概率与题设一致，路径乘积精确相等 | 指出第几抽、给定什么前缀、错误分母 |
| 映射层 | 每条路径的T值与独立代入一致 | 路径、样本值、作者算式、正确代入 |
| 归并层 | 每个t的原像路径集合相同，概率为其质量之和 | 漏合并/误合并路径，正确求和式 |
| 分布层 | 精确支持集与概率一一匹配，总和为1 | 即使总和正确也列出错误项；不接受只按行号比较 |
| 事件层 | 事件对应路径集合、对应支持值、总概率均一致 | 边界漏项、多项或比较方向错误 |
| 呈现层 | 所有正文、选项、反馈、卡背、表、图轴、动画标签采用同一数学条件与结果 | 具体DOM/活动/场景/帧位置；实际可见错误截图 |

路径顺序/表格行序不同不算错误，ID元组与精确数值决定相等。作品若只展示无序样本，评审须用其声明的归并规则展开与oracle对照；不能强迫作者显示所有身份路径，但必须能证明没丢掉概率质量。

### 7.3 独立不变量与反向检查

除正向枚举外，按适用条件做以下检查；它们是核算器的交叉验证，不是所有都要变成课程内容：

- 每条路径概率为正，总路径概率=1；每个t恰好对应一个组；每条路径归入且仅归入一个组。
- 事件概率由原路径求和与由分布求和一致；事件与补事件概率和为1。
- n=1时放回开关不改变一抽分布；改变单位显示顺序/重命名ID不改变分布。
- 重复数值保留身份；全相同数值时均值/最大值退化，极差为0；仍保留正确的身份路径数。
- 无放回n=N时样本均值固定为总体均值；这不意味着所有顺序有关的统计量也固定。
- 给所有值加已知c，均值整体平移c、极差不变；以正比例a缩放，均值与极差相应缩放。若a<0，最大值对应旧最小值，不能直接套最大值缩放。
- 对均匀身份抽样的均值，分布加权均值应等于总体值的算术平均；这是额外交叉验证，不把相关估计理论新增为必修。
- 分数等价后比较，严禁四舍五入后合并支持值。任何显示近似的允许误差只用于最终排版数值，不用于路径/分组/答案判定。

### 7.4 验证器自身的已执行检查

`reviews/correction-s2-fraction-oracle-selftest.json` 记录本轮实际执行的14项自检：重复值仍有正确身份路径、有无放回概率、无放回仍可得到相同值、n=1、n=N、全同值、单位重排、事件边界、精确有理数平移，以及拒绝重复ID、float、不可能样本量、错误布尔类型和超预算截断。

自检用的合成数据只用于检验核算器，不是给新作者预定例题。自检没有读取新课程，也没有执行浏览器、Manim或画面检查。它只能证明这些检查在当前脚本上通过，不能证明实现对一切输入已形式化验证。

## 8. 退回与通过判据

**Critical，必须退回：** 任一核心定义错误；缺一整项章内必需概念；未知参数条件造成统计量误判；重复值误删单位；有序样本空间或路径概率错误；无放回套独立概率；统计量计算/归并/事件边界错误；图与正文显示矛盾；互动为了简化而改变题设或只保留最终答案、删除必要推导。

**Important，修正后复核：** 结论数值正确但关键条件/理由缺失；把一次正确选择标为独立完整推导；只验总和或只验一个默认状态；把独立抽取与放回混为同一前提；答案等价表达误判；图不能明确对应路径及其概率贡献；个别非主链内容未经核验。

**Minor：** 不改变含义的符号统一、标签/单位排版及说明位置问题。若排版导致读者把不同身份认作同一单位，或将条件/符号读错，应升级，不能以“只是视觉”豁免。

通过条件：范围表全部有实质证据；每种数学题设在最终版本上独立重算通过；所有反馈/图帧与对应题设一致；人工语义审查与精确计算均通过；未完成的项目明确标“未验”，不沿用旧版本通过意见。最终报告须列本轮真正核验的版本哈希、案例数、边界/分支覆盖和未测限制。
