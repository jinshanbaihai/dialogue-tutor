# run-02 叙事失效对应的最小修规文本

仅修改本次证据暴露的生成缺口；不增加研究或界面功能范围，不改冻结课件。建议纳入 engagement-and-narrative、teaching-design 与 generation-checks 对应位置后定向复审。

## 1. 正确性与辅助分开生成文句及后续

可直接采用：

> 作者先为本条件生成独立的判断结果（未提交/正确/错误）、提交时辅助来源、当前结果覆盖、跳过记录和任务锁定情况。辅助来源不改变正确性，不能先返回 assisted 再使正确/错误分支不可达。结果未完整呈现时不评价预测；已呈现且有本条件预测时，先具体核对原选择与数学结果，再另句说明提交前辅助。错误仍存在时，下一建议优先指向本差异的具名完整修复；辅助后可以建议未揭示的新题，但不能因此越过当前错误的支持。直接阅读与跳过始终可用。
>
> 作者测试至少实际交叉运行“无辅助正确、无辅助错误、辅助正确、辅助错误”，保存原选择、辅助来源、结果覆盖、结尾句与点击目的地。不是只测试字段分开保存，也不是用“辅助正确”替代全部辅助情形。

实现只需本课自定义状态和已有 `getState()`；不新增 runtime 评分 API。例如先计算 `isCorrect` 与 `hadAssistance` 两值，在两个独立条件中写文句，而非 `if (hadAssistance) ... else if (isCorrect) ...`。

## 2. 补救入口绑定完整局部内容与原行

可直接采用：

> 每个可达 repair 在生成前给出本条件的错误差异、解释此差异所需的完整小步、原行锚点及可选再试/接续。正文别处有完整证明不能替代 repair 的实际支持：修复区要呈现当前断点需要的小步，并能返回确切主行；如复用正文，引用并展示该段完整内容，不能只显示最终分数和“请先找原像”。链接须定位当前条件与对象，点击后相关正文实际可查。只写 repair 名称、空容器或整章入口不算完成。
>
> 作者逐个走可达错误分支，读取实际 repair DOM 的推导、依据、返回目标和下一动作。主线与构造板分别检，不能用构造板的链接替主线通过。就均值等可能这一断点，必须实际看到原像路径权重的相加与必要约分，并有当前归并行的真实入口；不必复制无关的整章推导。

这属于用既有内容与控件落实完整补讲，不要求新增输入框、强制作答或独立题库。

## 3. 接续文句在使用前重新核当前任务状态

可直接采用：

> 同一个下一任务若在多个位置有按钮，各按钮使用前都按真实当前任务状态区分初次检查与回看。可在已有 `dt:navigate` 事件中刷新本课接续，也可在自定义 next 点击前调用 `getState()` 重新计算标签与目标；不得假设 runtime 有未提供的 state-change 事件。不要只从按钮创建时保存的 JSON 读取旧建议。
>
> 完成 Q4 后分别检验没有额外 scroll 的返回与产生 scroll 的返回，记录每个相关入口的文句及真实目的地；标签陈旧、错路由和错误解锁分别裁定。

当前 M2 只证实无 scroll fixture 序列的旧措辞，实际目的地仍为同一 Q4；不需要为此扩展 runtime 事件系统。

## 4. 来源日期取原件

可直接采用：

> 来源标题、考试日期、版本和页码从实际原件封面或出版信息获取；URL 文件名仅作定位，不能自动解析成出版或考试日期。来源表与正文采用同一已核字段。日期不一致时以原件正文为据并记录差异。

本轮具体差异是 S5 文件名含 20230524，而封面为 23 May 2023；题型支持不因此失效。
