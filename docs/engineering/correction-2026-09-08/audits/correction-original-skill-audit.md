# DialogueTutor 原版结构与外部依赖审计

审计日期：2026-09-08。对象为本工作区 baseline 的 1.6.0 与 repo 的 1.7.0 指令文件。本报告只审计技能语义，不修改技能、不生成课件，也不沿用前轮通过结论。完整读取覆盖与 SHA-256 另见 `correction-original-skill-read-coverage.md`；外部链接清单另见 `correction-original-skill-external-links.md`。

文中 B 表示 `baseline/dialogue-tutor/`，N 表示 `repo/plugins/dialogue-tutor/skills/dialogue-tutor/`。行号均对应本次记录的哈希。失败实例分为原文已记录的实物失败与本次由规则可推出的失败路径；后者不冒称已经运行观察。

## 实际优点

1. N `references/interactive-html.md:120–146,333–350` 保留闪卡、选择、数值、开放题各自的 payload、原答/提示/自评区分与复习记录。选择题和闪卡没有从 schema 删除，因此“改版已经删除这两种组件”不是本审计支持的结论。
2. N `references/teaching-design.md:20–23,36–50` 指出步进只记录参与、不能冒称本人补全，并提供真实作答与不同题练习。这个修正可以保留，前提是作为完整教学的补充，不成为删掉完整推导的理由。
3. N `references/visual-design.md:35–53` 明确 SVG 真实字号、暗色标注、图例与控件对比，改善可读性具有明确检查位置。
4. N `references/engagement-and-narrative.md:21–34,57–79` 区分预测提交和结果揭示、真实事件与收束话术，有助于避免把“看到了”编造成“推导了”。
5. N `references/modes-and-explanations.md:18–20` 继续要求原题条件与正式评分依据；N `references/learning-evidence.md:5–15` 说明研究未直接测试本页面，且 ICAP 的 interactive 不等于鼠标交互。这些证据边界应保留。

## Critical

### C1. 把完整本质讲解的设计骨架降为可抛弃的历史布局

- 原文：B `SKILL.md:17–45` 指定 HTML 为主件、深入追问为补件；`694–725` 要求上下两半分别写足、上半移除作业仍能独立成为入门讲解；`728–769` 指定七幕及轻重，核心是③造公式与④完整例题；`976–989` 从每个作业小问反向列公式链。
- 改版：N `SKILL.md:10–12` 写“旧版固定七幕、上下两半和字数下限不再决定页面结构”；N `references/modes-and-explanations.md:5–14` 以任务舞台和按需查阅取代原骨架，历史来历和另一种看法退成仅当前能力需要时才纳入。
- 失败实例：B `SKILL.md:2046–2056` 已记录“仅留七项检查表”会重新生成答案解析。新规则再将对象构建降成概念用途/依据/局限槽位，允许只给面向当前任务的知识，而缺少对象从缺口到成立的连续构造。此处是生成许可范围退化，不是本报告对新课件的实测。
- 保留/修复：交互优先可以决定同一学习位置的呈现方式，不能自动废止原有内容骨架。恢复按对象建立前提、造公式、完整例题、边界及下半逐题覆盖的明确映射；七幕的视觉形式可调整，实质教学职责和权重不可静默删除。背景短、推导与例题重的原分量本身已防止历史喧宾夺主。

### C2. 将“每个等号一行、一行一依据”改成“主要”等号，撤掉纵横两项检查

- 原文：B `SKILL.md:742–752,812–815,1435–1454` 强调每个等号单独占一行，每一行给具体依据；展开、原函数、代上限、代下限、通分、约分各算一行；纵向查相邻推理，横向查定义、条件、单位、零除数和舍解。`1143–1156` 连补写的 8.1、8.2 都要同样密度。
- 改版：N `references/modes-and-explanations.md:26` 仅要求“每个主要等号有可查依据”；N `references/teaching-design.md:29` 仅要求“每个主要变换的依据”；N `references/engagement-and-narrative.md:53` 说常规运算保持连贯。后一句反对每个等号强制暂停本可成立，却不能作为逐行文字密度的替代。
- 失败实例：B `SKILL.md:1459–1484` 的归一化例题，最终 k 正确而下限代入与相减同时错误；三个等号挤一行藏住错误。改版“主要”的不确定边界允许把通分、代入称作常规运算而再次省略。B 示例本身仍有个别行连写多个等号，恢复时应遵守更严格正文要求并修示例，不能把示例瑕疵当降低要求的依据。
- 保留/修复：恢复全部推理变化的一步一行与具体依据，明确无需每行都配按钮或强制等待。全量检查公式首次出现、每个相邻步骤、局部合法性。把作者检查和学习者控制节奏分开。

### C3. 把“互动穿插正文”实现成“单活动舞台，全部解释默认折叠”

- 原文：B `SKILL.md:66–90` 的优先级是“先保留完整而准确的讲解，再把有明确学习用途的操作穿插到对应内容”；B `references/interactive-html.md:33–39,159–163` 明确在正文实际学习节点预置挂载点，只有泄露练习解法的部分进入参考区。
- 改版：N `SKILL.md:35,41–49` 强制新课程使用 studio；N `references/interactive-html.md:88–93` 一次只显示主要活动，把 `bodyHtml` 自动装进关闭 details，并禁止完整解说内嵌活动挂载；N `references/visual-design.md:43` 规定完整讲解通过入口展开。
- 失败路径：新课程只要按规范把定义、构建推导和完整解释写入 bodyHtml，它们就与答案一起成为默认关闭内容。学习者读到新符号后需要主动找解释，且无法在连续推导恰当位置遇到辨析或翻卡。布局层把“必要前提”与“需要保护的答案”合并了。
- 保留/修复：恢复连续可读的数学讲解和就地互动；按内容区分公开前提、构造解释、活动、受保护解法。新课程应允许并鼓励精确正文锚点，不能将 document 只列作旧版兼容。保留具名导航、宽幅图形和轻量辅助工具，不让舞台成为默认结构的硬限制。

### C4. 外部技能完整读取与输出契约被删为模糊可选句

- 原文：B `SKILL.md:1182–1208` 已给导入环境路由，技能存在即按表读取，缺席则执行内置要求并记录；`1210–1370` 写明 writing-style、respectful-wording、obra、emi、manim 的读取文件、进入点、结果与失败处理。
- 改版：N `SKILL.md:77` 与 N `references/modes-and-explanations.md:42` 只保留“明确需要且实际提供时按任务采用”，没有具名技能、必要路径、产出或调用记录；视觉参考只保留一般动画与 reduced-motion 要求。
- 失败实例：B `SKILL.md:1188–1191,2205–2211` 明说先前只有“动笔前翻”导致第一份实物一份都没读。改版重现同一种不具可执行性的提示。不存在强制私有依赖问题，因为基线 `1193–1196` 已有缺席继续工作、真实记录的路由。
- 保留/修复：恢复下方完整依赖矩阵及触发判断，实际可用时完整读取被要求的正文；本地回退只处理缺席，不替代有条件可用的技能。保留 manim 的当前载体分流，而不是把所有图都强制做视频。

## Important

### I1. 选择题与闪卡虽保留组件，但选择规则未防止开放输入替代其教学作用

- 原文：B `references/interactive-html.md:16–26,82–107` 分别安排定义提取用闪卡、辨析用 choice、确定计算用 numeric、开放推导用 open；B `SKILL.md:1014–1017` 明确撤回“一概排除记忆题”，恢复必要提取。B `references/考纲与考试局.md:95–102,155–164` 要求 TMUA 练习为选择题并有实际错误对应的干扰项。
- 改版：N `references/teaching-design.md:14,20–23,44–46,56` 把选项线索风险、开放解释及独立题配方突出化，闪卡目标可由简短开放回答替代；N `references/interactive-html.md:18–21,120–140` 仍保留完整题型，故不能断言明文禁止 choice/flashcards。
- 失败路径：作者可将每个定义与判断都改写成“解释一下”文本框，声称已经收集独立推理；这样丢掉快速提取、低摩擦辨析、诊断干扰项和考试题型，且最后仍只有自评。当前用户批评说明该路径已经发生，具体课件频数应由课件审计核对，本报告不编造频数。
- 保留/修复：给出积极的默认选择规则和反替代规则：定义/条件已讲透后优先闪卡，概念比较与 TMUA 题优先选择；open 用于确实需要多样论证的任务。解释题可以补充 choice 的证据，不能自动替换或升级其评分。拒绝为形式配额乱加卡，但核心概念的提取与辨析用途须在蓝图中逐项交代。

### I2. 六样被重命名为一般语义槽，失去题干到方法的桥与全量小问约束

- 原文：B `SKILL.md:1391–1457` 规定一题一节、一小问一段、不合并、逐题读完；六样单列“题干昭示哪个方法并解释其他方法不合适”“回接上半哪一幕”“公式选择”；`1621–1646` 有原卷→总题面→小问块三层全量核验。
- 改版：N `references/modes-and-explanations.md:18–20` 合并成“题面、方法与适用条件、使用的依据、可核算过程、最终答案、评价位置”。没有原始六样的一一对应，亦未保留具体三层核验与不合并要求。
- 失败实例：B `SKILL.md:1384–1389` 四小问因为都用归一化而被合并，另有 Q1(c) 只在速查卡出现；`1540–1574` 给出 random、random variable、each set 在复述中丢失的实际失败。
- 保留/修复：原六项职责逐项恢复，允许同一界面不同布局但每小问独立可定位、内容完整；恢复原始材料全量连续阅读与题面继承链验证，不让最终答案槽挤掉前提与方法的论证。

### I3. 普通成品的逐行独立审读退成用户另提专家才触发

- 原文：B `SKILL.md:1031–1051,1072–1074,1267–1289` 要求完整第一版→文风检查→独立模拟学生逐行复算，有明确已有前提、断点报告和末轮清单；确无独立工具才标为作者自检。
- 改版：N `SKILL.md:59`、N `references/expert-review.md:3` 都以“用户要求专家”触发；专家责任表和交互路径强，但没有为普通生成保留每个新公式、每条相邻推理的独立审读。
- 失败路径：用户只说 bgct 时可直接交付经过作者数学核算的任务，缺失原有专门寻找作者心中自动补全前提的检查。专家色彩/游戏/叙事角色不替代这一阅读任务。
- 保留/修复：恢复成品自查后的逐行审读；专家全流程可按请求执行，但普通教学产物的断点审读保持自身触发和具体输出。审读者无需人为扮演低智力或伪造困惑。

### I4. 伴读原有听觉详细度地板与走位核对被取消，却误称基线会混读答案

- 原文：B `SKILL.md:394–430,569–571,600–638` 要求每条学科依据和数值都讲到、总覆盖不低于屏幕，按走位单核对；`406–411,644–647` 与 B `references/interactive-html.md:255–284` 已提供首次轨/答案轨。
- 改版：N `references/modes-and-explanations.md:34` 写“原版伴读将答案与题面混读”；`36–38` 只保留合计内容覆盖与一般朗读要求；N `references/learning-evidence.md:57` 明说取消字数地板。
- 失败路径：参考轨可把屏幕八行算式压成“积分得出结果”，声称覆盖方法与结果；这正是 B `SKILL.md:430` 指出的退化。取消“字数是有效性阈值”不能推出取消个人详细度偏好，基线 `606` 已区分这两者。
- 保留/修复：纠正原版时序描述；恢复学科信息逐行覆盖、数值与依据展开、两轨走位核对。字符数可用漏项警报并说明局限，不能把通过字符数当作语义审阅。保留自然讲师口吻、块开头定位一次、块内不报行号。

### I5. 未知前提“讲透再问”被缩成“简短解释或示例”

- 原文：B `SKILL.md:128–153` 指提问每个符号和概念都来自已建立前提，不能确定则先讲清；足够标准是能复述且说明为何成立，字数让位；`991–1009` 有连接完整性与三层为什么检验。
- 改版：N `SKILL.md:67` 指定未知前提提供“简短解释或示例”；N `references/teaching-design.md:27` 只说含义、条件和可检查例子。
- 失败路径：先给一个概率公式和短例，再问“为什么这里用条件概率”，学习者仍不知道如何判断条件作用；展示过例子不等于前提已经建立。
- 保留/修复：恢复可检验的前提成立条件、逐层拆链、必要时放开长度；保留可选诊断与直接看示例，但不以诊断失败代替讲授。

## Minor

### M1. 历史层次与现行层次应逐处标明

B `SKILL.md:2012–2015` 明说日志不覆盖现行条款。N `SKILL.md:12` 将“原版先写完整”认作失败本身，N modes 34 又把更早的混读问题归给当下基线。修复时应说明批评针对哪个具体快照、哪个实际行为。B 自身存在历史高度动画与现行 transform/opacity 规则不一致（`1313–1318` 对 `2223–2225`）、严格单等号与示例连等号不一致；保留明确现行意图并清理例子，不复制矛盾。
