# 纠偏验收冻结 v1

冻结时间2026-09-08，先于本轮正式数学HTML生成。旧run01–03及原1.7评审均不作为本轮通过证据。用户要求是修复skill后从空白生成数学课；本轮以一份完整S2第6章bgct原创样章验收，不把一次生成外推为所有输入的稳定性。

## 生成条件

- 输入：Edexcel IAL S2第6章 Sampling and sampling distributions；范围按Pearson官方规范S2 4.1/4.2与官方章节索引；原创例题和习题，不冒充提供了教材习题全文。
- 核心：完整逐行推导，活动穿插于有诊断价值的关键依据；选择/翻卡/免打字构造；真实Manim可查帧及图式同源。
- 模式：bgct；下半每个原创小问保留六项职责。bbct/olct/onct/plustts以提示合同审核和既有兼容性回归为限，不宣称新课覆盖了所有模式生成。
- 每轮独立新作者从空目录生成，读取已过审skill全文及必需参考/外部路由；不得从被打回课程复制正文。可复用通用runtime、已验证渲染环境。
- 记录skill所有输入文件SHA256、模型真实可见标识（不可见字段标未暴露）、原始指令、生成目录与产物哈希。
- 初始1份完整生成；专家退回则根裁定→先改skill→复审skill受影响条款→另起空目录重新生成。次数不设假通过上限。循环次数是工程安排，非学习效果阈值。

## 硬性失败

1. 主学习流程要求键入答案，或答对才可看完整讲解。
2. bgct上半教学对象不独立、七项职责被删，或下半小问合并/缺完整逐行依据；主要推导被默认整体关闭或只在视频里。
3. 数学定义/条件/有序路径/概率权重/图轴/公式不一致；例题多步并为一个未解释跳跃。
4. Manim只提供代码而无真实渲染；图与行/条件对不上；资源缺失；手机关键标签不可读。
5. 操作只换文案不变数学对象；首次完整构造提交前自动判分泄露余项；反馈缺具体补讲。
6. 参考接触被重试/恢复洗掉、组件核对冒称自由书写能力、闪卡自评冒称客观掌握；保存失败阻断学习。
7. 专家未读产物/未运行相关操作却称实测通过；以测试数量替代具体教学场景。

## 必须核对的场景

- 全程免打字：定义→路径→均值映射→概率归并→无放回→完整新题构造→闪卡→直接全文。
- 任意路径及反向路径：两抽值、逐行均值式、柱归属同步。9条各1/9与6条各1/6；均值相同与路径不同。
- 错误三种：均值等可能、漏反向、无放回旧权重；保留选择、局部n.1式补讲、回主行、可选新题。
- 先全解再答；首答后反馈；同题重试；旧草稿导入；刷新恢复；立即导出；不同条件不串证据。
- 原生按钮/选择可键盘操作；先前推导持续可查；图无动画仍完成任务。
- 精确算术由独立Fraction枚举核验，输出路径、分布、概率和条件。
- Manim关键静帧逐份目视检查；原始尺寸及手机目标宽度检查关键字形。源码/数据/媒体哈希和映射检查。
- 程序以最终组装HTML执行DOM事件测试；这是实际JS行为证据，不是浏览器排版证据。浏览器预览基础设施当前不可用，必须明确记录，不伪造截图或浏览器通过。

## 专家与结论

教育学、游戏策划、程序实现、色彩/数学可视化、讲述分别出具独立报告：版本/hash、实读/实际操作范围、具体失败、裁定、复验。学科和游戏必须亲自执行对应HTML操作脚本及查阅结果；画面评审必须实际看渲染图。

软性质量逐项0–2：数学问题牵引、操作后果可见、反馈具体、阅读连续、视觉层次、可自主停止/续学。0=缺失，1=存在但影响理解，2=明确可用；不以总分抵消硬失败。最终报告必须列任何未执行的浏览器/真实学习者检查；专家通过只能指明已验收的范围，不等于学习成效或普适稳定性。
