第一章 · 概率密度函数：一个自己不是概率的东西

① 先造出那个缺口

离散那一套办法，从中学起就在用：概率等于有利结果数除以总结果数。掷一枚骰子， 六个结果，出现 6 点的概率是 \(\tfrac{1}{6}\)。这套办法有一个隐含的前提， 就是结果数得数得清。

现在换一个问题。一列小火车相对时刻表的偏差记作 \(W\) 分钟，早到记成负数。 问：它恰好偏差 2.6 分钟的概率是多少？

分母立刻没有了着落。偏差可以是 2.6，也可以是 2.61、2.600001、2.6000001， 这样的取值有无穷多个，而且多到没办法排成一列去数。

再往下推一步就撞上了硬处。假设每一个具体取值都分到同一个正数 \(p \gt 0\)。 在区间里挑出 \(N\) 个不同的取值，它们的概率合起来是 \(Np\)。 \(N\) 可以取到任意大，\(Np\) 于是可以超过 1，而概率越不过 1。 所以 \(p\) 只能是 0：每一个具体取值的概率都是 0。

可是这条火车总要在某个时刻到站。全部取值合起来的概率是 1。 一堆 0 加起来，怎么会等于 1。

这个裂口不补上，连续型概率一步也走不了。第③幕补的就是它。

② 它从哪里来（两三句）

1777 年，布丰（Georges-Louis Leclerc, Comte de Buffon）在《道德算术试论》 （Essai d'arithmétique morale）里把一根针扔到画着平行线的地板上，问它压到线的概率是多少。 他手上只有「有利结果数除以总结果数」，而针的位置与角度数不清， 于是他把「数个数」换成了「量大小」。一百多年后，贝特朗（Joseph Bertrand）1889 年在 《概率演算》（Calcul des probabilités）里问：圆里随机取一条弦， 它比内接正三角形的边长的概率是多少？三种都说得通的取法给出三个答案： \(\tfrac{1}{2}\)、\(\tfrac{1}{3}\)、\(\tfrac{1}{4}\)。

同一句「随机」，三个答案。「等可能」这个词搬到连续场合以后本身还没有定义清楚， 第③幕造出来的东西正是为了给它一个说得明白的形式。 （布丰那根针后来算出压线的概率是 \(\tfrac{2\ell}{\pi d}\)， 历史上第一次有人用概率去量 \(\pi\)。来历在这里就这么长，篇幅让给第③幕与第④幕。）

③ 把公式一步一步造出来

第①幕已经证明了一件事：给单个取值分配概率这条路走不通。 既然走不通，就换一个承受概率的东西。区间是现成的候选，因为区间有长度， 长度可以比较大小，也可以相加。

于是第一个决定是：概率交给区间，不交给点。 写下要求它满足的两条性质，一条一行。

行写下的东西这一行凭什么
1\(F(x) = P(X \le x)\) 先给一个一定存在的东西起名。任何一个随机变量，问它「不超过 \(x\) 的概率是多少」总是有答案的。这个函数叫累积分布函数（cumulative distribution function, c.d.f.）
2\(a \le b \Rightarrow F(a) \le F(b)\) 事件 \(\{X \le a\}\) 包含在 \(\{X \le b\}\) 里面，大事件的概率不会更小。所以 \(F\) 单调不减
3\(\{X \le b\} = \{X \le a\} \cup \{a \lt X \le b\}\) 把「不超过 \(b\)」按「有没有超过 \(a\)」切成两块，两块互不相交
4\(F(b) = F(a) + P(a \lt X \le b)\) 互斥事件的概率相加，这是概率的可加性，对第 3 行两边取概率
5\(P(a \lt X \le b) = F(b) - F(a)\) 第 4 行两边同减 \(F(a)\)。到这里，区间的概率已经完全由 \(F\) 决定

第 5 行是一个可以停下来看一眼的位置。它说：想知道任何一段区间的概率， 查两次 \(F\) 就够了。那么还需要造别的东西吗？需要，理由在下面这一步。

\(F\) 装着全部信息，可是它把信息装得太紧。看着 \(F\) 这条上升的曲线， 读不出「哪一段更容易出现」这件事，因为它到处都在上升。 更常用的问法是「这附近的概率有多浓」，浓淡对应的是 \(F\) 上升的快慢， 而快慢就是斜率。

行写下的东西这一行凭什么
6\(\dfrac{P(x \lt X \le x+h)}{h} = \dfrac{F(x+h)-F(x)}{h}\) 分子用第 5 行换掉。左边是「一小段上的概率除以这一小段的长度」，也就是这一小段的平均浓度
7\(f(x) = \lim\limits_{h \to 0} \dfrac{F(x+h)-F(x)}{h} = F'(x)\) 让这一小段缩到一点上。极限存在的时候，得到的就是 \(F\) 在这一点的导数。到这一刻才给它命名：概率密度函数（probability density function, p.d.f.）
8\(F(b)-F(a) = \displaystyle\int_a^b f(x)\,dx\) 微积分基本定理（fundamental theorem of calculus）：\(f\) 是 \(F\) 的导数，那么 \(f\) 从 \(a\) 到 \(b\) 的定积分等于 \(F\) 在两端的差
9\(P(a \le X \le b) = \displaystyle\int_a^b f(x)\,dx\) 第 5 行接第 8 行。左边端点从 \(a \lt X\) 换成 \(a \le X\)，差的那一个点概率为 0（第 12 行），换与不换都成立

造完了。密度自己不是概率，它是概率对长度的变化率； 在一段上积起来，才是那一段的概率。第①幕的裂口就此合上： 单点的概率是 0，而区间的概率是一块面积，一堆 0 加不出 1 这件事不再成为障碍， 因为加起来的从来不是那些 0，是那些面积。

造出来的同时，有三件平时当规定背的事情自己掉了出来。

行掉出来的性质它凭什么成立
10\(f(x) \ge 0\) 第 2 行说 \(F\) 单调不减，单调不减的函数导数不会是负的
11\(\displaystyle\int_{-\infty}^{\infty} f(x)\,dx = F(\infty)-F(-\infty) = 1-0 = 1\) 第 8 行把两端推到无穷。\(F(\infty)=1\) 因为 \(X\) 总要取到某个值，\(F(-\infty)=0\) 因为它不可能比任何数都小
12\(P(X=a)=\displaystyle\int_a^a f(x)\,dx = 0\) 上下限相同的定积分是 0。这正是第①幕那个「每个点的概率都是 0」，现在它成了一条推论
13\(f(x)\) 可以大于 1 密度的单位是「概率每单位长度」。区间 \([0,\,0.5]\) 上的均匀密度是 2，它在 0.5 的长度上积出来才是 1。密度大于 1 一点问题也没有，概率大于 1 才有问题
④ 例题：把刚造好的密度用一次（本章主体）

这一道是本章自己出的题，跟下半那两道没有共同的情境，也没有共同的问法。 它只用得上第③幕刚造出来的东西，所以它检验的正是这一章。 题干先单独摆在这里，看完可以自己先动手算一遍，再往下读讲解。

例题. 一台机器一天里的空转时间占全天的比例记作 \(X\)。\(X\) 的概率密度函数是

\[ f(x) = \begin{cases} 2-2x, & 0 \le x \le 1 \\ 0, & \text{其余} \end{cases} \]

(a) Find \(P(X \le 0.1)\). (3 marks)
(b) Given that \(f(0)=2\), explain why this does not contradict the fact that a probability cannot exceed 1. (2 marks)

例题(a)  求 \(P(X \le 0.1)\)

① 题干拆解

「占全天的比例」这五个字撑住了取值范围：比例落在 0 与 1 之间， 所以两个端点用不着另找条件，题干那一行 \(0 \le x \le 1\) 只是把它写了出来。 分段写法里第二行那个 0 管着 \(0\) 到 \(1\) 以外的整条实轴，(a) 的积分下限因此写 0，不写 \(-\infty\)。 \(f(x)=2-2x\) 是一次函数，在 \(x=0\) 处取到最大值 2，在 \(x=1\) 处降到 0。

顺手核一句题干自己立不立得住：\(\int_0^1 (2-2x)\,dx = \big[2x-x^2\big]_0^1 = 2-1 = 1\)， 并且这一段上 \(f \ge 0\)。第③幕第 10、11 行那两条要求都满足，题干给的确实是一条合法的密度。

分值也在说话。(a) 给 3 分，配的是三样东西：一个带着上下限的积分式、一个原函数、一个数值。 (b) 给 2 分并且用的是 explain，配的是两句话。

② 题干昭示了哪个方法

Find \(P(X \le 0.1)\) 问的是一段区间的概率。第③幕第 8 行把区间的概率交给了积分， 所以主线是在这一段上积分。

别的方法在这里为什么不合适，值得逐条点一遍。把 \(f(0.1)=1.8\) 当成答案走不通， 那是把密度当成了概率，而第③幕第 12 行刚刚否掉这条路。 先求 \(F\) 再代值方向反了，题目给的是 \(f\)， \(F\) 还得先由 \(f\) 积出来，多绕一圈。 梯形面积这条路是通的，因为 \(f\) 在这里是一次函数， 着色的那一块正好是一个梯形；它在这道题里当验算，主线仍旧走积分， 理由是下一章要用到的是原函数这条路子。

③ 回接上半

用的是本章第③幕第 8 行 \(P(a \le X \le b)=\int_a^b f(x)\,dx\)。 那一行的来历是第①幕那个裂口：单个取值分不到概率，概率只好交给区间。 积分下限写 0 不写 \(-\infty\)，凭的是第③幕第 11 行那条归一化条件在区间外面留下的 0。

④ 公式为什么用这一条

同一个量有两条路可走，两条都摆出来。

  • 积分：\(P(X \le 0.1)=\int_0^{0.1}(2-2x)\,dx\)。它对任何形状的 \(f\) 都成立， 换成二次的密度（下半 Q2 就是二次的）照样能用。
  • 梯形面积：\(f\) 是直线，\(0\) 到 \(0.1\) 这一段下面是一个上底 \(f(0.1)=1.8\)、 下底 \(f(0)=2\)、高 \(0.1\) 的梯形，面积 \(\tfrac{2+1.8}{2}\times 0.1\)。它只在 \(f\) 是直线的时候好用。

这道题走积分，理由有两条：一条是它可以迁移，另一条是原函数 \(2x-x^2\) 正是这个 \(X\) 的 \(F\)， 下一步问别的区间的时候直接拿来代值就行。梯形那条留着当第⑤样末尾的横向检查。

⑤ 每个等号一行，每一行写出依据
行写下的东西这一行凭什么
1\(P(X \le 0.1) = P(0 \le X \le 0.1)\) \(X\) 落在 \(0\) 到 \(1\) 之外的概率是 0（题干第二行），所以下限从 0 起算，不从 \(-\infty\) 起算
2\(= \displaystyle\int_0^{0.1} (2-2x)\,dx\) 第③幕第 8 行：一段区间的概率等于密度在这一段上的积分
3\(\displaystyle\int (2-2x)\,dx = 2x - x^2\) 逐项积分，\(\int x^n dx = \tfrac{x^{n+1}}{n+1}\)（\(n \ne -1\)）。定积分不必写积分常数
4\(x=0.1:\ 2(0.1)-(0.1)^2 = 0.2 - 0.01 = 0.19\) 代上限。\((0.1)^2 = 0.01\) 这一步单独写出来，是因为平方的小数点最容易挪错位
5\(x=0:\ 2(0)-0^2 = 0\) 代下限。下限是 0 的时候这一行常常被跳过去，写出来是为了让第 6 行的减法有两个端点可减
6\(P(X \le 0.1) = 0.19 - 0 = 0.19\) 微积分基本定理（fundamental theorem of calculus），上限的值减去下限的值

横向再查一遍每一行自己立不立得住。\(0.19\) 落在 0 与 1 之间，概率的取值范围没有越界； 概率没有单位，量纲这一项不必对；上限 \(0.1\) 落在 \([0,1]\) 里面，用的是同一段解析式， 不必分段讨论。最后拿梯形那条路验一次：\(\tfrac{2+1.8}{2}\times 0.1 = 1.9 \times 0.1 = 0.19\)， 两条路对上了。

⑥ 得分位置

M1 给带着上下限 \(0\) 与 \(0.1\) 的积分式（第 2 行）。 M1 给正确的原函数 \(2x-x^2\)（第 3 行）。 A1 给 \(0.19\)。 下限误写成 \(-\infty\) 而得到发散的积分，第一个方法分就没有了， 因为那一步说明区间外的 0 没有用上。 这道题是本章自己出的，分值照 Edexcel 同类题的样子给。

例题(b)  \(f(0)=2\) 为什么不跟「概率不超过 1」冲突

① 题干拆解

题干把两句话摆在一起：\(f(0)=2\) 是从解析式里直接读出来的（\(2-2\times 0 = 2\)）， 「概率不会大于 1」是概率自己的性质。题目问的是它们为什么并不冲突， 所以答案要落在「\(f\) 到底是什么」这一点上。2 分、explain，要的是两句话。

② 题干昭示了哪个方法

explain 加上 2 分，昭示的是不必动手积分。 这里算出任何一个数都不得分，因为题目问的不是某个概率的值。 出题人等的是一句定义层面的话。看到 explain 就开始积分，说明信号读反了。

③ 回接上半

回接第③幕造完密度那一刻掉出来的第一件事（第 12 行）：密度不是概率。 那一行当时是顺带掉出来的推论，这一问把它单独拿出来考一次。

④ 公式为什么用这一条

用的仍旧是 \(P(a \le X \le b)=\int_a^b f(x)\,dx\)，只是这一次读它的方式反过来： 它说的是概率等于 面积，而 \(f(x)\) 只是这块面积的高。 高可以大于 1，面积照旧可以不超过 1，只要底足够短。

⑤ 一句一句写出来，每一句写出依据
句写下的东西这一句凭什么
1\(f(0)=2\) 的读法是「在 \(x=0\) 附近，每单位比例上的概率是 2」 第③幕第 9 行：\(f\) 是概率对长度的变化率，它的单位是「概率每单位 \(x\)」，本身不是概率
2概率是 \(f\) 下面的面积，不是 \(f\) 的高 第③幕第 8 行。面积等于高乘以底，底一短，面积就小
3\(P(0 \le X \le 0.1) = 0.19 \le 1\) (a) 已经算出来了。高是 2 的那一段，面积只有 0.19
4\(P(X=0)=0\) 第③幕第 13 行。单点的区间长度是 0，面积是 0。\(f(0)=2\) 与 \(P(X=0)=0\) 同时成立，正说明这两样是两回事
⑥ 得分位置

B1 说出密度不是概率（或者：\(f(x)\) 是单位长度上的概率）。 B1 说出概率是密度下面的面积或者积分，面积不超过 1。 只写「因为这是密度」拿不到第二分，那句话没有回答面积为什么仍旧不超过 1。

两问走完，这一章造出来的那个东西被完整地用了一次： 密度给出高，积分把高变成面积，面积才是概率。 下半那两道题换了情境、换了函数、换了问法，用的仍旧是这三句话。

⑤ 另一种看法（一两句）

贝特朗那三个答案到底谁对，两种回答到今天还没有合并。 柯尔莫哥洛夫（Andrey Kolmogorov）1933 年在《概率论基础》 （Grundbegriffe der Wahrscheinlichkeitsrechnung）里说：先指定测度，再谈概率； 三个答案各自对应一种取法，三个都对，问题问得不完整。 杰恩斯（E. T. Jaynes）1973 年在《The Well-Posed Problem》里说： 题目没有提到圆的位置、大小与朝向，平移、缩放、旋转这三条不变性合起来只留下 \(\tfrac{1}{2}\)。分歧收敛在一步上：问题陈述里没说的东西，算不算一种信息。 我在这里没有立场，只是转述两边。

⑥ 它自己承认的边界

密度只在「有密度」的分布上存在，第③幕第 7 行已经把条件写在脸上： 那一行要求极限存在，也就是 \(F\) 可导。\(F\) 不可导的地方，密度没有定义。

两个现成的例子。混合型分布：一份保险的赔付额 \(Y\)，有 0.7 的概率恰好是 0 （这一年没有出险），剩下 0.3 连续地分布在正数上；\(F\) 在 0 这一点向上跳了 0.7， 跳跃处没有导数，\(Y\) 没有一个处处适用的密度。康托尔分布：\(F\) 处处连续、 没有任何跳跃，导数却在几乎所有点上都是 0，积出来是 0 而不是 1，密度同样不存在。 有名有姓的批评一条：狄拉克（Paul Dirac）1930 年在《量子力学原理》里用的 \(\delta\) 函数在函数的意义上并不存在，要等到施瓦茨（Laurent Schwartz） 1950 年前后的分布理论才站得住，密度的适用范围比它被使用的范围窄。

结论落在一句话上：\(F\) 处处都有，密度不一定有，所以 \(F\) 是更基本的那一个。 课本为什么总是从 \(F\) 出发，答案就在这里。

第二章 · 均匀分布：把「没有偏好」写成一条水平线

① 先造出那个缺口

第一章造出了密度这个工具，手上却还没有任何一条具体的密度。 题目给的是一句中文：这列火车的偏差「等可能地落在 \(-1.4\) 到 \(6.6\) 之间」。 这句话要变成一个可以积分的 \(f\)。

麻烦在于「等可能」这三个字在这里失效了。离散场合它的意思很清楚： 每个结果的概率相同，六个面各 \(\tfrac{1}{6}\)。 连续场合按第一章第 12 行，每个取值的概率都已经是 0， 「相同」于是变成 \(0 = 0\)，这句话什么也没有说出来。

缺口：「没有偏好」这句话，怎么写成一条密度。

② 它从哪里来（两三句）

拉普拉斯（Pierre-Simon Laplace）1814 年在《概率的哲学随笔》 （Essai philosophique sur les probabilités）里把这句话立成了一条原则： 没有任何理由偏向其中某一个的时候，就把它们当作等可能的。 他用这条原则处理过太阳明天照常升起的概率，也用它处理过法庭判决的可靠性。

凯恩斯（John Maynard Keynes）1921 年在《概率论》（A Treatise on Probability） 里给这条原则起了现在通用的名字，叫无差别原则（principle of indifference）， 同时指出它会自己跟自己打架。第⑥幕会把他举的那一类反例摆出来。

名字有了，可用的式子还没有。下一幕从「没有偏好」这句话本身出发，把式子造出来。 （均匀分布在统计里还有一个很深的位置：任何一个连续随机变量把自己的 \(F\) 作用在自己身上， 得到的 \(U=F(X)\) 都服从 \(U(0,1)\)，这叫概率积分变换（probability integral transform）。 假设检验里「取显著性水平 5%」这句话之所以成立，靠的正是它；计算机只会生成 \(U(0,1)\)， 别的分布都是把这一条倒过来变出来的。来历在这里就这么长。）

③ 把公式一步一步造出来

先把「没有偏好」翻译成一句可以检验的话。它的意思是： 同样长的两段，出现的机会一样大，跟这两段落在什么位置无关。 位置无关这一条是关键，它把一句心理上的话变成了一个数学要求。

行写下的东西这一行凭什么
1\(g(h) = P(X \in \text{任何一段长为 } h \text{ 的子区间})\) 「跟位置无关」这句话，意思正是这个概率只由长度 \(h\) 决定。于是它可以写成一个只有一个变量的函数
2\(g(h_1+h_2) = g(h_1) + g(h_2)\) 把一段长 \(h_1+h_2\) 的区间从中间切开，两块互不相交，概率相加（第一章第 4 行）
3\(g(h) = c\,h\) 第 2 行是柯西函数方程（Cauchy's functional equation）。\(g\) 单调不减，这个条件足以把它的解锁定成正比例函数。\(c\) 是待定的常数
4\(P(x \lt X \le x+h) = c\,h \Rightarrow f(x) = \lim\limits_{h\to 0}\dfrac{c\,h}{h} = c\) 代进第一章第 7 行那个定义。密度是一个常数，这就是那条水平线
5\(\displaystyle\int_a^b c\,dx = c\,(b-a) = 1\) 第一章第 11 行，总概率是 1；区间外面密度为 0，所以只在 \(a\) 到 \(b\) 上积
6\(c = \dfrac{1}{b-a}\) 第 5 行两边同除以 \(b-a\)。这里用得上 \(b \gt a\)，所以 \(b-a \ne 0\)

到这一刻才给它命名：连续均匀分布（continuous uniform distribution）， 记作 \(X \sim U(a,\,b)\)，读作「\(X\) 服从 \(a\) 到 \(b\) 上的均匀分布」。 它的密度写全是这样：

\[ f(x) = \begin{cases} \dfrac{1}{b-a}, & a \le x \le b \\[6pt] 0, & \text{其余} \end{cases} \]

下面那一行 \(0\) 是密度的一部分，省掉它，第 5 行那个「只在 \(a\) 到 \(b\) 上积」就没有了依据。 下半 Q1(a) 的 specify fully 要的正是这一行。

期望：为什么它落在正中间

图形左右对称，重心落在中点，所以期望是 \(\tfrac{a+b}{2}\)。这句话是对的， 可是它只是文字层。下面把符号层补上，每个等号一行。

行写下的东西这一行凭什么
1\(E(X) = \displaystyle\int_{-\infty}^{\infty} x\,f(x)\,dx\) 连续型期望的定义式。它是离散型 \(\sum x\,P(X=x)\) 的连续版本：把「取值乘以概率再相加」换成「取值乘以密度再积分」
2\(= \displaystyle\int_a^b \frac{x}{b-a}\,dx\) 区间外面 \(f = 0\)，那两段积出来是 0；区间里面代入第 6 行
3\(= \dfrac{1}{b-a}\displaystyle\int_a^b x\,dx\) \(\tfrac{1}{b-a}\) 与 \(x\) 无关，常数因子可以提到积分号外面
4\(= \dfrac{1}{b-a}\left[\dfrac{x^2}{2}\right]_a^b = \dfrac{b^2-a^2}{2(b-a)}\) \(\int x\,dx = \tfrac{x^2}{2}\)，代上限减代下限
5\(= \dfrac{(b-a)(b+a)}{2(b-a)} = \dfrac{a+b}{2}\) 平方差公式 \(b^2-a^2=(b-a)(b+a)\)；约掉 \(b-a\)，约之前先确认 \(b-a \ne 0\)（第 6 行已经确认过）

「重心在中点」这句话，到第 5 行才算兑现。同一条路再走一遍可以拿到方差： \(E(X^2) = \dfrac{b^3-a^3}{3(b-a)} = \dfrac{a^2+ab+b^2}{3}\)， 减去 \(\mu^2 = \dfrac{(a+b)^2}{4}\)，通分之后分子是 \(a^2-2ab+b^2\)， 于是 \(\mathrm{Var}(X) = \dfrac{(b-a)^2}{12}\)。 分母那个 12 不是记号约定，它是通分之后剩下来的东西。

④ 例题：把这条水平线用一次（本章主体）

这一道同样是本章自己出的题。下半的 Q1 给了两个端点，正着求密度、期望与概率； 这一道反过来走：给一个概率，反求端点。情境、方向、问法都跟下半那两道不一样， 用到的仍旧只有第③幕造出来的这条水平线。

例题. 一段长 \(a\) 厘米的细绳在一个随机的位置被剪断。 剪断处到左端的距离记作 \(X\) 厘米，\(X\) 服从 \(0\) 到 \(a\) 之间的连续均匀分布。 已知 \(P(X \lt 12) = 0.3\)。

(a) Find the value of \(a\). (3 marks)
(b) Find \(P(20 \lt X \lt 32)\). (2 marks)

例题(a)  求 \(a\) 的值

① 题干拆解

「在一个随机的位置被剪断」这一句就是「没有偏好」，它是第③幕开头那句话的原样， 所以这里可以直接用均匀分布，用不着再论证一次。 「到左端的距离」把左端点钉成 0：距离从左端量起，最小值是 0。 右端点是 \(a\)，绳子有多长，距离最大就是多少；\(a\) 没有给出来，正是要求的那个东西。

\(P(X \lt 12)=0.3\) 这一句给了两样东西：一个位置 12，一个概率 0.3。 0.3 落在 0 与 1 之间而且两头都不取到，说明 12 落在区间里面， 也就是 \(a \gt 12\)。这一句在最后当横向检查用。 3 分配的是三样：一条把 \(a\) 装进去的式子、一次解方程、一个数值。

② 题干昭示了哪个方法

题目给的是概率、要的是端点，方向是反的。所以这里的动作是列一条含 \(a\) 的方程再解它， 而不是代进公式算一个数。

别的方法为什么不合适。\(E(X)=\tfrac{a+b}{2}\) 用不上，题目一个字都没有提期望。 把 \(f(12)\) 算出来更走不通：\(f\) 是常数 \(\tfrac{1}{a}\)，跟 12 没有关系， 而且密度不是概率（第一章第③幕第 12 行）。 先写 \(F\) 再代 12 这条路是通的，它和下面那条积分的路子是同一件事的两种写法。

③ 回接上半

用的是本章第③幕第 6 行 \(f(x)=\tfrac{1}{b-a}\)，这里 \(b-a = a-0 = a\)。 更深一层是第③幕第 1 行那句话：概率只由长度决定。 它让「\(0\) 到 12 这一段的概率」可以写成「12 除以总长」，方程于是列得出来。

④ 公式为什么用这一条

两条路都摆出来，它们同源。

  • 密度加积分：\(P(X \lt 12)=\int_0^{12}\tfrac{1}{a}\,dx = \tfrac{12}{a}\)。 这条路对任何密度都成立，写出 \(f=\tfrac{1}{a}\) 那一步就拿到了方法分。
  • 长度比：\(P = \dfrac{\text{那一段的长}}{\text{总长}} = \dfrac{12}{a}\)。 它是第③幕第 3 行 \(g(h)=ch\) 的直接读法，考场上更快。

这道题两条写哪一条都拿满分。下面走密度那一条，因为它把 \(f=\tfrac{1}{a}\) 这一步落在了纸上， 阅卷人看得见方法；长度比那一条留着当横向检查。

⑤ 每个等号一行，每一行写出依据
行写下的东西这一行凭什么
1\(X \sim U(0,\ a)\) 「随机的位置」给出均匀，「到左端的距离」给出左端点 0，绳长给出右端点 \(a\)
2\(f(x) = \dfrac{1}{a-0} = \dfrac{1}{a},\quad 0 \le x \le a\) 第③幕第 6 行 \(f=\tfrac{1}{b-a}\)，代入 \(b=a\)、\(a_{\text{左}}=0\)
3\(P(X \lt 12) = \displaystyle\int_0^{12}\frac{1}{a}\,dx\) 第一章第③幕第 8 行。下限写 0，因为区间外的密度是 0
4\(= \Big[\dfrac{x}{a}\Big]_0^{12} = \dfrac{12}{a} - 0 = \dfrac{12}{a}\) \(\tfrac{1}{a}\) 与 \(x\) 无关，可以提到积分号外面；\(\int dx = x\)
5\(\dfrac{12}{a} = 0.3\) 题干给的那句 \(P(X \lt 12)=0.3\)，把第 4 行的结果接上去
6\(a = \dfrac{12}{0.3} = 40\) 两边乘 \(a\) 再除以 0.3。\(a\) 是绳长，\(a \ne 0\)，所以乘除都合法

横向查一遍。\(a = 40 \gt 12\)，跟第①样里那句「12 落在区间里面」对得上； 单位是厘米，跟题干一致；拿长度比那条路验一次，\(\tfrac{12}{40}=0.3\)，两条对上了。

⑥ 得分位置

M1 写出 \(\tfrac{12}{a}\)（积分式或者长度比都算）。 M1 列出方程 \(\tfrac{12}{a}=0.3\) 并且动手解它。 A1 给 \(a=40\)。 漏掉单位不扣分，把 \(a\) 解成 \(12 \times 0.3 = 3.6\) 的时候， 横向那一句「\(a\) 要大于 12」当场就能拦住。

例题(b)  求 \(P(20 \lt X \lt 32)\)

① 题干拆解

(a) 已经把 \(a\) 定成 40，所以这一问的区间是 \([0,40]\)。 20 与 32 都落在里面，两头都没有被截断，整段都在密度非零的那一片上。 这一段的长度是 \(32-20=12\)。12 这个数刚刚出现过， 它正是 (a) 里那一段的长度。

② 题干昭示了哪个方法

2 分，而且紧接在 (a) 后面，昭示的是上一问的答案要用上。 更省事的一条信号藏在长度里：这一段与 (a) 里那一段一样长，都是 12。 第③幕第 1 行说概率只由长度决定，跟位置无关， 所以答案跟 (a) 里给出的 0.3 相同，一步计算都不必做。

考场上照常列式当然也对，两分照拿。把这条信号点出来，是因为它正是这一章的那句话本身： 同样长的两段，机会一样大。

③ 回接上半

回接第③幕第 1 行：\(g(h)\) 只跟长度 \(h\) 有关。 那一行当时是为了把「没有偏好」写成一个数学要求，这一问把它反过来用了一次。

④ 公式为什么用这一条

仍旧是长度比与积分两条，同源。这一问走长度比，因为区间的两个端点都在里面， 密度是常数，积分算出来就是长度乘以 \(\tfrac{1}{40}\)，中间那一步没有新东西。 积分那条留着当横向检查。

⑤ 每个等号一行，每一行写出依据
行写下的东西这一行凭什么
1\(0 \le 20 \lt 32 \le 40\) 先确认两个端点都落在 \([0,40]\) 里面。落在外面的话要先截断，这一行是为了排除那种情形
2\(P(20 \lt X \lt 32) = \dfrac{32-20}{40}\) 第③幕第 1 行与第 6 行：概率等于这一段的长度乘以常数密度 \(\tfrac{1}{40}\)
3\(= \dfrac{12}{40} = 0.3\) \(32-20=12\)；\(12 \div 40 = 0.3\)
4\(P(20 \lt X \lt 32) = P(X \lt 12)\) 两段一样长，都是 12。第③幕第 1 行说概率只由长度决定，所以这两个概率相等

横向查一遍。拿积分那条路验一次：\(\int_{20}^{32}\tfrac{1}{40}\,dx = \big[\tfrac{x}{40}\big]_{20}^{32} = \tfrac{32}{40}-\tfrac{20}{40} = 0.3\)，对上了。 \(0.3\) 落在 0 与 1 之间；连续型里 \(P(X=20)=P(X=32)=0\)， 所以不等号写成严格的还是带等号的，答案一样。

⑥ 得分位置

M1 给正确的区间长度与总长（\(\tfrac{12}{40}\)，或者等价的积分式）。 A1 给 \(0.3\)。 直接写「与 (a) 相同，等于 0.3」并且说明理由是两段一样长，同样拿满两分。

两问走完，这一章那句话被用了一个来回： 先由「概率只由长度决定」反求出总长，再由同一句话看出两段等长就等概率。

⑤ 另一种看法（一两句）

把均匀分布当作「我一无所知」的表达，这个用法有过一场很长的争论。 拉普拉斯那一边：不知道参数是多少，就给它一个均匀先验。 杰弗里斯（Harold Jeffreys）1946 年在《An invariant form for the prior probability in estimation problems》里指出这个做法不稳，\(\theta\) 上的均匀分布换成 \(\theta^2\) 描述同一件事的时候就不再均匀，于是他提出用 Fisher 信息构造的先验，它在参数重写之下保持不变。 杰恩斯 1968 年在《Prior Probabilities》里接着往下走，主张先验应当由问题自己的变换群定出来。 可检验的后果落在同一处：同一批数据、不同的先验，算出来的区间估计不一样。 我在这里没有立场，只是转述两边。

⑥ 它自己承认的边界

第一条边界写在第③幕第 6 行里：\(c=\tfrac{1}{b-a}\) 要求 \(b-a\) 是一个有限的正数。 区间无界的时候这条路走不通。假设在整条实轴上有一个常数密度 \(c\)： \(c=0\) 积出来是 0，\(c \gt 0\) 积出来是无穷，两种都不等于 1。 「在无穷大的范围里完全没有偏好」这句话写不成一条密度。

第二条边界是第②幕欠下的那一笔，也是那条有名有姓的批评：凯恩斯 1921 年指出无差别原则会自相矛盾。 一个立方体的边长在 1 到 2 之间，此外一无所知；按边长均匀，中位数边长 1.5，对应体积 3.375； 按体积均匀（体积在 1 到 8 之间），中位数体积 4.5，对应边长约 1.65。 同一份无知，两种写法，两个答案。 所以「均匀」依赖于用哪一个量去描述，题目没有指定那个量的时候，均匀分布本身是不确定的。 这一条跟第一章第⑤幕的贝特朗悖论是同一件事在两处的样子。 考试里的题目会把那个量写清楚（例题写的是「距离」，下半 Q1 写的是「时间」）， 记住这条边界，是为了知道那句话在替我们做一个选择。

Q1. 一列蒸汽小火车相对时刻表的偏差记作 \(W\) 分钟，负数表示早到。 \(W\) 服从 \(-1.4\) 到 \(6.6\) 之间的连续均匀分布。

(a) Specify fully the probability density function \(f(w)\) of \(W\). (2 marks)
(b) Find \(E(W)\). (2 marks)
(c) Find \(P(W \gt 3)\). (2 marks)

Q1(a)  写出 \(W\) 的概率密度函数

① 题干拆解

「相对时刻表的偏差」加上「负数表示早到」这两句话合起来告诉我们取值可以是负的， 所以区间的左端点是 \(-1.4\) 而不是 \(1.4\)。 「\(-1.4\) 到 \(6.6\)」给出两个端点，区间长度 \(6.6-(-1.4)=8\)。 「连续均匀分布」是题目直接给的分布名。 「\(f(w)\)」这个记号说明答案要用 \(w\) 当变量，跟着题目走。 2 分这个分值，配的是两样东西：一个常数值，一个完整的定义域。

② 题干昭示了哪个方法

关键的词是 specify fully。它要的是把 \(f\) 在整条实轴上都写出来， 区间外面那一行「其余为 0」同样要写。 只写 \(f(w)=\tfrac{1}{8}\) 在这里不够用：那样写的话 \(f\) 只在一段上有定义， 第一章第 11 行那个 \(\int_{-\infty}^{\infty} f = 1\) 就没有了着落， 而这道题接下来两问都靠它。

③ 回接上半

用的是第二章第③幕造出来的那条：从「跟位置无关」推到常数密度（第 4 行）， 再由总概率为 1 定出这个常数（第 5、6 行）。 分段的那个写法就是那一幕末尾的式子，把字母换成这道题的数字。

④ 公式为什么用这一条

有两条路可以走。一条是直接用 \(f(w)=\tfrac{1}{b-a}\)； 另一条是先写累积分布函数 \(F(w)=\tfrac{w-a}{b-a}\)，再求导。 两条都通，第一条更短，因为题目已经把「均匀」这个词给出来了， 常数密度可以直接拿来用。第二条在题目只给 \(F\) 的时候才需要。

⑤ 每个等号一行，每一行写出依据
行写下的东西这一行凭什么
1\(W \sim U(-1.4,\ 6.6)\) 题目给的分布名与两个端点，翻译成记号。\(a=-1.4\)，\(b=6.6\)
2\(b-a = 6.6-(-1.4) = 6.6+1.4 = 8\) 减去一个负数等于加上它的相反数。这一步单独写出来，是因为负号在这里最容易掉
3\(f(w) = \dfrac{1}{b-a} = \dfrac{1}{8} = 0.125\) 第二章第③幕第 6 行。分数与小数写哪一个都可以，写小数的时候留意 \(0.125\) 是有限小数，没有精度损失
4\(f(w) = \begin{cases} 0.125, & -1.4 \le w \le 6.6\\ 0, & \text{其余}\end{cases}\) specify fully 要的完整形式。第二行那个 0 覆盖了实轴上其余的全部位置
⑥ 得分位置

B1 给常数值 \(0.125\)（或 \(\tfrac{1}{8}\)）。 B1 给完整的分段形式，含区间与「其余为 0」那一行。 只写常数、漏掉分段的答案拿一分。

Q1(b)  求 \(E(W)\)

① 题干拆解

这一问接着 (a) 的设定，没有新的条件。 \(E(W)\) 问的是这列火车「平均偏差多少分钟」，答案带单位，是分钟。 2 分对应两样：一条公式，一个数值。

② 题干昭示了哪个方法

题目在 (a) 里已经确认了均匀分布，所以这里可以直接用均匀分布的期望公式， 不必回到 \(\int w f(w)\,dw\) 那条定义式。 定义式当然算得出来，只是要多写三行，而这一问只给 2 分，出题人等的是那条现成的式子。

③ 回接上半

第二章第③幕「期望：为什么它落在正中间」那张表，五行推导的终点就是 \(\tfrac{a+b}{2}\)。 那一幕还说明了这条式子的来路：它是重心落在中点这句话的兑现， 不是一条需要单独记忆的规定。

④ 公式为什么用这一条

\(E(X)=\dfrac{a+b}{2}\) 这一条在公式册里印着，可以直接引用。 另一条路是 \(E(W)=\int_{-1.4}^{6.6} 0.125\,w\,dw\)， 它在密度不是常数的时候才必须用（比如下面的 Q2）。 两条路给出同一个答案，选短的那一条。

⑤ 每个等号一行，每一行写出依据
行写下的东西这一行凭什么
1\(E(W) = \dfrac{a+b}{2}\) 均匀分布期望的一般式，公式册里有；适用条件是 \(W\) 服从均匀分布，(a) 已经确认
2\(= \dfrac{-1.4+6.6}{2}\) 把这道题的 \(a=-1.4\)、\(b=6.6\) 代进去。字母先于数字，代入单独占一行
3\(= \dfrac{5.2}{2}\) 先算分子。这一步留着，方法分有落点，也让下一步只剩一次除法
4\(= 2.6\) 除法算完。单位是分钟，写成「平均晚 2.6 分钟」

第 3 行常常被合并掉。写着它的好处是：万一 \(5.2\) 这个数算错了， 错的位置当场看得见，而合并之后错误藏在一个等号里面。

⑥ 得分位置

M1 给写出 \(\tfrac{a+b}{2}\) 或者正确代入的算式。 A1 给 \(2.6\)。带上单位不扣分，漏掉单位在这一类题里通常也不扣，写上更稳。

Q1(c)  求 \(P(W \gt 3)\)

① 题干拆解

\(P(W \gt 3)\) 问的是偏差超过 3 分钟的概率。 严格大于还是大于等于，在连续分布里给出同一个答案， 理由是第一章第 12 行：单点的概率是 0。 3 落在 \(-1.4\) 与 \(6.6\) 之间，所以这是区间内部的一次切分， 不涉及区间外面那一段。

② 题干昭示了哪个方法

密度是常数，这一点让「面积」退化成「矩形面积」，宽乘高就够了。 题目没有写 algebraic integration 或者 by integration， 所以长度比这条捷径可以直接用。 题目要是写了 using algebraic integration，那就得把 \(\int_3^{6.6} 0.125\,dw\) 写出来， 面积公式再快也替代不了那两行。

③ 回接上半

第二章那张图里深色的那一块，就是这一问要的面积。 它成立的依据是第③幕第 3 行：概率与长度成正比，比例系数是 \(\tfrac{1}{b-a}\)。

④ 公式为什么用这一条

两条路摆在一起看：

路径一，长度比：\(P(W \gt 3) = \dfrac{6.6-3}{6.6-(-1.4)}\)。 路径二，积分：\(P(W \gt 3) = \int_3^{6.6} 0.125\,dw\)。

两条路的第一步是同一件事，路径一把「常数乘以长度」这一步直接写成了比值。 密度是常数的时候选路径一；密度随 \(x\) 变化的时候（Q2）路径一失效， 因为那时候概率与长度不再成正比。

⑤ 每个等号一行，每一行写出依据
行写下的东西这一行凭什么
1\(P(W \gt 3) = \displaystyle\int_3^{6.6} f(w)\,dw\) 第一章第 9 行。上限取 \(6.6\) 而不是 \(\infty\)，因为 \(6.6\) 以上密度为 0（(a) 的第二行）
2\(= 0.125 \times (6.6-3)\) 被积函数是常数，积出来等于常数乘以区间长度。这一行也可以读成矩形的宽乘高
3\(= 0.125 \times 3.6\) 先把括号里的长度算出来
4\(= 0.45\) 乘法算完。概率落在 0 与 1 之间，数值合理

横向查一遍第 4 行：\(0.45\) 是一个概率，它落在 0 到 1 之间，量级也说得通， 因为 3 分钟比中点 2.6 稍微靠右一点，答案应当略小于 0.5。

⑥ 得分位置

M1 给正确的区间与方法（长度比或者积分都算）。 A1 给 \(0.45\)。 上限误用 \(\infty\) 而写成发散的积分，方法分也拿不到，因为那一步说明区间外的 0 没有用上。

Q2. 一段旅程所花的时间记作 \(S\) 分钟，它的概率密度函数是

\[ f(s) = \begin{cases} k\,(s-2)(10-s), & 2 \le s \le 10 \\ 0, & \text{其余} \end{cases} \]

(a) Show that \(k = \dfrac{3}{256}\). (5 marks)
(b) Find \(P(S \le 4)\). (4 marks)
(c) Write down \(E(S)\). (1 mark)

Q2(a)  证明 \(k = \dfrac{3}{256}\)

① 题干拆解

密度写成了分段的形式，区间外面那一行 0 已经给出来了， 它的用处是把积分范围锁定在 2 到 10 上。 \(k\) 是一个待定常数，题目管它叫 constant，说明它与 \(s\) 无关，可以提到积分号外面。 Show that 加上 5 分，两样合起来说明这一问要的是完整过程。 答案 \(\tfrac{3}{256}\) 已经印在题面上，写出这个数拿不到分，中间那几行才是分。

② 题干昭示了哪个方法

题目给了一个待定常数，同时给了一个完整的密度，这两样凑在一起只指向一个方法： 归一化条件 \(\int f = 1\)。这是唯一一条把「未知常数」与「已知的 1」连起来的式子。

Show that 这个词还额外要求一件事：目标已经给出来了， 每一步都要落在纸上，跳步会被扣过程分。 在这里直接写「由 \(\int f=1\) 得 \(k=\tfrac{3}{256}\)」拿不到中间那三分。

③ 回接上半

第一章第 11 行：\(\int_{-\infty}^{\infty} f(x)\,dx = 1\)。 那一行是从 \(F(\infty)=1\) 推出来的，它就是「\(X\) 总要取到某个值」 这句话写成积分的样子，用不着当作一条额外的规定去记。

④ 公式为什么用这一条

这里没有第二条路。密度里带着未知常数的时候，能够定出它的条件只有总面积为 1。 需要留意的是积分范围：写成 \(\int_{-\infty}^{\infty}\) 也对， 只是区间外面那两段积出来是 0，所以实际写的时候从 2 积到 10。 这一步的依据是题目给的第二行，不是习惯。

⑤ 每个等号一行，每一行写出依据
行写下的东西这一行凭什么
1\(\displaystyle\int_2^{10} k\,(s-2)(10-s)\,ds = 1\) 总概率为 1（第一章第 11 行）；密度在 2 到 10 之外为 0，所以只在这一段上积
2\(k \displaystyle\int_2^{10} (s-2)(10-s)\,ds = 1\) \(k\) 与 \(s\) 无关，定积分对常数因子是线性的，可以提到积分号外面
3\((s-2)(10-s) = 10s - s^2 - 20 + 2s = -s^2 + 12s - 20\) 多项式乘法，逐项展开；展开之后才好逐项积分
4\(\displaystyle\int (-s^2+12s-20)\,ds = -\dfrac{s^3}{3} + 6s^2 - 20s\) \(\int s^n ds = \tfrac{s^{n+1}}{n+1}\)（\(n \ne -1\)），逐项求原函数；定积分不必写常数 \(C\)
5\(s=10:\ -\dfrac{1000}{3} + 600 - 200 = -\dfrac{1000}{3} + \dfrac{1200}{3} = \dfrac{200}{3}\) 代上限；\(400\) 通分写成 \(\tfrac{1200}{3}\) 再相加
6\(s=2:\ -\dfrac{8}{3} + 24 - 40 = -\dfrac{8}{3} - \dfrac{48}{3} = -\dfrac{56}{3}\) 代下限；\(-16\) 通分写成 \(-\tfrac{48}{3}\)。这一行的负号是这道题最常出错的位置
7\(\dfrac{200}{3} - \left(-\dfrac{56}{3}\right) = \dfrac{256}{3}\) 微积分基本定理，上限的值减去下限的值；减去负数等于加上正数
8\(k \times \dfrac{256}{3} = 1 \Rightarrow k = \dfrac{3}{256}\) 回到第 2 行那条式子，两边同除以 \(\tfrac{256}{3}\)，也就是同乘 \(\tfrac{3}{256}\)

八行，每一行有依据，每一行单独拿出来看都挑不出毛病。 把这八行压成三行的时候，第 6 行那个 \(-\tfrac{56}{3}\) 一旦写错， 最终答案照样能凑对（因为答案已经印在题面上），错误就没有地方露出来。 一步一行的好处是错的那一步在写的当下就被自己看见。

⑥ 得分位置

M1 写出 \(\int_2^{10} f(s)\,ds = 1\)。 M1 正确展开被积式。 M1 求出原函数。 A1 得到 \(\tfrac{256}{3}\)。 A1 解出 \(k=\tfrac{3}{256}\)。 Show that 题里，最后那一分只给完整过程，直接抄答案不给分。

Q2(b)  求 \(P(S \le 4)\)

① 题干拆解

\(P(S \le 4)\) 要的是从密度的左端点积到 4。 左端点是 2 而不是 \(-\infty\)，理由是 2 以下密度为 0。 \(k\) 在上一问已经定下来，这里可以直接用 \(\tfrac{3}{256}\)。 4 分说明这一问的过程比 Q1(c) 长。

② 题干昭示了哪个方法

密度是一条抛物线，随 \(s\) 变化，所以 Q1(c) 那条长度比在这里失效： 概率与长度不再成正比。剩下的路只有积分。 题干「Given that…」式的提示这里没有出现，而 (a) 的答案正是这一问的输入， 这也是小问顺序给出的信号：先回头看上一问。

③ 回接上半

第一章第 9 行：\(P(a \le X \le b) = \int_a^b f(x)\,dx\)。 那一行是第 5 行与第 8 行接起来的结果， 所以这一问算的其实是 \(F(4) - F(2)\)，而 \(F(2)=0\)。

④ 公式为什么用这一条

原函数在 (a) 的第 4 行已经求过了，这一问换一组上下限再用一次。 另一种写法是先求出 \(F(s)\) 的表达式再代入 4， 它在同一道题要问好几个概率的时候更省事；只问一次的时候，直接定积分更短。

⑤ 每个等号一行，每一行写出依据
行写下的东西这一行凭什么
1\(P(S \le 4) = \displaystyle\int_2^{4} \dfrac{3}{256}(s-2)(10-s)\,ds\) 第一章第 9 行；下限取 2 是因为 2 以下密度为 0，\(k\) 用 (a) 的结果
2\(= \dfrac{3}{256}\displaystyle\int_2^{4} (-s^2+12s-20)\,ds\) 常数因子提到外面；被积式用 (a) 第 3 行展开好的形式
3\(= \dfrac{3}{256}\left[-\dfrac{s^3}{3}+6s^2-20s\right]_2^{4}\) 原函数与 (a) 第 4 行相同，换成新的上下限
4\(s=4:\ -\dfrac{64}{3}+96-80 = -\dfrac{64}{3}+\dfrac{48}{3} = -\dfrac{16}{3}\) 代上限；\(96-80=16\)，通分写成 \(\tfrac{48}{3}\)
5\(s=2:\ -\dfrac{56}{3}\) 代下限；这个值在 (a) 第 6 行已经算过，直接引用
6\(-\dfrac{16}{3}-\left(-\dfrac{56}{3}\right) = \dfrac{40}{3}\) 上限的值减去下限的值
7\(P(S \le 4) = \dfrac{3}{256}\times\dfrac{40}{3} = \dfrac{40}{256} = \dfrac{5}{32}\) 分子分母同时约掉 3，再约掉 8。约分之前确认 3 与 8 都不为 0
8\(= 0.15625\) 化成小数。答案落在 0 与 1 之间

横向再查一眼：整条密度关于 \(s=6\) 对称，4 落在中点左边， 所以答案应当明显小于 \(0.5\)，\(0.156\) 说得通。

⑥ 得分位置

M1 写出带正确上下限的积分。 M1 代入上下限。 A1 得到 \(\tfrac{40}{3}\) 或等价值。 A1 得到 \(\tfrac{5}{32}\) 或 \(0.15625\)。 下限写成 0 或者 \(-\infty\) 是这一问最常见的丢分处。

Q2(c)  写出 \(E(S)\)

① 题干拆解

\(E(S)\) 问的是这段旅程的平均时间，单位是分钟。 这一问只给 1 分，而且用的词是 write down。

② 题干昭示了哪个方法

write down 加上 1 分，这两个信号一起出现的时候， 出题人等的是一眼看出来的理由，动手积分就说明读错了信号。 这道题里那个理由是对称性：密度关于区间中点对称，期望就落在中点。 按定义式 \(\int_2^{10} s f(s)\,ds\) 算出来的答案一样，可是要多花四五分钟， 在一张限时的卷子上，这几分钟通常比这一分值钱。

③ 回接上半

第二章第③幕「期望：为什么它落在正中间」。那一幕讲的是均匀分布， 而重心那句话的适用面更宽：任何一条关于某点对称的密度，期望都落在那一点上。 均匀分布是它最简单的一个例子。

④ 公式为什么用这一条

先把对称性验证一遍，这一步值得写在草稿上。中点是 \(\tfrac{2+10}{2}=6\)。 把 \(s\) 换成 \(12-s\)（关于 6 的镜像）代进密度：

\[ f(12-s) = k\,(12-s-2)\,(10-(12-s)) = k\,(10-s)\,(s-2) = f(s) \]

两个括号恰好互换，密度值不变。所以这条抛物线关于 \(s=6\) 对称，期望落在 6。

⑤ 每个等号一行，每一行写出依据
行写下的东西这一行凭什么
1\(f(12-s) = f(s)\) 上面那一步验证，两个因式互换
2密度关于 \(s = \dfrac{2+10}{2} = 6\) 对称 \(s\) 与 \(12-s\) 关于 6 互为镜像，密度在镜像的两点上取值相同
3\(E(S) = 6\) 对称密度的重心落在对称轴上（第二章第③幕）。单位是分钟
⑥ 得分位置

B1 给 \(6\)。这一分不看过程，写对数就有； 写错的常见来源是把 \(k\) 也带进对称性的判断里， 而 \(k\) 是一个正的常数因子，它不影响对称轴的位置。
